## 1. 주력 과제

**타이틀**  
전사 R&D LIMS 적재를 위한 접착제 레거시 데이터 Parsing Agent 개발

**기간**  
2026.07 ~ 2026.10(목표) · 진행 중

**역할**  
전사 R&D가 실험·시험 데이터를 LIMS(실험실 정보관리 시스템)로 모아 단일 진실원(SSOT)을 구축하는 전환에서, 접착제 사업부를 선행 도메인으로 두고 작성자·연도마다 제각각인 레거시 엑셀·PPT를 LIMS에 적재 가능한 정규화 데이터로 바꾸는 Parsing Agent 개발을 공동 담당했다. 병목은 LIMS 화면이 아니라 이미 쌓인 비표준 파일이었고, 표준 스키마를 먼저 확정해 끼워 맞추기보다 에이전트가 시트 구조를 해석하며 스키마를 데이터와 함께 다듬도록 설계·구현에 참여했다. 목표는 파서 제품의 완성이 아니라, 접착제부터 적재해 전사로 확대할 수 있는 데이터 입구를 만드는 일이었다. 첫째, Unipars docgraph 파이프라인이다. ingest에서 원본 셀·수식·병합·숨김을 SQLite 스테이징 DB에 해석 없이 전개하고 G1 라운드트립으로 blob 원본과의 일치를 검증했다. parse에서는 시트마다 에이전트가 claim(셀 주소를 가리키는 의미 주장)만 남기게 하고, 숫자·단위는 모델이 타이핑하지 못하도록 가드레일을 둬 셀 JSON에서만 복사되게 했다. lims에서는 오케스트레이터가 claim을 접착제 LIMS V0 29개 테이블(기준정보·조성·공정·측정)로 투영해 증거 DB(docgraph)와 제품 DB(LIMS sqlite)를 분리했다. recipe·sample·measurement_result처럼 grain이 다른 행을 섞지 않게 맞추고, Control Tower·제품군별 하드코드 어댑터·이중 저장소 경로를 제거해 ingest→parse→lims 단일 제품 경로로 리뉴얼했다. 둘째, 글로벌 스키마(공책) 공진화다. 파일마다 다른 스키마·매니페스트를 두지 않고 adhesive-lims-schema 루트에 에이전트가 파일 단위 적재 실험(analyses)을 직접 커밋했다. MI-data와 역할을 나눠 Explorer로 검수·합격하고, 사람만 아는 의미는 질문 문서로, 스키마가 못 받는 사실은 schema-feedback으로 남겨 표를 키웠다. Track A(데이터 기반 Parsing Agent)로서 Track B(Human 스키마)와 경계를 유지하면서도 접착제 도메인 숙지에 참여해, 연구원이 근거를 보고 최소 질문만으로 승인할 수 있게 품질 기준을 맞췄다. 셋째, 제품화와 품질이다. frontend·backend·worker를 서버리스로 나누고 업로드·작업 ID·checkpoint를 외부화하는 제약을 PoC와 정렬했으며, file-analysis harness의 source ledger 1:1 대조·residue 전수 회계·silent miss 0%를 기준으로 조용한 오파싱을 줄이고자 했다. 본인은 Unipars docgraph 리뉴얼, sqlite 스키마·식별자(문서·시트·셀 SHA-256) 정리, LIMS 투영 경로 문서화, uv 기반 배치 CLI 공유를 맡았다. 원본은 Git에 올리지 않고 취합 저장소와 분리했으며, 스테이징·카탈로그·LIMS sqlite 역할을 ADR·문서로 구분해 팀 용어를 맞췄다. 목표 완료 시점은 2026년 10월 이전이었고, 전사 확대 시에도 같은 파이프라인을 재사용할 수 있게 도메인 특화 하드코딩을 최소화했다. 또한 적재 실패가 스키마 빈칸으로 드러나도록 실험을 봉인·커밋하는 협업 규칙을 따랐으며, 업로드 UI·서버리스 worker 계약은 PoC 마일스톤과 맞춰 검토했다. 파일 단위 실험 폴더에는 메타·적재 리포트·질문·빈칸 문서와 sqlite를 남겨 재현 가능하게 했고, 원본 엑셀은 커밋하지 않는 원칙을 지켰다. 협업은 MI-agent 공동 담당 체계 아래에서 진행했다. 성공 기준은 적재 가능성과 검수 가능성을 함께 보는 것이었다. 이 경험은 전사 데이터 거버넌스의 입구를 만드는 일이었다. 파서 결과는 LIMS 적재 계약과 서로 정합하도록 반복 확인했고, 접착제 선도 적용이 전사 확대의 검증대가 되게 했다. 정리하면, 비표준 연구 데이터를 전사 LIMS SSOT로 흘려보내기 위한 에이전트 파싱·스키마 공진화·검증 가능한 적재 파이프라인을 설계하고 구현한 역할이었다.
