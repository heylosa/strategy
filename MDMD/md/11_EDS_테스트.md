# 11. EDS, 프로브, 제품 테스트

## 1. 한눈에 보기

### 왜 PE에게 중요한가

- 테스트는 PE가 제품을 "보는" 유일한 창이다. 공정 변수는 직접 보이지 않고, 테스트가 만든 전기 데이터와 불량 맵(fail bit map)으로만 드러난다.
- EDS(Electrical Die Sorting) 수율은 웨이퍼 한 장의 가치를 결정한다. 수율 1%p는 월 수십만 장 규모에서 곧바로 매출로 환산된다.
- 테스트는 불량을 "찾는" 일이자 "고치는" 일(리페어)이며, 동시에 "놓치는" 일이다. 놓친 불량은 고객 라인에서 DPPM(Defective Parts Per Million)으로 돌아온다.
- 비트맵 시그니처는 공정 사고의 지문이다. row fail, column fail, edge ring, 반복 결함 각각이 특정 공정 층과 장비를 가리킨다.
- 테스트 조건(온도, 전압, 타이밍, 패턴)은 그 자체가 설계 변수다. 조건을 잘못 잡으면 좋은 칩을 버리거나(over-kill) 나쁜 칩을 보낸다(under-kill).

### 핵심 키워드

| 용어 | 한 줄 정의 |
|---|---|
| WAT/PCM(Wafer Acceptance Test / Process Control Monitor) | 스크라이브 라인의 TEG 소자로 공정 파라미터(Vt, Rs, Cox 등)를 측정하는 공정 검수 |
| EDS(Electrical Die Sorting) | 웨이퍼 상태에서 프로브 카드로 각 다이의 기능·특성을 측정해 양/불을 가르는 웨이퍼 테스트 |
| FT(Final Test) | 패키지 후 소켓에서 수행하는 최종 전기 테스트 |
| SLT(System Level Test) | 실제 시스템(보드, 컨트롤러)과 유사한 환경에서 응용 조건으로 검증하는 테스트 |
| 프로브 카드(Probe Card) | 웨이퍼 패드에 수천~수만 개 니들을 접촉시켜 테스터와 다이를 연결하는 인터페이스 |
| 비트맵(Fail Bit Map, FBM) | 셀 어레이 좌표별 fail/pass를 그린 지도. 시그니처 분석의 원자료 |
| 리던던시/리페어(Redundancy / Repair) | 여분의 row/column을 두고 fail 주소를 퓨즈로 대체해 살리는 기술 |
| 번인(Burn-in) | 고온·고전압으로 초기 불량(infant mortality)을 강제로 앞당겨 걸러내는 스크리닝 |
| 리텐션(Retention) | DRAM 셀이 리프레시 없이 데이터를 유지하는 시간. 온도에 지수적으로 민감 |
| tRCD / tWR | RAS-to-CAS 지연, 쓰기 회복 시간. 셀-비트라인 경로의 저항·커패시턴스에 민감한 AC 파라미터 |
| Row Hammer | 인접 row 반복 활성화로 이웃 셀이 방전되는 간섭 불량 |
| Cycling / Retention Bake | NAND 셀에 P/E 사이클을 가하고 고온 방치해 내구성·보존성을 평가 |
| 수율(Yield) | 전체 다이 중 양품 비율. 결함밀도 D0와 다이 면적 A로 모델링 |
| DPPM | 출하 100만 개당 고객 불량 수. 테스트 커버리지 구멍의 정량 지표 |
| 테스트 커버리지(Test Coverage) | 실제 발생 가능한 불량 메커니즘 중 테스트가 검출할 수 있는 비율 |

## 2. 기초

### 2.1 메모리 제품이 거치는 테스트 흐름

메모리 웨이퍼 한 장은 팹에서 나온 뒤 아래 흐름을 거친다.

```text
 FAB 종료
   |
   v
 [WAT/PCM] -- TEG 소자 측정, 공정 합격 판정 (다이 아님, 스크라이브 라인)
   |
   v
 [EDS 1차] -- 상온/고온 기능 테스트, fail 주소 수집
   |
   v
 [리페어]  -- 퓨즈(레이저 또는 e-fuse/anti-fuse)로 fail row/col 대체
   |
   v
 [EDS 2차] -- 리페어 검증, 저온/고온 재테스트, 최종 양불 판정, 잉크/맵
   |
   v
 [조립/패키지] -- 다이싱, 본딩, 몰딩 (또는 TSV 스택)
   |
   v
 [번인]    -- 고온·고전압 스트레스 (선택적, 제품 등급별)
   |
   v
 [FT]      -- 패키지 상태 최종 테스트, 속도 등급(bin) 분류
   |
   v
 [SLT]     -- 시스템 조건 검증 (고신뢰 제품, 서버/차량용)
   |
   v
 출하 -> 고객 -> DPPM 피드백
```

각 단계는 "무엇을 측정하는가"와 "어디서 불량을 잡는 것이 가장 싼가"라는 두 질문에 답한다. 불량 검출 비용은 뒤로 갈수록 대략 10배씩 커진다는 경험칙이 있다. 웨이퍼에서 1원에 잡을 것을 패키지 후에는 10원, 시스템에서는 100원, 고객 현장에서는 1,000원 이상 들여 잡는 셈이다.

> **[핵심]** WAT/PCM은 "공정이 맞게 됐나"를 보고, EDS는 "이 다이가 동작하나"를 보고, FT는 "이 패키지가 스펙을 만족하나"를 보고, SLT는 "실제 시스템에서 문제없나"를 본다. 대상, 시점, 판정 단위가 모두 다르다.

### 2.2 WAT/PCM: 공정을 재는 시험

WAT(Wafer Acceptance Test) 또는 PCM(Process Control Monitor)은 다이가 아니라 스크라이브 라인에 심어둔 TEG(Test Element Group)를 측정한다. 트랜지스터, 저항, 커패시터, 컨택트 체인, 비아 체인 등이 대상이다.

대표 항목과 예시 값(일반적 범위, 세대별 상이):

| 항목 | 측정 대상 | 예시 스펙 | 공정 연관 |
|---|---|---|---|
| Vt (Vth) | 주변 회로 NMOS/PMOS | 목표 ±30 mV | 임플란트 dose, 게이트 산화막, 채널 길이 |
| Idsat | 트랜지스터 구동 전류 | 목표 ±5% | 채널 길이, 이동도, 소스/드레인 저항 |
| Ioff | 오프 누설 | ≤ 수 nA/μm | Vt, 접합 누설, GIDL |
| Rs (sheet resistance) | 메탈/폴리/확산층 | 목표 ±10% | 증착 두께, CMP, 임플란트 활성화 |
| 컨택트/비아 체인 저항 | 수천 개 직렬 컨택트 | 개당 수 Ω, 오픈 0개 | 식각 잔류물, 배리어, 필링 |
| Cox / EOT | 게이트 커패시턴스 | ±2% | 산화막 두께, 고유전막 |
| 브레이크다운 전압 | 산화막, 접합 | ≥ 스펙 전압의 1.5~2배 | 막질, 결함 |

WAT는 웨이퍼당 5~13개 사이트를 측정한다. 다이 전체를 대표하지 못하지만, 공정이 벗어났는지 빠르게 판정한다. WAT 불합격이면 EDS 이전에 웨이퍼를 홀드하거나 스크랩한다.

> **[주의]** WAT가 합격이어도 EDS 수율이 낮을 수 있다. WAT는 주변 회로 수준 소자를 보지만, 메모리 셀은 훨씬 작고 밀도가 높다. 셀 커패시터 누설이나 워드라인 브리지 같은 셀 고유 불량은 WAT에 나타나지 않는다. 그래서 EDS가 필요하다.

### 2.3 EDS: 다이를 재는 시험

EDS는 웨이퍼 상태에서 각 다이의 패드에 프로브 니들을 대고, 테스터(ATE, Automatic Test Equipment)가 전원과 신호를 공급해 메모리 셀 전체를 읽고 쓴다.

한 다이의 EDS는 크게 세 부류로 나뉜다.

1. DC 테스트: 전원 핀 누설, 오픈/쇼트, 대기 전류(IDD), 입력 누설. 프로브 접촉 확인도 겸한다.
2. 기능(function) 테스트: 모든 셀에 패턴을 쓰고 읽어 비교. fail 주소를 수집해 비트맵을 만든다.
3. AC/특성 테스트: 타이밍 마진(tRCD, tWR, tRP 등), 전압 마진(Vmin), 리텐션 시간, 속도 등급.

용량으로 감을 잡아 보자. 16 Gb DRAM은 약 1.7×10^10 개 셀이다. 한 패턴을 1회 쓰고 읽는 데 셀당 수 ns가 걸려도, 뱅크 병렬과 x16 이상 폭을 활용해 1회 스캔에 수십 ms~수 초가 든다. 패턴 수십 종에 온도 두 조건, 리텐션 대기까지 더하면 다이당 수십 초~수 분, 웨이퍼당 수 시간이 된다. 그래서 테스터 한 대가 웨이퍼의 수백 개 다이를 동시에 접촉하는 병렬 테스트(예시: 64~256 DUT 동시)를 한다.

> **[예시]** 300 mm 웨이퍼에 다이 크기 약 60 mm²라면 총 다이 수는 대략 1,000개 안팎이다. 다이당 테스트 시간 30초, 128 DUT 병렬이면 웨이퍼 1장에 30 × (1,000/128) ≈ 4분. 여기에 온도 안정화, 인덱싱, 리페어 재테스트가 더해져 실제로는 그 수 배가 된다.

### 2.4 프로브 접촉의 물리

프로브 니들이 알루미늄 또는 구리 패드에 닿을 때 다음 조건이 만족돼야 신뢰할 수 있는 측정이 된다.

- 접촉 저항(contact resistance): 대략 수 Ω 이하. 패드 표면의 자연 산화막(Al2O3 수 nm)을 니들이 뚫어야 한다. 이를 위해 접촉 후 미세하게 옆으로 미는 스크럽(scrub) 동작을 넣는다.
- 접촉 힘(contact force): 니들 하나당 대략 수 g 이하(예시: 2~8 gf). 너무 약하면 산화막을 못 뚫어 접촉 저항이 튀고, 너무 강하면 패드가 파이고 아래 층이 깨진다(프로브 마크 불량).
- 오버드라이브(overdrive): 첫 접촉 후 추가로 내려가는 깊이(예시: 50~100 μm). 니들 높이 편차(평탄도)를 흡수한다.
- 평탄도(planarity): 수천 개 니들의 팁 높이 차이(예시: ±10~15 μm). 편차가 크면 일부 다이는 접촉 불량, 일부는 과압.

패드 크기는 세대가 진행되며 줄어든다. 예시로 40~60 μm 피치 패드에 니들을 맞추려면 니들 팁 직경은 10 μm 급, 위치 정밀도는 ±5 μm 이내가 요구된다.

> **[예시]** 접촉 저항이 2 Ω에서 20 Ω으로 튀면 어떤 일이 생기나. 전원 핀에 100 mA가 흐를 때 전압 강하가 0.2 V → 2 V가 되어 실제 다이에는 규정 전압보다 훨씬 낮은 전압이 걸린다. 그러면 정상 다이가 Vmin fail로 잡힌다. 이것이 "테스트 불량(test-induced fail)"이며, 진짜 불량과 구분해야 한다.

### 2.5 메모리 테스트 알고리즘의 기초

메모리 셀 불량은 한 셀만 봐서는 잡히지 않는 것이 많다. 이웃 셀과의 간섭(coupling), 주소 디코더 불량, 감지 증폭기 마진 등을 보려면 패턴을 설계해야 한다.

| 패턴/알고리즘 | 동작 | 잡는 불량 | 대략 복잡도 |
|---|---|---|---|
| Solid (all 0 / all 1) | 전체에 0 또는 1 | stuck-at, 큰 쇼트/오픈 | 2N |
| Checkerboard | 인접 셀에 0/1 교차 | 인접 셀 브리지, 비트라인 커플링 | 4N |
| March C- | 0 쓰기 → 순방향 읽고 1 쓰기 → 역방향 … | stuck-at, transition, 주소 디코더, 일부 coupling | 10N |
| Row/Column stripe | 행 또는 열 단위 0/1 | 워드라인/비트라인 쇼트, 감지 증폭기 | 4N |
| Walking / Galloping | 1개 셀만 반전하며 전체 읽기 | 강한 coupling, 디코더 | N^1.5 ~ N² (부분 적용) |
| Retention (pause) | 쓰기 → 일정 시간 대기 → 읽기 | 셀 누설, weak cell | 2N + 대기 시간 |
| Hammer | 특정 row를 수만~수십만 회 활성화 | row hammer 취약 셀 | 시간 지배 |

N은 셀 수다. 16 Gb에 N² 알고리즘은 불가능하므로 실제로는 March 계열을 주력으로 하고 갤로핑은 소규모 블록에 샘플 적용한다.

> **[면접]** "메모리 테스트 패턴이 왜 여러 개 필요한가"를 묻는다면: 결론은 "불량 메커니즘마다 드러나는 조건이 다르기 때문"이다. 근거로, stuck-at은 한 값만 쓰면 보이지만 인접 셀 브리지는 두 셀이 반대 값일 때만 보이고, 디코더 불량은 특정 순서로 주소를 훑을 때만 보인다. 예로 체커보드는 인접 브리지를, March C-는 디코더와 transition을 10N 비용으로 잡는다. 마지막으로 "테스트 시간과 커버리지의 균형이 PE의 판단 영역"이라고 닫는다.

### 2.6 리던던시와 리페어의 기초

DRAM과 NAND는 설계 시점에 여분 셀을 넣어둔다. DRAM은 뱅크마다 여분 row와 column(예시: 서브어레이당 여분 row 수 개~수십 개), NAND는 여분 block과 column을 둔다.

리페어의 논리는 단순하다.

1. EDS 기능 테스트로 fail 주소를 수집한다.
2. 리페어 알고리즘이 "이 fail들을 가진 여분 row/col로 모두 덮을 수 있나"를 계산한다(2차원 커버 문제, 휴리스틱 사용).
3. 덮을 수 있으면 퓨즈 회로에 "원래 주소 → 여분 주소" 매핑을 기록한다. 레이저 퓨즈(메탈 절단) 또는 전기 퓨즈/anti-fuse(산화막 파괴로 단락)를 쓴다.
4. 재테스트로 리페어가 실제로 동작하는지 확인한다.

리페어 전 수율(raw yield, pre-repair)과 리페어 후 수율(post-repair)은 다르게 관리한다. 공정 품질은 pre-repair 비트 수와 분포로 보고, 사업 지표는 post-repair 수율로 본다.

> **[예시]** 어떤 다이에 single bit fail이 30개 흩어져 있고 서브어레이당 여분 row 4개가 있다고 하자. fail이 여러 서브어레이에 고르게 퍼져 있으면 각 서브어레이에서 1~2개씩만 써도 다 덮인다. 그러나 한 서브어레이에 30개가 몰려 있으면(cluster) 여분 4개로는 부족해 다이 전체가 불량이 된다. 같은 fail 수라도 분포가 수율을 결정한다.

### 2.7 수율과 DPPM의 기초 계산

수율 모델의 출발점은 결함밀도 D0(개/cm²)와 다이 면적 A(cm²)다.

- 포아송 모델: Y = exp(−D0·A)
- 음이항(negative binomial) 모델: Y = (1 + D0·A/α)^(−α). α는 클러스터링 계수(대략 1~3). 결함이 뭉쳐 있으면 α가 작아지고, 같은 D0에서 수율이 포아송보다 높게 나온다.

예시: D0 = 0.3/cm², A = 0.6 cm² → 포아송 Y ≈ exp(−0.18) ≈ 83.5%. α = 2인 음이항이면 (1 + 0.09)^(−2) ≈ 84.2%. 리던던시가 있으면 "치명 결함"만 D0에 넣으므로 실효 D0는 훨씬 낮아진다.

DPPM은 출하 후 고객이 발견한 불량 비율이다.

- DPPM = (고객 불량 수 / 출하 수) × 10^6
- 예시: 1,000만 개 출하에 불량 50개 → 5 DPPM.
- 일반 소비자용은 대략 수십~수백 DPPM, 서버/차량용은 한 자리 DPPM 이하를 요구하는 것이 일반적이다.

DPPM을 낮추는 세 가지 지렛대는 (1) 공정 결함밀도 감소, (2) 테스트 커버리지 향상, (3) 스크리닝 강화(번인, 가드밴드)다. (2)와 (3)은 over-kill 비용과 상충하므로 PE가 최적점을 찾아야 한다.

> **[핵심]** 수율은 "만든 것 중 얼마를 팔 수 있나", DPPM은 "판 것 중 얼마가 돌아오나"다. 둘은 상충한다. 테스트를 엄격히 하면 수율은 떨어지고 DPPM은 좋아진다. PE는 이 두 축의 교환 비율을 데이터로 정한다.

### 2.8 Shmoo, 가드밴드, bin

테스트 조건을 정하는 도구가 shmoo다. 두 축(예시: 전원 전압 × tRCD)을 격자로 훑으며 각 점에서 pass/fail을 찍는다.

```text
  VDD
  1.20 | P P P P P P P P F F
  1.15 | P P P P P P P F F F
  1.10 | P P P P P P F F F F
  1.05 | P P P P F F F F F F
  1.00 | P P F F F F F F F F
       +--------------------->  tRCD 짧아짐 (마진 축소)
         규격점(*)은 P 영역 안쪽에 있어야 하고,
         규격점과 P/F 경계 사이 거리가 마진이다.
```

- 가드밴드(guardband): 규격점보다 더 가혹한 조건으로 테스트해 마진을 확보하는 것. 예시로 규격 tRCD가 13.75 ns이면 테스트는 그보다 수 ns 짧은 값으로 한다. 이유는 (1) 테스터 정확도 오차, (2) 온도·전압 조건의 실사용 차이, (3) 시간에 따른 열화(에이징)를 미리 흡수하기 위해서다.
- 가드밴드가 크면 escape가 줄고 over-kill이 늘어난다. 최적값은 FT/필드 데이터와 수율 손실을 함께 보고 정한다.
- bin: 테스트 결과에 따른 다이 등급. 예시로 bin 1(완전 양품, 최고 속도), bin 2(양품, 낮은 속도 등급), bin 3(리페어 필요), 각종 fail bin(DC fail, function fail, retention fail 등). fail bin 코드의 분포 자체가 공정 진단 데이터다.

> **[예시]** 어떤 웨이퍼의 fail bin 분포가 "DC fail 1%, function fail 3%, retention fail 6%, 타이밍 fail 2%"에서 다음 로트에 "retention fail 12%"로 튀었다면, 원인은 누설 계열(접합, 유전막, GIDL)로 좁혀진다. function fail이 튀었다면 구조 불량(브리지, 오픈)이나 디코더 쪽이다. bin 분포는 비트맵을 열기 전에 보는 1차 진단표다.

### 2.9 테스트 데이터의 흐름

테스트가 만드는 데이터는 크게 네 층이다.

1. 다이 단위 결과: bin 코드, 파라메트릭 값(IDD, Vmin, 리텐션 시간 등). 웨이퍼 맵의 원천.
2. 비트 단위 결과: fail 주소(row, column, 뱅크, 패턴, 온도). 비트맵과 리페어의 원천. 용량이 커서 압축 저장.
3. 장비·조건 로그: 테스터 ID, 프로브 카드 ID, 사이트 번호, 척 온도, 시간. 테스트 유발 불량 배제의 원천.
4. 상관 데이터: WAT, 인라인 계측/결함 검사, 장비 이력과의 조인. 공정 원인 추적의 원천.

PE의 분석은 4개 층을 조인하는 일이다. 예시로 "retention fail bin 상승(1층) → 비트맵에서 랜덤 SB, 고온 전용(2층) → 특정 사이트 편중 없음, 테스트 문제 배제(3층) → 접합 임플란트 어닐 장비 A 경유 로트에만 발생(4층)"처럼 층을 내려가며 좁힌다.

## 3. 공정/기술 상세

### 3.1 테스트 단계별 비교

| 구분 | WAT/PCM | EDS | FT | SLT |
|---|---|---|---|---|
| 대상 | 스크라이브 라인 TEG | 웨이퍼 위 각 다이 | 패키지 단품 | 패키지 단품 또는 모듈 |
| 시점 | 팹 종료 직후 | 팹 후, 조립 전 | 조립 후 | FT 후 |
| 목적 | 공정 파라미터 합격 판정 | 다이 양불, 리페어, 맵 생성 | 최종 스펙 보증, 속도 bin | 시스템 조건 검증 |
| 측정 단위 | 소자(Vt, Rs, C) | 셀 비트, 타이밍, 전류 | 셀 비트, 타이밍, 전류, 열 | 응용 패턴, 트래픽 |
| 온도 | 대개 상온 | 상온, 고온, 저온 | 고온, 저온 | 시스템 온도(케이스) |
| 시간 | 웨이퍼당 수 분 | 웨이퍼당 수 시간 | 개당 수 초~수 분 | 개당 수 분~수 시간 |
| 못 잡는 것 | 셀 고유 불량, 다이별 편차 | 패키지 유발 불량, 고속 신호 | 시스템 상호작용 | 비용상 전수 적용 어려움 |

각 단계는 위 단계의 구멍을 메운다. 특히 EDS에서는 프로브 카드의 대역폭 한계로 고속 인터페이스(예시: 수 Gbps 이상 데이터 속도)를 실속도로 못 돌리는 경우가 많아, 고속 특성은 FT에서 확정한다. HBM처럼 패키지 후 접근이 제한되는 제품은 EDS 단계의 커버리지가 더욱 중요해진다.

### 3.2 프로브 카드 종류와 사양

| 종류 | 구조 | 장점 | 단점 | 적용 |
|---|---|---|---|---|
| 캔틸레버(cantilever) | 에폭시 링에 텅스텐 니들을 비스듬히 고정 | 저가, 수리 용이 | 핀 수 제한, 피치 한계(≥ 대략 50 μm), 낮은 병렬도 | 구형/저핀수 |
| 버티컬(vertical) | 가이드 플레이트 사이에 수직 핀(코브라, 버클링 빔) | 고핀수, 정확한 위치 | 고가, 수리 어려움 | 로직, 일부 메모리 |
| MEMS(micro-spring) | 반도체 공정으로 만든 미세 스프링 | 초고핀수(수만 개), 좁은 피치, 고병렬 | 매우 고가, 리드타임 김 | 메모리 EDS 주력 |

메모리 EDS용 MEMS 카드는 웨이퍼 전체 다이의 수십~수백 개를 한 번에 접촉하기 때문에 핀 수가 수만 개에 이른다. 카드 한 장의 가격은 대략 수억 원대에 달할 수 있고, 수명은 접촉 횟수(touchdown) 기준으로 관리한다(예시: 수십만~백만 회).

프로브 카드 관리 항목:

- 니들 팁 클리닝 주기: 알루미늄 잔사가 팁에 쌓여 접촉 저항 상승. 연마 시트에 일정 횟수마다 터치.
- 평탄도, 정렬(alignment) 측정: 카메라로 팁 위치를 측정. 오차 초과 시 수리.
- 접촉 저항 모니터링: DC 테스트의 컨택트 체크 실패율 추세로 감시.
- 프로브 마크 검사: 패드 위 마크 크기, 위치, 깊이. 마크가 패드 밖으로 나가면 패시베이션 손상 위험.

### 3.3 테스터와 프로버 구성

```text
 +------------------+       +----------------------+
 |  ATE (테스터)     |       |  Prober (프로버)     |
 |  - 패턴 생성기    | 케이블 |  - 웨이퍼 척 (온도)   |
 |  - 타이밍/전압    |<----->|  - XYZ 스테이지       |
 |  - 비교기/캡처    |       |  - 정렬 카메라        |
 |  - fail 메모리    |       |  - 프로브 카드 홀더    |
 +------------------+       +----------+-----------+
                                       |
                                  프로브 카드
                                       |
                                    웨이퍼
```

- 패턴 생성기(APG): 주소, 데이터, 명령을 알고리즘적으로 만들어 대용량 패턴 저장 없이 수행한다.
- fail 메모리(catch RAM): 다이별 fail 주소를 저장. 비트맵과 리페어 계산의 원천.
- 척(chuck): 웨이퍼를 진공 흡착하고 온도를 제어한다. 고온(예시: 85~95 °C), 저온(예시: −10~−40 °C), 상온.
- 인덱스 시간: 한 터치다운을 끝내고 다음 위치로 이동해 접촉하는 시간(예시: 수 초). 병렬도가 높으면 터치다운 수가 줄어 총 시간이 줄어든다.

테스트 시간을 구성하는 요소는 "테스트 자체 시간 × 터치다운 수 + 인덱스 시간 × 터치다운 수 + 온도 안정화 시간"이다. 이 셈법을 알아야 테스트 시간 절감 과제를 정량화할 수 있다.

### 3.4 온도 테스트: hot과 cold

같은 다이라도 온도에 따라 다른 불량이 드러난다.

| 조건 | 예시 온도 | 잘 드러나는 불량 | 이유 |
|---|---|---|---|
| 고온(hot) | 85~95 °C | DRAM 리텐션 fail, 누설, 접합 누설, NAND read disturb 마진 | 누설 전류가 온도에 지수적으로 증가. 리텐션 시간은 10 °C 상승에 대략 절반 |
| 저온(cold) | −10~−40 °C | 타이밍 fail(tRCD, tWR), Vt가 높은 셀의 쓰기 부족, 저온 컨택트 저항 | 트랜지스터 Vt 상승, 이동도 증가로 타이밍 특성이 바뀜. 컨택트/금속 저항 특성 변화 |
| 상온 | 25 °C | 기본 기능, 오픈/쇼트 | 기준 조건 |

고온은 누설 계열, 저온은 타이밍·구동 계열을 잡는다는 감각이 핵심이다. DRAM 리텐션은 셀 커패시터의 저장 전하가 접합 누설, GIDL, 트랩 어시스트 누설로 빠지는 것이며 이는 아레니우스 관계로 온도에 지수적이다. 예시로 상온에서 1초 버티는 셀이 85 °C에서 수십 ms로 떨어질 수 있다.

저온에서는 액세스 트랜지스터의 Vt가 올라 쓰기 시 셀에 전하가 충분히 들어가지 않는다. 그래서 tWR 마진이 줄어든다. 또 워드라인 부스트 전압(VPP)의 마진도 상대적으로 줄어든다. 한편 이동도는 저온에서 커져서 일부 경로는 빨라지는데, 이 두 효과가 경로별로 다르게 작용해 저온에서만 실패하는 경로가 생긴다.

> **[면접]** "왜 EDS를 고온과 저온 두 번 하나"라는 질문에는: 결론은 "불량 메커니즘의 온도 의존성이 반대이기 때문"이다. 고온은 누설이 커져 리텐션 fail을 드러내고, 저온은 Vt 상승으로 타이밍 fail을 드러낸다. 예로 상온에서 1초인 리텐션이 85 °C에서 수십 ms로 줄어 weak cell이 보이고, −25 °C에서는 tWR 마진 부족 셀이 보인다. 한 온도만 하면 다른 쪽 불량이 고객에게 간다.

### 3.5 DRAM 테스트 항목 상세

#### 기능(function) 테스트

- 각 뱅크, 각 row, 각 column을 모두 훑는다. 패턴은 solid, checkerboard, March 계열.
- fail 주소를 catch RAM에 기록해 비트맵을 만든다.
- 목적: stuck-at, 브리지, 오픈, 디코더 불량, 감지 증폭기 불량.

#### 리텐션 테스트

- 전체 셀에 데이터를 쓴 뒤, 리프레시를 멈추고 일정 시간(예시: 수십~수백 ms에서 수 초까지 단계적으로) 대기 후 읽는다.
- 대기 시간을 늘려 가며 fail 비트 수를 그리면 리텐션 분포(tail)가 나온다.
- 규격 리프레시 주기(예시: 64 ms 또는 고온에서 32 ms)에 마진(가드밴드, 예시: 2~4배)을 곱한 시간을 버티면 합격.
- 데이터 패턴 의존성이 있다. 셀 저장 값과 이웃 값에 따라 누설 방향이 달라, 0/1 패턴을 모두 본다.
- VRT(Variable Retention Time): 같은 셀의 리텐션 시간이 시간에 따라 두 상태 사이를 오가는 현상. 한 번 테스트로 못 잡는 대표적 커버리지 구멍이다.

#### tRCD / tWR 마진 테스트

- tRCD(RAS to CAS Delay): 워드라인을 켠 뒤 셀 전하가 비트라인에 나와 감지 증폭기가 증폭을 끝내기까지의 시간. 짧게 설정하고 읽어서 fail 나는 셀을 찾는다.
- tWR(Write Recovery): 쓰기 데이터가 비트라인을 거쳐 셀 커패시터에 충분히 들어가기까지의 시간. 짧게 설정하고 쓰고 읽어 fail 셀을 찾는다.
- 이 두 항목은 셀 트랜지스터의 구동력(Vt, 채널 길이), 비트라인 컨택트 저항, 셀 커패시턴스, 워드라인 저항에 직접 연결된다. 그래서 공정 변수의 미세 shift를 가장 먼저 반영하는 감도 높은 지표다.
- 테스트는 규격보다 짧은 값(가드밴드)으로 수행한다. 예시로 규격 tRCD가 13.75 ns이면 테스트는 그보다 수 ns 짧게 설정해 마진을 확인한다.

#### Row Hammer 테스트(개요)

- 한 row(aggressor)를 리프레시 주기 안에 수만~수십만 회 활성화하면 인접 row(victim) 셀의 전하가 빠져 비트 플립이 난다. 워드라인 스위칭에 의한 전하 주입, 인접 셀 간 커플링, 전자 이동 등이 원인으로 논의된다.
- 테스트: 특정 row 반복 활성화 후 이웃 row 읽기. 플립 비트 수와 플립이 시작되는 활성화 횟수(threshold, 예시: 세대가 진행되며 수만 회에서 수천 회 수준으로 감소했다는 보고가 있다)를 측정한다.
- 완화: TRR(Target Row Refresh), RFM(Refresh Management), PRAC(Per Row Activation Counting) 등 회로/프로토콜 대책. 테스트는 이 회로가 실제로 동작하는지도 확인한다.

#### 전류와 전압 마진

- IDD 계열 대기/동작 전류: 규격 초과는 누설 불량 또는 쇼트.
- Vmin: 정상 동작하는 최저 전원 전압. 낮을수록 마진이 좋음. 전압 shmoo(전압 × 타이밍 2차원 pass/fail 그림)를 그려 마진 지형을 본다.

### 3.6 NAND 테스트 항목 상세

#### Program / Erase 검증

- 각 block을 erase하고 각 page를 program하여 동작 여부와 시간(tPROG, tBERS)을 측정한다. 예시로 TLC의 tPROG는 대략 수백 μs~수 ms, tBERS는 수 ms대다.
- Program이 목표 Vt 분포에 도달하는지(ISPP, Incremental Step Pulse Programming 루프 수), erase 후 Vt가 충분히 낮은지 확인한다.
- 초기 bad block: 제조 시 이미 불량인 block을 찍어 bad block table에 등록한다. 규격상 일정 개수까지 허용(예시: 전체 block의 수 % 이내).

#### Read 마진 / Vt 분포

- 읽기 기준 전압(read level)을 바꿔 가며 fail 비트 수를 세어 Vt 분포의 폭과 인접 상태 간 간격(read window margin)을 구한다.
- TLC는 8개 상태, QLC는 16개 상태를 좁은 전압 범위(예시: 총 6~7 V 창)에 넣어야 하므로 상태당 간격이 수백 mV 수준이다. 분포가 조금만 넓어져도 read fail이 급증한다.
- 온칩 또는 컨트롤러 ECC가 있으므로 RBER(Raw Bit Error Rate)로 관리한다. 예시로 ECC 정정 한계가 코드워드당 수십~수백 비트일 때, 초기 RBER은 그 한계의 수 분의 1 이하여야 한다.

#### Cycling(내구성)

- P/E 사이클을 반복(예시: TLC 수천 회, QLC 수백~천 회 수준을 목표로 하는 것이 일반적)하며 RBER, tPROG, tBERS 변화를 추적한다.
- 터널 산화막에 트랩이 쌓여 erase가 느려지고 Vt 분포가 넓어진다. 어느 사이클에서 ECC 한계를 넘는지가 endurance다.
- EDS에서 전수 cycling은 시간상 불가능하므로, 샘플 block에 가속 cycling을 하거나 신뢰성 평가 단계에서 수행한다.

#### Retention Bake

- Program 후 고온(예시: 85~125 °C)에서 수 시간~수십 시간 방치(bake)하고 읽는다. 아레니우스 가속으로 상온 수년을 모사한다.
- 전하가 터널 산화막이나 블로킹 산화막을 통해 빠져 Vt가 낮아진다(charge loss). cycling 후 bake는 더 심하다(트랩이 누설 경로가 되기 때문).
- 반대로 이웃 셀 program으로 인한 Vt 상승(program disturb)이나 read disturb도 있다. 이들은 방향이 반대라 read level 최적화가 어렵다.

#### 기타

- 워드라인/비트라인 쇼트, 셀렉트 게이트 누설, 채널 홀 오픈(3D NAND) 등 구조 불량은 erase 실패, 전체 string fail 등으로 드러난다.
- 피크 전류(program 시 차지 펌프 동작), 대기 전류도 측정한다.

### 3.7 스크리닝: 번인과 전압 스트레스

초기 불량(infant mortality)은 미세 결함이 있는 소자가 사용 초기에 빠르게 고장 나는 것이다. 욕조 곡선(bathtub curve)의 앞부분에 해당한다. 스크리닝은 이 고장을 "출하 전에 미리 일어나게" 만드는 것이다.

| 방법 | 조건 예시 | 가속 원리 | 잡는 불량 | 부작용 |
|---|---|---|---|---|
| 번인(burn-in) | 125 °C, 정격 대비 +10~30% 전압, 수 시간~수십 시간 | 아레니우스(온도) + 전압 가속 | 산화막 약점, 컨택트 약점, 미세 파티클 브리지 | 시간·비용 큼, 양품 수명 일부 소모 |
| 웨이퍼 레벨 번인(WLBI) | 웨이퍼 상태에서 고온·고전압 인가 | 동일, 패키지 전 수행 | 동일, 조립 비용 절약 | 고온 프로브 카드 필요 |
| 전압 스트레스(voltage stress) | 짧은 시간(수 ms~수 초) 고전압 인가 후 테스트 | 산화막 약점의 조기 브레이크다운 | 게이트 산화막 핀홀, 셀 커패시터 유전막 약점 | 과도하면 양품도 손상 |
| 고온 동작 테스트(HTOL) | 신뢰성 평가용 장기 시험 | 온도·전압 가속 | 수명 전반 | 샘플만 |

번인의 효과는 가속 계수로 정량화한다. 예시로 활성화 에너지 Ea = 0.7 eV, 55 °C 사용 대비 125 °C 번인의 온도 가속 계수는 대략 수십 배. 전압 가속(예시: 지수 모델)을 곱하면 수백 배가 되어, 번인 24시간이 사용 조건 수천 시간에 해당한다.

DRAM 셀 커패시터 유전막(고유전 ZrO2 계열, 두께 수 nm)이나 NAND 터널 산화막은 약점이 있을 때 초기 브레이크다운을 일으킨다. 전압 스트레스는 이 약점을 EDS 단계에서 터뜨려 리페어 대상으로 만든다. 즉 스크리닝은 "잠재 불량을 현재 불량으로 바꿔 리페어로 처리한다"는 뜻도 있다.

> **[주의]** 스트레스를 세게 하면 잠재 불량은 더 잡히지만 양품의 일부도 손상되어 수율이 떨어지고 수명이 줄 수 있다. 스트레스 조건은 "잠재 불량 검출 곡선"과 "양품 손상 곡선"이 교차하기 전 지점에서 잡는다. 이 지점은 공정 세대와 결함 유형마다 다르므로 데이터로 정해야 한다.

### 3.8 리페어 흐름 상세

```text
 EDS 1차 (pre-repair)
   |  fail 주소 수집 (catch RAM)
   v
 리페어 해석 (repair analysis)
   |  - row fail -> 여분 row 배정
   |  - column fail -> 여분 column 배정
   |  - single bit -> row 또는 column 중 효율적인 쪽
   |  - 여분 부족 -> 다이 불량 (unrepairable)
   v
 퓨즈 프로그래밍
   |  - 레이저 퓨즈: 메탈 링크 절단 (별도 장비)
   |  - e-fuse / anti-fuse: 전기적으로 EDS 중 즉시 기록
   v
 EDS 2차 (post-repair)
   |  - 리페어 검증
   |  - 다른 온도 조건 테스트
   |  - 최종 bin 결정
   v
 웨이퍼 맵 (양/불/등급)
```

여분 자원의 양은 설계 시점의 결정이다. 여분을 많이 넣으면 수율은 오르지만 다이 면적이 커진다. 예시로 셀 어레이 면적의 수 %를 여분으로 쓰는 것이 일반적이며, 공정 초기(수율 램프 시기)에는 이 여분이 수율을 수십 %p 끌어올린다.

DRAM은 출하 후에도 고칠 수 있는 PPR(Post Package Repair)을 지원하는 세대가 있다. 시스템에서 fail row를 발견하면 명령으로 여분 row로 바꾼다. hPPR(hard, 영구)과 sPPR(soft, 전원 유지 중)이 있다. 이는 테스트 커버리지 구멍을 시스템 단계에서 보완하는 장치다.

| 변수 | 조절 방향 | 영향 받는 결과 | 모니터링 항목 |
|---|---|---|---|

| 번인 시간/온도/전압 | 강하게 | 초기 불량 제거↑, 비용↑, 양품 수명 소모 | 번인 fail율 추세, 번인 후 FT fail율 |

## 4. 결함·불량 유형

### 4.1 비트맵 시그니처 분류

비트맵은 셀 어레이 좌표(row × column)에 fail을 찍은 그림이다. fail이 어떤 모양으로 모이는지가 불량 원인의 첫 단서다.

| 시그니처 | 현상 | 발생 원인(대표) | 검출/분석 | 대책 |
|---|---|---|---|---|
| Single bit(SB) | 한 셀만 fail, 무작위 분포 | 셀 커패시터 누설, 접합 결함, 컨택트 고저항, 랜덤 파티클 | 기능/리텐션 테스트, 분포 통계, 소자 분석 | 여분 row/col로 리페어, 결함밀도 저감 |
| Row fail(WL fail) | 한 row 전체 또는 대부분 fail | 워드라인 오픈/쇼트, 워드라인 드라이버 불량, 게이트 컨택트 | row 주소 통계, 인접 row 상태, 물리 좌표 | 여분 row 리페어, 게이트/WL 공정 점검 |
| Column fail(BL fail) | 한 column 전체 fail | 비트라인 오픈/쇼트, 감지 증폭기 불량, 비트라인 컨택트 | column 주소 통계, 감지 증폭기 대응 | 여분 column 리페어, BL/SA 공정 점검 |
| Paired row/column | 인접 두 줄이 함께 fail | WL-WL 또는 BL-BL 브리지(식각 잔류, 파티클) | 두 줄 데이터 의존성(반대 값일 때만 fail) | 리페어, 식각/세정 점검 |
| Block fail | 서브어레이 또는 뱅크 단위 fail | 로컬 전원/디코더/감지 증폭기 블록 불량, 큰 파티클, 스크래치 | 블록 경계와 일치 여부, 물리 좌표 | 대개 unrepairable, 공정/장비 추적 |
| Cluster | 국소 영역에 SB가 뭉침 | 국소 막 두께 이상, 국소 파티클, CMP 스크래치, 포토 디포커스 | 클러스터 크기·형태, 웨이퍼 내 위치 | 여분 부족 시 불량, 해당 공정 국소 균일도 개선 |
| Repeater | 웨이퍼 내 여러 다이에서 같은 좌표 fail | 레티클 결함, 마스크 파티클, 스캐너 슬릿 이상, 레이아웃 약점 | 다이 좌표 겹치기(stacked map), 레티클 필드 내 위치 | 마스크 검사/수리, 레이아웃 수정 |
| Edge ring | 웨이퍼 가장자리 다이 집중 fail | 식각/증착 에지 불균일, 스핀 코팅 두께, 척 온도 에지 편차 | 반경 방향 수율 프로파일 | 에지 공정 튠, 에지 배제 |
| Center / radial | 중심 또는 반경 방향 패턴 | CMP 압력 분포, 플라즈마 밀도 분포, 온도 분포 | 반경 프로파일, 공정 챔버별 비교 | 챔버 매칭, 레시피 조정 |
| Scratch / line | 직선 또는 곡선 형태 fail | CMP 스크래치, 웨이퍼 핸들링 긁힘 | 선 형태와 방향, 공정 순서 추정 | CMP 슬러리/패드 관리, 핸들링 점검 |
| Zone / stripe | 웨이퍼 절반 또는 띠 형태 | 스캐너 노광 필드 편차, 레이저 어닐 스캔, 척 온도 | 필드 경계와 일치 여부 | 장비 캘리브레이션 |
| Data-dependent | 특정 패턴에서만 fail | 인접 셀 커플링, 감지 증폭기 오프셋, 약한 셀 | 패턴별 fail 교차 비교 | 리페어, 설계/공정 마진 개선 |
| Temperature-dependent | 특정 온도에서만 fail | 리텐션(고온), 타이밍(저온) | 온도별 비트맵 비교 | 온도별 리페어, 가드밴드 |

> **[핵심]** 비트맵 해석의 순서는 "전기적 주소 → 물리적 좌표 변환 → 시그니처 분류 → 공정 층 후보 → 공정 데이터(WAT, 인라인 계측, 장비 이력)와 상관 → 물리 분석(FA)으로 확정"이다. 주소 스크램블링 때문에 논리 주소와 물리 위치는 다르다. 변환 없이 맵을 읽으면 오판한다.

### 4.2 맵 시그니처 → 공정 층 매핑

| 맵 시그니처 | 가장 의심되는 공정/층 | 함께 볼 데이터 | 확인 방법 |
|---|---|---|---|
| 랜덤 SB 증가(리텐션) | 셀 커패시터 유전막, 접합(임플란트), 셀 컨택트 | 리텐션 분포 tail, 고온 vs 상온 비율 | 커패시터 누설 TEG, TEM 단면 |
| 랜덤 SB 증가(tWR/tRCD) | 셀 트랜지스터 Vt, 비트라인 컨택트 저항, 워드라인 저항 | WAT Vt/Rs, 저온 fail 비율 | 컨택트 체인 저항, 저온 shmoo |
| Row fail 증가 | 워드라인(게이트) 형성, 게이트 컨택트, WL 드라이버 | 인라인 CD, 식각 EPD, 드라이버 위치 | WL 저항 측정, 단면 SEM |
| Column fail 증가 | 비트라인 형성, BL 컨택트, 감지 증폭기 | BL CD, 메탈 두께, SA 위치 | BL 저항, 브리지 위치 EBI/EBAC |
| Paired WL/BL | 라인 간 브리지(식각 잔류, 파티클, 포토 브리지) | 결함 검사(파티클) 맵과 겹치기 | 물리 분석, 세정 강화 |
| Cluster(국소) | 파티클, CMP 스크래치, 포토 디포커스 핫스팟 | 인라인 결함 검사 맵, 포커스 맵 | 결함 좌표 매칭 |
| Repeater(레티클 주기) | 마스크 결함, 스캐너 슬릿/렌즈 국소 이상 | 레티클 필드 내 좌표 통계 | 마스크 재검사 |
| Edge ring | 에지 식각률, 증착 두께, 코팅 두께, 척 온도 | 인라인 두께 맵 반경 프로파일 | 에지 튠 실험 |
| Center-fast/slow | CMP 압력, 플라즈마 분포, RTP 온도 | 두께/CD 반경 프로파일 | 챔버 매칭 |
| Block fail | 큰 파티클, 스크래치, 로컬 전원 라인 오픈, 디코더 | 결함 검사(대형), 물리 좌표 | 광학/SEM 검사 |
| 고온 전용 fail 증가 | 접합 누설, GIDL, 유전막 트랩 | WAT Ioff, 리텐션 분포 | 온도 가속 분석 |
| 저온 전용 fail 증가 | Vt 상승 폭, 컨택트 저항 온도 계수 | WAT Vt, 저온 Rs | 저온 shmoo |
| P/E 실패 block(NAND) | 채널 홀 식각 잔류, 셀렉트 게이트, 워드라인 컨택트(계단) | 채널 홀 CD/보잉, 계단 컨택트 저항 | 단면 TEM, 스트링 전류 |
| Read window 축소(NAND) | 전하 트랩막 두께/조성, 터널 산화막, 채널 폴리 결정성 | 인라인 두께, ISPP 루프 수 | Vt 분포 분석 |

이 표는 시작점이다. 같은 시그니처가 다른 원인일 수 있으므로, 항상 2개 이상 독립 데이터로 교차 확인한다.

### 4.3 테스트 자체가 만드는 불량과 오판

| 결함명 | 현상 | 발생 원인 | 검출/분석 방법 | 대책 |
|---|---|---|---|---|
| 컨택트 불량(open) | 특정 사이트 다이 전부 DC fail 또는 전 비트 fail | 니들 오염, 니들 높이 편차, 패드 산화 | 사이트별 fail 상관, 컨택트 저항 로그 | 니들 클리닝, 카드 수리, 오버드라이브 조정 |
| 접촉 저항 상승 | Vmin fail, 전원 노이즈 fail 증가 | 니들 팁 마모/오염 | 전원 핀 전압 실측, 재테스트 pass 비율 | 클리닝 주기 단축 |
| 프로브 마크 과대 | 패드 파임, 패시베이션 크랙, 후속 본딩 불량 | 접촉 힘 과대, 오버드라이브 과대, 정렬 오차 | 마크 검사(크기, 위치, 깊이) | 힘/오버드라이브 감소, 정렬 보정 |
| 사이트 간 편차 | 특정 DUT 위치만 수율 낮음 | 카드 배선 길이 차, 전원 분배, 온도 편차 | 사이트별 수율 맵 | 카드 설계 개선, 사이트 보정 |
| 테스터 상관성 불량 | 테스터 A와 B의 결과 불일치 | 캘리브레이션, 타이밍 정확도, 전원 임피던스 | 골든 웨이퍼 반복 측정(GR&R) | 캘리브레이션, 상관 웨이퍼 관리 |
| 온도 불안정 | 척 온도 설정과 다이 온도 차 | 척 열 접촉, 다이 자체 발열, 대기 시간 부족 | 온도 센서 다이, 온도별 fail 재현성 | 안정화 시간, 발열 보정 |
| 전원 노이즈(병렬 테스트) | 여러 DUT 동시 동작 시 fail 증가 | 공유 전원 경로 임피던스 | 병렬도 낮춰 재테스트 | 디커플링, 전원 분리 |
| Over-kill | 양품을 불량 판정 | 가드밴드 과대, 테스트 불량 | 재테스트 회수율, FT 상관 | 가드밴드 최적화 |
| Under-kill(escape) | 불량을 양품 판정 | 커버리지 구멍, 조건 미달 | FT/SLT/고객 불량 역추적 | 테스트 항목 추가 |

> **[트러블슈팅]** 증상: 특정 로트에서 갑자기 수율 5%p 하락. 원인 후보 1순위는 공정이 아니라 테스트다. 확인 순서: (1) 같은 웨이퍼를 다른 프로브 카드/테스터로 재측정, (2) fail이 사이트 위치와 상관 있는지 확인, (3) 컨택트 저항 로그. 프로브 카드 문제라면 재테스트에서 대부분 회복된다. 공정 문제라면 카드를 바꿔도 같은 다이가 fail한다. 이 구분 없이 공정을 건드리면 시간과 웨이퍼를 낭비한다.

### 4.4 EDS 통과 후 FT/SLT/고객에서 나타나는 불량

| 결함명 | 현상 | 발생 원인 | 검출/분석 방법 | 대책 |
|---|---|---|---|---|
| 조립 유발 불량 | FT에서 오픈/쇼트, 특정 핀 fail | 본딩 불량, 다이 크랙, 몰딩 응력, 다이싱 칩핑 | X-ray, 초음파(SAT), 단면 | 조립 공정 관리 |
| 고속 인터페이스 fail | FT 실속도에서만 fail | EDS는 저속만 가능, I/O 회로 마진 | FT 속도 bin, 아이 다이어그램 | EDS 커버리지 보완 또는 FT 의존 |
| 리텐션 tail 셀 | 고객 시스템에서 산발적 비트 오류 | VRT, 테스트 온도/시간 미달, 패턴 미달 | 필드 반환품 리텐션 재측정 | 가드밴드 조정, 온칩 ECC, 리프레시 관리 |
| 열 관련 fail | 시스템 고온에서만 fail | 패키지 열저항, 스택 내부 온도, 테스트 온도보다 높은 실사용 온도 | 열 시뮬레이션, 온도 센서 로그 | 열 설계, 온도 조건 재설정 |
| 잠재 신뢰성 불량 | 사용 수백~수천 시간 후 fail | 산화막 약점, 전자이동(EM), 핫캐리어 | 번인 fail율, HTOL, FA | 번인 강화, 공정 개선 |
| 응력 유발 특성 변화 | 패키지 후 Vt/타이밍 shift | 몰딩/기판 응력이 채널 응력 변화 | EDS vs FT 파라미터 비교 | 설계 마진, 패키지 재료 |
| 시스템 상호작용 | SLT에서만 fail | 컨트롤러 트래픽 패턴, 전원 시퀀스, 특정 명령 조합 | SLT 로그, 트래픽 재현 | 펌웨어/설계 대응, SLT 패턴 EDS 이식 |

> **[면접]** "EDS를 통과한 칩이 고객에서 불량이 나는 이유"를 묻는다면: 결론은 "테스트가 재현하지 못한 조건이 있기 때문"이다. 세 종류로 나눈다. 첫째, 시간 축 구멍(VRT, 잠재 신뢰성 불량은 짧은 테스트에서 안 보임). 둘째, 조건 축 구멍(실사용 온도, 실속도, 특정 트래픽 패턴). 셋째, 테스트 이후 발생(조립 응력, 핸들링). 예로 VRT 셀은 테스트 순간 좋은 상태였다가 고객에서 나쁜 상태로 바뀐다. 대책은 온칩 ECC와 PPR로 시스템에서 흡수하고, 필드 데이터를 EDS 조건에 역반영하는 것이다.

## 5. 공정 변수 ↔ 소자/제품 특성 상관관계

### 5.1 DRAM: 공정 변수 shift가 테스트에 나타나는 방식

| 공정 변수 shift | 소자 특성 변화 | 테스트에서 보이는 것 | 수율/신뢰성 영향 |
|---|---|---|---|
| 셀 트랜지스터 Vt↑(임플란트 dose↑, 채널 도핑↑) | 구동 전류↓, 누설↓ | tWR fail↑(특히 저온), 리텐션은 개선 | 저온 수율↓, 리텐션 tail 개선 |
| 셀 트랜지스터 Vt↓ | 구동↑, 서브스레숄드 누설↑ | tWR 개선, 리텐션 fail↑(고온) | 고온 수율↓, 리프레시 마진↓ |
| 셀 커패시터 유전막 두께↓ | 커패시턴스↑, 누설↑, 브레이크다운↓ | 감지 마진 개선, 리텐션 fail↑, 스트레스 fail↑ | 신뢰성 위험, 초기 불량↑ |
| 셀 커패시터 유전막 두께↑ | 커패시턴스↓ | tRCD fail↑, 감지 마진↓, 리텐션 fail↑(전하 적음) | 상온/저온 수율↓ |
| 커패시터 HAR 식각 보잉/휨 | 인접 커패시터 브리지, 면적 편차 | Paired bit fail, 국소 cluster | 리페어 소모↑, 수율↓ |
| 비트라인 컨택트 저항↑(식각 잔류, 배리어) | RC 지연↑ | tRCD/tWR fail↑, column fail(심하면 오픈) | 타이밍 수율↓ |
| 워드라인 저항↑(메탈 두께↓, CD↓) | WL 상승 시간↑ | 어레이 끝단 셀 tRCD fail, row fail(오픈) | 타이밍 수율↓ |
| 워드라인-워드라인 브리지(식각 잔류) | 인접 row 동시 활성화 | Paired row fail, 데이터 의존 fail | 리페어 소모↑ |
| 접합 누설↑(임플란트 손상, 어닐 부족) | 셀 노드 누설↑ | 고온 리텐션 fail↑, 랜덤 SB↑ | 고온 수율↓, 필드 리텐션 위험 |
| GIDL↑(게이트-드레인 오버랩, 필드) | 오프 상태 누설↑ | 리텐션 fail↑, 특정 데이터 패턴 의존 | 리프레시 마진↓ |
| 감지 증폭기 트랜지스터 미스매치↑ | 오프셋 전압↑ | column fail 또는 column 단위 마진 부족, 데이터 의존 | 리페어 소모↑ |
| 셀 커패시터 면적 편차(리소 CD) | 커패시턴스 편차 | tRCD/리텐션 분포 폭↑ | 마진 분포 tail↓ |
| 워드라인 간격↓ / 셀 간 커플링↑ | row hammer 취약성↑ | hammer 테스트 플립↑ | 보안/신뢰성 이슈, 완화 회로 부담 |

> **[심화]** tRCD와 tWR은 같은 셀-비트라인 경로를 보지만 반대 방향 전하 이동이다. tRCD는 셀에서 비트라인으로 전하가 나와 감지되는 시간, tWR은 비트라인에서 셀로 전하가 들어가는 시간. 셀 트랜지스터 Vt가 높아지면 tWR은 나빠지고 tRCD는 상대적으로 덜 영향받는다(감지는 작은 전하 차이로도 시작되므로). 둘의 fail 비율 변화를 보면 Vt 문제인지, 컨택트 저항 문제인지, 커패시턴스 문제인지 1차 분류가 가능하다.

### 5.2 NAND: 공정 변수 shift가 테스트에 나타나는 방식

| 공정 변수 shift | 소자 특성 변화 | 테스트에서 보이는 것 | 수율/신뢰성 영향 |
|---|---|---|---|
| 채널 홀 CD↑(상부) / 보잉 | 셀 크기 편차, 상하부 특성 차 | 층별 Vt 분포 폭↑, 특정 WL 층 read fail↑ | read window 마진↓ |
| 채널 홀 미개통(식각 부족) | 스트링 전류 없음 | 해당 스트링 전체 fail, erase 실패 | block fail↑ |
| 채널 폴리 두께/결정성 변화 | 스트링 전류↓, 이동도↓ | read 속도↓, tR 증가, 하부 층 fail | 성능 bin↓ |
| 터널 산화막 두께↓ | program/erase 빠름, 리텐션 나쁨 | tPROG↓, retention bake 후 charge loss↑ | 신뢰성↓ |
| 터널 산화막 두께↑ | program/erase 느림 | ISPP 루프 수↑, tBERS↑, erase 실패 | 성능↓, cycling 열화 형태 변화 |
| 전하 트랩막(SiN) 두께/조성 변화 | 트랩 밀도, 저장 전하량 변화 | Vt 분포 위치 shift, 상태 간 간격 변화 | read level 재최적화 필요 |
| 블로킹 산화막 약화 | 게이트 쪽 전하 누설 | program 후 Vt 상승 부족, retention bake fail | 신뢰성↓ |
| 워드라인(메탈 게이트) 저항↑ | WL 상승 지연 | 층별 tPROG/read 타이밍 편차 | 성능 편차 |
| 계단(staircase) 컨택트 오픈/고저항 | 특정 WL 구동 불가 | 특정 층 전체 page fail | block 또는 plane 단위 불량 |
| 셀렉트 게이트 Vt 편차 | 스트링 선택 마진↓ | 누설 스트링, program disturb↑ | RBER↑ |
| WL 간 절연막 두께↓ | WL-WL 커플링↑, 브레이크다운↓ | 인접 WL disturb↑, 고전압 program 시 fail | 신뢰성↓ |
| 슬릿 식각 편차 | 블록 간 분리 불량 | 인접 block 간섭, erase 간섭 | block fail↑ |
| 채널 홀 내 잔류물/보이드 | 국소 트랩, 누설 | 특정 스트링 read fail, cycling 조기 열화 | endurance↓ |

### 5.3 테스트 조건 ↔ 검출력 상관

| 조건 변화 | 검출력 변화 | over-kill 변화 | 판단 기준 |
|---|---|---|---|
| 리텐션 대기 시간 2배 | tail 셀 검출↑ | 2배 마진 필요 없는 양품도 fail | FT/필드 리텐션 불량률 vs 수율 손실 |
| 고온 85 → 95 °C | 누설 계열 검출↑ | 양품 리텐션 분포 전체 이동 | 실사용 최고 온도 + 마진 |
| tRCD 가드밴드 1 ns 추가 | 마진 부족 셀 검출↑ | 규격 만족 셀도 fail | FT 타이밍 상관 |
| 패턴 추가(예: hammer) | 특정 메커니즘 검출↑ | 거의 없음 | 테스트 시간 증가분 |
| 전압 스트레스 강화 | 잠재 불량 조기 검출↑ | 양품 손상 시작점 이후 급증 | 스트레스 후 신뢰성 샘플 |
| 병렬도↑ | 처리량↑ | 전원 노이즈로 오판 가능 | 사이트 편차 |

## 6. 트러블슈팅 케이스

### 케이스 1: 특정 로트 EDS 수율 급락, 웨이퍼 에지 column fail

- 증상: 3개 로트에서 EDS post-repair 수율이 평균 대비 약 8%p 하락. 불량 다이가 웨이퍼 가장자리 약 15 mm 링에 집중.
- 1차 데이터: 비트맵에서 column fail이 다이당 수십 개. 여분 column을 초과해 unrepairable. 상온·고온·저온 모두 동일하게 나타남(온도 무관). 사이트 위치와 상관 없음(테스트 문제 아님).
- 가설 나열:
  1. 비트라인 컨택트 식각 에지 부족(잔류물로 고저항/오픈).
  2. 비트라인 메탈 증착 에지 두께 편차.
  3. 감지 증폭기 영역 리소 에지 디포커스.
  4. 프로브 카드 에지 사이트 접촉 문제.
- 가설 검증:
  - 가설 4: 다른 카드로 재테스트 → 동일 다이 fail. 기각.
  - 가설 3: 디포커스라면 SA 영역 CD 이상과 함께 row 쪽 영향도 있어야 하나 column만 fail. 포커스 맵 정상. 기각.
  - 가설 1 vs 2: WAT 비트라인 컨택트 체인 저항의 에지 사이트 값이 중심 대비 약 30% 높음. 메탈 Rs는 반경 방향 차이 없음. 가설 1 유력.
  - 단면 TEM: 에지 다이의 비트라인 컨택트 바닥에 잔류 산화막 수 nm 확인.
- 근본 원인: 컨택트 식각 장비 특정 챔버의 에지 식각률 저하(엣지 링 부품 마모로 플라즈마 분포 변화). 해당 3개 로트가 같은 챔버를 거침.
- 조치: 챔버 엣지 링 교체, 에지 식각률 보정 레시피 적용. 챔버별 WAT 컨택트 저항 반경 프로파일을 관리 항목에 추가.
- 재발 방지: 챔버 부품 수명 관리 강화. EDS 비트맵에서 "에지 링 + column fail" 조합을 자동 알람 룰로 등록해 로트 단위가 아닌 웨이퍼 단위로 조기 검출.

### 케이스 2: 고온 EDS에서 리텐션 fail 증가, 특정 서브어레이 위치

- 증상: 신제품 램프 중 고온 리텐션 fail 비트 수가 다이당 평균 2배 증가. 상온 기능 테스트는 정상. 리페어 후 수율 하락은 약 3%p이지만 리페어 자원 소모가 커 향후 위험.
- 1차 데이터: fail 비트는 랜덤 SB 형태이나, 다이 안에서 특정 서브어레이 위치(다이 중심부 뱅크)에 편중. 웨이퍼 내 위치 편차는 약함. 리텐션 분포를 그리면 tail 부분만 나빠지고 메인 분포는 동일.
- 가설 나열:
  1. 셀 커패시터 유전막 국소 두께 편차(다이 내 위치).
  2. 접합 누설 증가(임플란트 또는 어닐 다이 내 편차).
  3. 다이 자체 발열로 중심부 실제 온도가 설정보다 높음(테스트 조건 문제).
  4. GIDL 증가(워드라인 오프 전압 마진).
- 가설 검증:
  - 가설 3: 병렬도를 절반으로 낮추고 대기 시간을 늘려 재테스트 → 중심부 편중이 절반으로 줄었으나 여전히 존재. 부분 기여.
  - 가설 4: 워드라인 오프 전압을 더 낮게(음전압 강화) 설정해 재테스트 → fail 수 변화 미미. 기각.
  - 가설 1 vs 2: 온도 가속 기울기(85 vs 95 °C fail 비율)로 활성화 에너지를 추정. 접합 누설(대략 0.6~0.7 eV대)에 가까운 값. 커패시터 유전막 누설이라면 다른 온도 의존성과 전압 의존성을 보임. 전압 의존성 확인 시 셀 플레이트 전압 변화에 둔감 → 가설 2 유력.
  - 인라인 데이터: 셀 접합 임플란트 후 어닐의 웨이퍼 내 온도 균일도는 정상이나, 다이 내 패턴 밀도 차이에 따른 어닐 국소 온도 차(패턴 로딩 효과)를 시뮬레이션으로 확인.
- 근본 원인: 레이저/RTP 어닐에서 다이 중심부(고밀도 어레이) 흡수율 차이로 국소 온도가 낮아 접합 결함 회복 부족 → 누설 증가. 여기에 테스트 시 다이 자체 발열이 겹쳐 증상이 증폭.
- 조치: 어닐 조건 조정(에너지/시간 미세 상향), 어레이 주변 더미 패턴 밀도 조정 검토. 테스트 측은 병렬도 조건에서 발열 보정용 온도 안정화 시간 추가.
- 재발 방지: 리텐션 fail의 다이 내 위치 분포를 정기 모니터링 항목에 추가. 온도 가속 기울기 기반 누설 메커니즘 자동 분류 스크립트 도입.

> **[아이디어]** 리텐션 tail의 온도 가속 기울기를 셀 단위로 자동 산출하면, 접합 누설형과 유전막 누설형을 테스트 데이터만으로 1차 분류할 수 있다. 이를 리페어 우선순위(필드에서 악화될 셀 우선 리페어)에 반영하는 것이 목표. 다만 셀당 여러 온도 측정이 필요해 테스트 시간이 문제이며, 샘플 다이에만 적용하는 방식이 현실적이다.

### 케이스 3: EDS 통과 칩이 FT에서 리텐션 fail — 커버리지 구멍

- 증상: FT 고온 리텐션 항목에서 fail이 평소 대비 3배. 해당 칩은 EDS 고온 리텐션을 통과한 것들.
- 1차 데이터: FT fail 비트 주소를 EDS 비트맵과 비교 → 대부분 EDS에서는 pass. FT fail 셀은 다이 내 특정 위치 편중 없음. 같은 칩을 FT에서 3회 반복 측정하면 fail 셀이 매번 조금씩 다름(재현성 낮음).
- 가설 나열:
  1. VRT 셀(리텐션 시간이 두 상태 사이를 오가는 셀)이 EDS 시점에는 좋은 상태.
  2. 조립 응력으로 리텐션 특성 변화.
  3. EDS와 FT의 실제 다이 온도 차(FT 소켓 열저항, 패키지 내부 온도).
  4. EDS 리텐션 가드밴드 부족.
- 가설 검증:
  - 가설 3: 열 시뮬레이션과 온도 센서로 FT 시 다이 온도가 EDS 대비 약 5 °C 높음 확인. 리텐션은 10 °C에 약 2배이므로 5 °C는 약 1.4배 기여. 일부 기여하나 3배는 설명 못 함.
  - 가설 2: EDS 직후 패키지 없이 재측정한 대조군(웨이퍼 일부 보관)과 비교 → 응력 효과는 미미.
  - 가설 1: FT fail 셀 중 절반 이상이 반복 측정에서 pass/fail을 오감. 시간 도메인 측정(수 분 간격 반복)에서 두 상태 전이 확인. VRT 확정.
  - 가설 4: 가드밴드는 규격 대비 충분했으나 VRT의 나쁜 상태 리텐션이 가드밴드 안에 들어옴.
- 근본 원인: VRT 셀 발생률 증가. 물리적으로는 셀 트랜지스터 근처 산화막 계면 트랩이 전하를 잡고 놓으며 누설 경로가 켜지고 꺼지는 것으로 해석. 특정 공정 변경(게이트 산화막 질화 조건 변경)이 시기적으로 일치.
- 조치: 공정 변경 롤백 및 재평가. 테스트 측은 EDS 고온 리텐션을 2회 측정(시간 간격)하여 한 번이라도 fail이면 리페어 대상으로 처리(테스트 시간 약 10% 증가). 온칩 ECC로 필드 흡수 여력 확인.
- 재발 방지: 공정 변경 시 VRT 평가를 필수 항목화. FT fail 셀의 EDS 이력 자동 조회 체계 구축(FT-EDS 비트 단위 상관).

> **[핵심]** 테스트 커버리지 구멍은 "시간 축(VRT, 잠재 불량)", "조건 축(온도, 전압, 패턴, 속도)", "시점 축(테스트 후 발생)"으로 나뉜다. 어느 축의 구멍인지에 따라 대책이 다르다. 시간 축은 반복 측정과 스크리닝, 조건 축은 조건 확대와 가드밴드, 시점 축은 후공정 관리와 PPR/ECC다.

### 케이스 4: 프로브 카드 교체 후 특정 사이트 Vmin fail 급증

- 증상: 신규 프로브 카드 투입 직후 특정 4개 사이트(DUT 위치)에서 Vmin fail이 다른 사이트 대비 10배.
- 1차 데이터: fail 다이를 다른 사이트 위치로 재테스트 → 대부분 pass. 즉 다이가 아닌 사이트 문제. 컨택트 체크(DC)는 pass. 해당 사이트의 전원 핀 전압을 직접 측정하면 설정보다 약 80 mV 낮음.
- 가설 나열:
  1. 해당 사이트 전원 핀 니들 접촉 저항 높음(팁 오염/높이).
  2. 카드 내부 전원 배선 저항 또는 디커플링 불량.
  3. 테스터 채널 캘리브레이션.
- 가설 검증:
  - 가설 3: 같은 테스터에 구형 카드 장착 → 정상. 기각.
  - 가설 1: 니들 클리닝 후 재테스트 → 변화 없음. 팁 높이 측정 정상. 기각.
  - 가설 2: 카드 전원 경로 저항 측정 → 해당 4개 사이트가 다른 사이트 대비 약 2배. 카드 제작 시 특정 층 비아 불량.
- 근본 원인: 프로브 카드 PCB 내부 전원 비아 결함으로 전원 경로 저항 증가 → 다이 단자 전압 강하 → Vmin over-kill.
- 조치: 카드 반품/수리. 입고 검사에 사이트별 전원 경로 저항 항목 추가.
- 재발 방지: 신규 카드 투입 시 골든 웨이퍼로 사이트별 수율 편차 검증을 필수화. 사이트별 Vmin 분포 자동 비교 알람.

### 케이스 5: NAND cycling 후 특정 층 block fail 증가

- 증상: 신뢰성 평가에서 P/E 사이클 목표치의 약 70% 지점부터 block fail(erase 실패 또는 RBER 한계 초과)이 기준 대비 급증.
- 1차 데이터: fail block의 fail page를 WL 층별로 집계 → 스택 중간 특정 층(예시: 채널 홀이 가장 좁아지는 하부 구간)에 집중. 초기(0 cycle) 상태에서는 해당 층 Vt 분포 폭이 다른 층보다 약간 넓었으나 스펙 내였음. cycling 후 해당 층의 erase Vt가 충분히 내려가지 않음.
- 가설 나열:
  1. 해당 층 채널 홀 CD가 작아 전계 집중 → 터널 산화막 열화 가속.
  2. 해당 층 터널 산화막 두께 편차(증착 단차 피복 불량).
  3. 해당 층 워드라인 저항 높아 erase 펄스 실효값 저하.
- 가설 검증:
  - 가설 3: WL 저항이면 tPROG도 층별로 차이 나야 하나 초기 tPROG는 정상. 기각.
  - 가설 1: 단면 TEM에서 해당 층 채널 홀 CD가 목표 대비 약 8% 작음. 곡률 증가로 전계 집중.
  - 가설 2: 터널 산화막 두께는 층별 편차 1 nm 미만으로 정상. 기각.
- 근본 원인: 채널 홀 HAR 식각 프로파일이 하부 특정 구간에서 좁아짐(테이퍼링) → 해당 층 셀의 전계 집중 → cycling 시 트랩 생성 가속 → erase 속도 저하 및 RBER 증가.
- 조치: 식각 레시피 프로파일 개선(하부 구간 식각 가스 비율 조정). 임시로 해당 층에 erase 펄스 보정(층별 erase verify 조건) 적용 검토.
- 재발 방지: 층별 초기 Vt 분포 폭을 EDS 관리 항목으로 추가하고, 층별 편차가 임계 넘으면 cycling 가속 평가로 연결. 채널 홀 CD 층별 프로파일 인라인 계측 강화.

> **[아이디어]** 3D NAND에서 층별 특성 편차는 불가피하다. 층별 read level과 program 조건을 다르게 주는 것은 이미 쓰이는 방식이며, 이를 더 나아가 EDS 시 층별 초기 특성을 측정해 다이별로 층별 보정값을 기록하는 방향이 논의 가능하다. 문제는 테스트 시간과 저장 공간. 층 그룹 단위 보정으로 절충하는 것이 현실적인 첫 단계다.

### 케이스 6: 웨이퍼 내 반복 좌표 fail(repeater)로 위장한 레이아웃 약점

- 증상: 신제품 초기 로트에서 여러 다이의 동일 서브어레이 위치에 SB fail이 반복. 웨이퍼 전체 다이의 약 40%에서 같은 물리 좌표.
- 1차 데이터: 다이 좌표를 겹친 stacked map에서 뚜렷한 핫스팟 1개. 레티클 필드 내 다이 위치(필드당 여러 다이)와 무관하게 모든 다이에서 동일 → 마스크 파티클이라면 필드 내 특정 다이에만 나와야 하므로 마스크 파티클은 아님. 상온·고온·저온 모두 fail, 데이터 패턴 의존성 있음(특정 인접 셀 값일 때만 fail).
- 가설 나열:
  1. 마스크 설계 데이터 자체 결함(OPC 오류로 특정 위치 패턴 약화).
  2. 레이아웃 약점(해당 위치의 셀 컨택트와 인접 라인 간 거리가 규칙 한계).
  3. 레티클 렌즈 국소 수차.
- 가설 검증:
  - 가설 3: 렌즈 수차라면 필드 내 위치에 따라 달라야 하는데 모든 다이 동일. 기각.
  - 가설 1 vs 2: 마스크 검사 결과 해당 위치 패턴은 설계 데이터와 일치. 설계 데이터에서 해당 위치를 보니 어레이 경계와 감지 증폭기 연결부의 특정 셀이 다른 셀보다 인접 라인과 거리가 약 10% 좁음. 리소 시뮬레이션에서 해당 위치의 공정 윈도우가 다른 셀보다 좁게 나옴. 가설 2 유력.
  - 물리 분석: 해당 위치 단면에서 셀 컨택트와 인접 비트라인 사이 절연막 두께가 다른 위치보다 얇음. 데이터 의존성(인접 값에 따라 커플링)과 일치.
- 근본 원인: 어레이 경계 셀의 레이아웃이 규칙 한계에 걸려 공정 편차 안에서도 커플링 마진이 부족. 마스크나 장비 문제가 아닌 설계-공정 상호작용.
- 조치: 다음 마스크 리비전에서 해당 위치 레이아웃 수정(간격 확보, 더미 조정). 리비전 전까지는 해당 좌표를 리페어 우선 배정하고 OPC 보정으로 마진 일부 회복.
- 재발 방지: 신제품 설계 검증 단계에서 어레이 경계 셀의 공정 윈도우 시뮬레이션을 필수화. stacked map 핫스팟이 마스크 필드 위치와 무관할 때 "레이아웃 약점" 후보를 자동 표시하는 룰 추가.

> **[면접]** "repeater fail을 봤을 때 마스크 문제인지 레이아웃 문제인지 어떻게 구분하나"를 묻는다면: 결론은 "레티클 필드 내 위치 의존성으로 가른다"이다. 근거로, 마스크 파티클은 마스크 위 한 점이므로 필드당 여러 다이가 있으면 특정 다이 위치에만 나온다. 레이아웃 약점은 모든 다이에 같은 위치로 나온다. 예로 필드당 4개 다이 중 1개 위치에만 반복되면 마스크, 4개 모두면 레이아웃이나 OPC다. 여기에 데이터 패턴 의존성이 있으면 커플링 마진 문제로 좁혀진다.

## 7. 응용·심화(최신 이슈)

### 7.1 HBM 테스트: KGSD와 스택 테스트

HBM은 DRAM 다이를 TSV로 수직 적층한다. 적층 후에는 개별 다이 접근이 어려워 적층 전 각 다이가 확실히 양품이어야 한다. 이를 KGSD(Known Good Stacked Die) 개념으로 부른다.

- 코어 다이(core die) EDS: TSV 연결 전, 마이크로 범프 패드에 프로브를 대야 한다. 범프 피치가 좁아(예시: 수십 μm) 프로브 카드 난도가 매우 높다. 일부는 별도 테스트 패드를 두거나 DFT(Design for Test) 회로로 내부 접근을 확보한다.
- TSV 테스트: TSV 오픈/쇼트/고저항을 적층 전에 확인해야 한다. 적층 후 발견하면 스택 전체(다이 8~16개)를 버린다. 회로적으로 TSV 양단을 루프백하거나 커패시턴스를 측정하는 기법을 쓴다.
- 적층 후 테스트: 베이스(로직) 다이를 통해 코어 다이에 접근한다. IEEE 1500 계열 테스트 래퍼, 내장 BIST(Built-In Self Test)로 각 다이 셀 어레이를 테스트한다. TSV 리페어(여분 TSV로 대체)도 이 단계에서.
- 수율의 곱셈 효과: 코어 다이 수율이 각 99%라도 12단이면 0.99^12 ≈ 88.6%. 여기에 적층 공정 수율을 곱한다. 그래서 다이 하나의 EDS 커버리지가 스택 수율에 지수적으로 영향을 준다.
- 열: 적층 내부 다이는 방열이 어려워 실사용 온도가 높다. EDS 온도 조건을 실사용 스택 내부 온도 기준으로 재설정할 필요가 있다.

> **[심화]** HBM에서 하이브리드 본딩(범프 없이 구리-구리 직접 접합)이 도입되면 본딩 후 접합 불량이 새 유형으로 등장한다. 본딩 계면 보이드, 미세 정렬 오차에 의한 고저항이 대표적이며, 이는 스택 후 전기 테스트에서 특정 TSV 채널의 타이밍 마진 저하로 나타난다. 적층 전 EDS는 이를 잡을 수 없으므로 스택 후 테스트 커버리지와 TSV 리던던시 설계가 더 중요해진다.

### 7.2 Row Hammer 대응과 테스트의 진화

공정 미세화로 셀 간 거리가 줄어 row hammer 취약성이 커졌다. 대응은 회로/프로토콜 차원에서 진행된다.

- TRR(Target Row Refresh): 자주 활성화되는 row를 감지해 이웃 row를 추가 리프레시.
- RFM(Refresh Management): 호스트가 활성화 횟수를 세어 임계 도달 시 리프레시 관리 명령을 발행.
- PRAC(Per Row Activation Counting): row마다 카운터를 두어 정확히 세는 방식.

테스트 관점 과제:

- 회로 검증: TRR/PRAC 로직이 실제로 동작하는지 기능 테스트 필요.
- 취약 셀 스크리닝: 어떤 활성화 횟수에서 플립이 시작되는지 다이별 분포를 알아야 한다. 전수 측정은 시간이 크므로 샘플 row 또는 가장 취약한 패턴만 측정.
- 패턴 다양화: single-sided, double-sided(양쪽 이웃 동시), many-sided 패턴이 취약성을 다르게 드러낸다.
- 온도 의존성: 고온에서 취약성이 변하므로 온도 조건도 고려.

### 7.3 온칩 ECC와 테스트의 관계

DDR5 등에서 온칩 ECC가 도입되었다. 이는 테스트와 수율에 다음 영향을 준다.

- 마스킹: ECC가 켜진 상태로 테스트하면 single bit fail이 정정되어 보이지 않는다. 그러면 공정 문제가 숨는다. 따라서 EDS 기능 테스트는 ECC를 끄고(테스트 모드) 원시 비트 오류를 봐야 한다.
- 수율 지렛대: ECC가 한 코드워드당 1비트를 정정할 수 있으면, 리페어하지 않아도 되는 single bit이 생긴다. 이를 수율 향상에 얼마나 쓸지는 정책 문제다. 너무 의지하면 필드에서 추가 비트 오류 발생 시 정정 한계를 넘어 UE(uncorrectable error)가 된다.
- 필드 관점: 고객이 보는 오류율은 ECC 후 값이다. 원시 오류율과 ECC 후 오류율을 함께 관리해야 잠재 위험을 볼 수 있다.

> **[주의]** "ECC가 있으니 single bit은 신경 안 써도 된다"는 것은 함정이다. ECC는 코드워드당 정정 능력이 한정된다. 공정에서 single bit 밀도가 오르면 같은 코드워드에 2비트가 걸리는 확률이 제곱으로 오른다. ECC는 마진이고, 공정 결함밀도 관리는 그대로 필요하다.

### 7.4 테스트 시간과 비용의 최신 접근

메모리 용량이 세대마다 2배씩 늘면 테스트 시간도 그대로 늘어난다. 이를 억제하는 접근:

- 병렬도 확대: 웨이퍼 전체 다이를 한 번에 접촉하는 풀 웨이퍼 컨택트 카드. 전원 공급과 열 관리가 병목.
- BIST/BISR(Built-In Self Repair): 다이 내부 회로가 스스로 패턴을 생성·비교하고 리페어까지 수행. 외부 테스터 대역폭 의존이 줄어든다. 단, BIST 회로 자체가 면적을 차지하고, BIST가 검출한 fail의 물리 주소를 외부로 꺼내 비트맵을 만드는 인터페이스가 필요하다.
- 적응형 테스트(adaptive test): 웨이퍼 초기 데이터(WAT, 일부 다이 결과)로 위험도를 예측해 위험한 웨이퍼/다이만 긴 테스트를 적용. 데이터 기반 의사결정.
- 테스트 항목 최적화: 각 항목의 unique fail 기여도를 통계로 산출해 기여도 낮은 항목은 샘플링으로 전환.
- 웨이퍼 레벨 번인(WLBI): 패키지 전 스트레스를 가해 조립 비용을 아낀다.

### 7.5 300단 이상 NAND의 테스트 과제

- 페이지 수 증가: 층수 × 스트링 수 × 플레인 수가 늘어 block당 페이지 수가 수천에 달한다. program/read 전수 테스트 시간이 비례 증가.
- 층별 편차: 채널 홀 상하부 CD 차, 계단 컨택트 저항 차로 층별 특성 편차가 커진다. 층별 read level, 층별 program 조건이 필수가 되고 테스트도 층별 통계를 관리해야 한다.
- 멀티 스택(2~3 tier) 접합부: 상하 스택을 이어 붙인 경계 층에서 채널 홀 정렬 오차와 계면 특성 불량이 나타난다. 경계 층 전용 테스트 항목이 필요하다.
- 셀 크기 축소와 QLC: 상태 간 간격이 더 좁아져 RBER 관리가 어렵고, cycling·retention 평가에서 마진이 급격히 준다. 온도 크로스(고온 program 후 저온 read 또는 반대) 조건이 중요해진다.
- 웨이퍼 본딩 구조(주변 회로와 셀 어레이를 별도 웨이퍼로 만들어 접합): 접합 전 각 웨이퍼 테스트, 접합 후 접합부 테스트가 추가된다.

### 7.6 데이터 기반 비트맵 분류

수동으로 비트맵을 보는 시대는 지났다. 웨이퍼당 수백 다이, 다이당 수십 종 패턴의 맵을 사람이 볼 수 없다.

- 규칙 기반 분류: row/column/cluster/repeater를 좌표 통계로 자동 분류. 기본이지만 규칙 유지가 부담.
- 이미지 분류 모델: 비트맵을 이미지로 보고 CNN 계열 모델로 시그니처를 분류. 새 시그니처 등장 시 재학습 필요.
- 인라인 데이터 결합: 비트맵 시그니처와 인라인 결함 검사 맵, 계측 맵, 장비 이력을 결합해 원인 공정을 확률로 추정. 이 결합이 PE의 트러블슈팅 시간을 크게 줄인다.
- 주의점: 모델이 "무엇"을 잘 맞추더라도 "왜"는 PE가 설명해야 한다. 물리적 인과를 이해하지 못한 분류는 새로운 공정 변화에서 쉽게 틀린다.

### 7.7 1c nm급 DRAM과 테스트 조건의 변화

- 셀 커패시터 커패시턴스가 세대마다 줄어 감지 마진이 좁아진다. tRCD 가드밴드 설정이 더 민감해지고, 감지 증폭기 오프셋에 의한 column 마진 문제가 늘어난다.
- 리텐션 tail 셀 비율이 늘어 온칩 ECC와 리페어 의존이 커진다. 리텐션 테스트 시간이 수율에 미치는 영향이 커진다.
- 저온 조건의 중요성: 셀 트랜지스터 크기가 작아지고 Vt 편차가 커져 저온 tWR fail이 늘어난다. 저온 EDS 비중이 커지는 경향.
- 고속 인터페이스(수 Gbps 이상)의 EDS 커버리지 한계가 뚜렷해져, 루프백 기반 자체 테스트나 FT 의존이 늘어난다.

> **[면접]** "PE로서 테스트 항목을 하나 추가하거나 빼야 한다면 어떤 기준으로 판단하겠나"를 묻는다면: 결론은 "그 항목의 unique fail 기여도, 필드 불량 예방 효과, 테스트 시간 비용을 정량 비교한다"이다. 근거로, 기존 항목이 이미 잡는 fail을 중복 검출하는 항목은 시간만 든다. 예로 새 패턴이 웨이퍼당 unique fail을 다이 1개 이하만 추가 검출하고 시간이 5% 늘면 빼는 쪽이 맞지만, 필드 DPPM 데이터에서 그 메커니즘이 주요 반품 원인이면 남긴다. 마지막으로 "결정 후에도 샘플링으로 모니터링을 남겨 판단이 틀렸을 때 되돌릴 수 있게 한다"고 닫는다.

## 8. 셀프 체크 질문

### 개념(5)

1. WAT/PCM, EDS, FT, SLT의 차이를 대상과 목적 중심으로 설명하라.
- 답: WAT/PCM은 스크라이브 라인 TEG로 공정 파라미터(Vt, Rs, 컨택트 저항)가 맞게 됐는지 보는 공정 검수이며 다이를 보지 않는다. EDS는 웨이퍼 상태에서 각 다이 셀 전체를 읽고 써서 양불을 가르고 리페어하며 비트맵을 만든다. FT는 패키지 후 최종 스펙과 속도 등급을 보증하고, 조립 유발 불량과 고속 특성을 잡는다. SLT는 실제 시스템 조건에서 컨트롤러 상호작용까지 검증한다. 뒤로 갈수록 검출 비용은 대략 10배씩 커지므로 가능한 한 앞에서 잡는 것이 원칙이다.

2. 프로브 카드의 역할과 관리 항목을 설명하라.
- 답: 프로브 카드는 테스터와 웨이퍼 패드를 연결하는 수천~수만 개 니들의 인터페이스다. 접촉 저항(수 Ω 이하), 접촉 힘(니들당 수 gf), 오버드라이브(수십 μm), 평탄도(±10 μm대)가 핵심 사양이다. 관리 항목은 니들 팁 클리닝 주기, 평탄도/정렬 측정, 컨택트 fail율 추세, 프로브 마크 검사다. 접촉 저항이 수 Ω에서 수십 Ω으로 오르면 전원 강하로 정상 다이가 Vmin fail로 오판된다. 메모리용 MEMS 카드는 고병렬 고핀수로 비용이 매우 크며 터치다운 횟수 기준 수명을 관리한다.

3. 비트맵 시그니처 여섯 가지(single bit, row, column, block, cluster, repeater)를 각각 정의하고 대표 원인을 말하라.
- 답: single bit는 한 셀만 무작위로 fail하며 셀 누설, 접합 결함, 랜덤 파티클이 원인이다. row fail은 워드라인 전체로 WL 오픈/쇼트나 드라이버 불량, column fail은 비트라인 전체로 BL 오픈/쇼트나 감지 증폭기 불량이다. block fail은 서브어레이 단위로 로컬 전원/디코더 불량이나 큰 파티클이다. cluster는 국소 영역에 SB가 뭉친 것으로 파티클, CMP 스크래치, 디포커스가 원인이다. repeater는 여러 다이에서 같은 좌표가 fail하는 것으로 마스크 결함이나 레이아웃 약점을 가리킨다. 논리 주소를 물리 좌표로 변환한 뒤 분류해야 한다.

4. 리던던시와 리페어가 수율에 기여하는 방식을 예시와 함께 설명하라.
- 답: 설계 시 여분 row/column(DRAM) 또는 여분 block/column(NAND)을 넣고, EDS에서 수집한 fail 주소를 퓨즈(레이저 또는 e-fuse/anti-fuse)로 여분에 매핑한다. 예로 다이에 SB 30개가 여러 서브어레이에 퍼져 있으면 서브어레이당 여분 4개로 모두 덮이지만, 한 곳에 30개가 몰리면 unrepairable이다. 즉 fail 수뿐 아니라 분포가 수율을 결정한다. 공정 품질은 pre-repair 비트 수로, 사업 지표는 post-repair 수율로 따로 관리한다. 출하 후에도 PPR로 row 단위 리페어가 가능한 세대가 있다.

5. 수율과 DPPM의 정의와 둘의 관계를 설명하라.
- 답: 수율은 만든 다이 중 양품 비율로 Y = exp(−D0·A)(포아송) 또는 음이항 모델로 결함밀도와 다이 면적에 연결된다. 예로 D0 0.3/cm², A 0.6 cm²면 약 83%. DPPM은 출하 100만 개당 고객 불량 수로, 1,000만 개 출하에 50개 불량이면 5 DPPM이다. 둘은 상충한다. 테스트를 엄격히 하면 수율이 떨어지고 DPPM이 좋아진다. PE는 over-kill 비용과 필드 불량 비용을 비교해 가드밴드와 스크리닝 강도의 최적점을 데이터로 정한다.

### 응용(5)

6. 고온 EDS와 저온 EDS에서 각각 어떤 DRAM 불량이 드러나며, 왜 그런가.
- 답: 고온(85~95 °C)에서는 누설이 지수적으로 커져 리텐션 fail과 IDD 초과가 드러난다. 리텐션은 10 °C에 대략 절반이므로 상온 1초인 셀이 85 °C에서 수십 ms로 준다. 저온(−10~−40 °C)에서는 셀 트랜지스터 Vt가 올라 쓰기 시 전하가 충분히 안 들어가 tWR fail, 그리고 컨택트 저항 특성 변화로 타이밍 fail이 드러난다. 두 메커니즘의 온도 의존성이 반대이므로 한 온도만 하면 다른 쪽 불량이 고객으로 간다. 리페어도 온도별 fail을 합쳐 수행한다.

7. tRCD fail과 tWR fail의 비율 변화로 공정 원인을 1차 분류하는 방법을 설명하라.
- 답: 둘은 같은 셀-비트라인 경로지만 전하 방향이 반대다. tWR만 나빠지면 셀 트랜지스터 Vt 상승(쓰기 구동 부족)이 유력하고 저온에서 악화된다. tRCD와 tWR이 함께 나빠지면 비트라인 컨택트 저항이나 워드라인 저항 증가(RC 지연)를 의심하며 WAT 컨택트 체인 저항과 대조한다. tRCD만 나빠지고 리텐션도 함께 나쁘면 셀 커패시턴스 감소(유전막 두께 증가, 면적 축소)를 의심한다. 이후 저온 shmoo, WAT, 단면 분석으로 확정한다.

8. 웨이퍼 에지 링 형태로 column fail이 몰리면 어떤 순서로 원인을 좁히겠나.
- 답: 먼저 테스트 문제를 배제한다. 다른 카드/사이트로 재테스트해 같은 다이가 fail하는지 본다. 다음으로 온도 의존성을 확인해 저항형(온도 무관 또는 저온 악화)인지 누설형인지 가른다. column fail이면 비트라인, BL 컨택트, 감지 증폭기가 후보이므로 WAT 컨택트 체인 저항과 메탈 Rs의 반경 프로파일을 대조한다. 에지에서 컨택트 저항만 높으면 컨택트 식각 에지 부족을 의심하고, 해당 로트들의 식각 챔버 이력을 교차해 특정 챔버로 좁힌 뒤 단면 TEM으로 잔류물을 확정한다.

9. 번인과 전압 스트레스의 원리와 조건 설정 기준을 설명하라.
- 답: 둘 다 잠재 불량을 출하 전에 강제로 드러내는 스크리닝이다. 번인은 고온(예시 125 °C)과 정격 대비 10~30% 높은 전압으로 수 시간~수십 시간 가해 아레니우스와 전압 가속을 이용하며, Ea 0.7 eV 기준 55 °C 사용 대비 수십 배 온도 가속에 전압 가속을 곱해 수백 배가 된다. 전압 스트레스는 EDS 중 짧게 고전압을 가해 유전막 약점을 조기 브레이크다운시켜 리페어 대상으로 만든다. 조건은 잠재 불량 검출 곡선과 양품 손상 곡선이 교차하기 전 지점으로 잡고, 스트레스 후 신뢰성 샘플로 양품 손상이 없는지 검증한다.

10. NAND EDS에서 retention bake와 cycling을 어떻게 수행하고 무엇을 보는가.
- 답: cycling은 P/E를 반복(TLC 수천 회 수준 목표)하며 RBER, tPROG, tBERS 변화를 본다. 터널 산화막 트랩 축적으로 erase가 느려지고 Vt 분포가 넓어져 ECC 한계에 닿는 사이클이 endurance다. retention bake는 program 후 고온(85~125 °C)에서 수 시간~수십 시간 방치해 상온 수년의 charge loss를 모사하며, cycling 후 bake가 더 심하다. 전수는 시간상 불가능하므로 EDS에서는 샘플 block 가속 평가와 초기 Vt 분포 폭, 초기 bad block 수, ISPP 루프 수를 전수 관리하고, 그 편차가 큰 다이를 신뢰성 평가로 연결한다.

### 심화(5)

11. VRT(Variable Retention Time)가 테스트 커버리지에 주는 문제와 대책을 설명하라.
- 답: VRT는 같은 셀의 리텐션 시간이 두 상태 사이를 무작위로 오가는 현상으로, 계면 트랩이 전하를 잡고 놓으며 누설 경로가 켜지고 꺼지는 것으로 해석된다. EDS 측정 순간 좋은 상태면 pass하고, FT나 고객에서 나쁜 상태로 바뀌어 fail한다. 즉 시간 축 커버리지 구멍이다. 대책은 리텐션 측정을 시간 간격을 두고 2회 이상 반복해 한 번이라도 fail이면 리페어하고, 온칩 ECC와 PPR로 시스템에서 흡수하며, VRT 발생률을 공정 변경 평가의 필수 항목으로 두는 것이다. FT-EDS 비트 단위 상관 체계가 있어야 이런 구멍을 정량화할 수 있다.

12. HBM에서 개별 다이 EDS 커버리지가 왜 지수적으로 중요하며, TSV 테스트는 어떻게 하는가.
- 답: HBM은 다이를 8~16단 적층하므로 스택 수율은 다이 수율의 거듭제곱이다. 다이 수율 99%라도 12단이면 약 88.6%가 되고, 적층 후 발견된 다이 불량 하나가 스택 전체를 버리게 한다. 그래서 적층 전 KGSD 확보가 핵심이다. TSV는 적층 전 오픈/쇼트/고저항을 루프백 회로나 커패시턴스 측정으로 검사하고 여분 TSV로 리페어한다. 적층 후에는 베이스 다이를 통해 IEEE 1500 계열 래퍼와 BIST로 각 다이에 접근한다. 마이크로 범프 피치가 좁아 프로브 카드 난도가 높고, 스택 내부 온도가 높아 EDS 온도 조건도 실사용 기준으로 재설정해야 한다.

13. 온칩 ECC가 있는 DRAM에서 EDS 테스트와 수율 정책을 어떻게 설계해야 하나.
- 답: 기능 테스트는 ECC를 끈 테스트 모드로 원시 비트 오류를 봐야 공정 문제가 마스킹되지 않는다. 수율 정책은 ECC 정정 능력 일부를 single bit 미리페어에 쓰되, 필드에서 추가 비트가 발생할 여지를 남겨야 한다. 공정 SB 밀도가 오르면 같은 코드워드에 2비트가 걸릴 확률이 제곱으로 오르므로 결함밀도 관리는 그대로 필요하다. 원시 오류율과 ECC 후 오류율을 함께 관리하고, 필드 UE(정정 불가 오류) 데이터를 EDS 정책에 역반영한다. ECC는 마진이지 공정 품질의 대체가 아니다.

14. 테스트 시간을 20% 줄이라는 과제를 받았다. PE로서 접근 방법을 정량적으로 설명하라.
- 답: 먼저 시간 구조를 분해한다. 총 시간은 항목별 테스트 시간 × 터치다운 수 + 인덱스 시간 × 터치다운 수 + 온도 안정화다. 다음으로 항목별 unique fail 기여도를 산출해 다른 항목이 이미 잡는 fail만 중복 검출하는 항목을 샘플링으로 전환한다. 리텐션 대기 시간은 분포 tail을 보고 가드밴드를 재산정한다. 병렬도를 높이면 터치다운 수가 줄지만 전원 노이즈와 사이트 편차를 검증해야 한다. 적응형 테스트로 WAT와 초기 다이 결과가 좋은 웨이퍼에 짧은 플로우를 적용한다. 각 조치는 FT fail율과 필드 DPPM 변화를 사후 모니터링해 커버리지 손실이 없음을 확인한 뒤 확정한다.

15. 비트맵 시그니처를 공정 층에 매핑할 때 흔한 오판과 그것을 피하는 방법을 설명하라.
- 답: 첫째, 논리 주소를 물리 좌표로 변환하지 않고 맵을 읽는 오판이다. 주소 스크램블 때문에 논리 row 연속이 물리 연속이 아니다. 둘째, 테스트 유발 불량(사이트 편차, 접촉 저항)을 공정 불량으로 보는 오판이며, 카드/사이트 교체 재테스트로 배제한다. 셋째, 같은 시그니처를 한 원인으로 단정하는 오판이다. row fail은 WL 오픈, WL 드라이버, 게이트 컨택트 모두 가능하므로 온도/전압 의존성, WAT, 인라인 계측, 장비 이력 중 2개 이상 독립 데이터로 교차 확인해야 한다. 마지막으로 물리 분석(FA)으로 확정한 뒤에만 공정을 건드린다.

16. Row hammer 취약성을 EDS에서 어떻게 평가하고, 공정 변수와 어떻게 연결되나.
- 답: 특정 row를 리프레시 주기 내에 수만~수십만 회 활성화한 뒤 이웃 row를 읽어 플립 비트 수와 플립 시작 횟수를 측정한다. single/double/many-sided 패턴과 온도 조건을 달리 해 최악 조건을 찾는다. 전수는 시간상 어려워 샘플 row 또는 취약 패턴만 측정하고 TRR/PRAC 회로의 동작 여부는 기능 테스트로 확인한다. 공정 측면에서는 워드라인 간격 축소, 셀 간 커플링 증가, 워드라인 스위칭 시 전하 주입이 취약성을 높이므로 WL 피치, 격리 구조, 게이트 산화막 조건 변경 시 hammer 평가를 함께 해야 한다.

## 9. 한 페이지 요약

| 항목 | 핵심 |
|---|---|
| 테스트 단계 | WAT/PCM(공정 파라미터, TEG) → EDS(다이 양불, 리페어, 비트맵) → FT(패키지 스펙, 속도 bin) → SLT(시스템 검증). 검출 비용은 뒤로 갈수록 약 10배씩 |
| 프로브 카드 | 캔틸레버/버티컬/MEMS. 접촉 저항 수 Ω, 힘 수 gf, 오버드라이브 수십 μm, 평탄도 ±10 μm대. 접촉 저항 상승은 Vmin over-kill로 나타남 |
| 온도 | 고온(85~95 °C)은 누설·리텐션, 저온(−10~−40 °C)은 Vt 상승·타이밍(tWR). 메커니즘의 온도 의존성이 반대라 둘 다 필요 |
| DRAM 항목 | function(패턴), retention(대기 후 읽기, 10 °C에 절반), tRCD/tWR 가드밴드, row hammer(반복 활성화), IDD, Vmin |
| NAND 항목 | P/E 동작·시간, 초기 bad block, read window(Vt 분포), RBER, cycling(트랩 축적), retention bake(고온 가속 charge loss) |
| 비트맵 시그니처 | SB(셀 누설·파티클), row(WL), column(BL·SA), paired(브리지), block(로컬 회로·큰 결함), cluster(국소 공정), repeater(마스크), edge ring/radial(장비 균일도), scratch(CMP·핸들링) |
| 매핑 원칙 | 논리→물리 좌표 변환 → 시그니처 분류 → 온도/전압 의존성 → WAT·인라인·장비 이력 교차 → FA 확정. 독립 데이터 2개 이상 |
| 테스트 불량 배제 | 카드/사이트 교체 재테스트, 컨택트 저항 로그, 사이트 상관. 공정보다 먼저 확인 |
| 리페어 | 여분 row/col(block)을 퓨즈로 매핑. fail 수보다 분포가 수율 결정. pre-repair(공정 품질)와 post-repair(사업) 분리 관리. PPR은 필드 보완 |
| 스크리닝 | 번인(고온·고전압, 아레니우스+전압 가속 수백 배), 전압 스트레스(유전막 약점 조기 파괴). 검출 곡선과 양품 손상 곡선 교차 전에 조건 설정 |
| 수율·DPPM | Y = exp(−D0·A) 또는 음이항. DPPM = 불량/출하 × 10^6. 상충 관계, over-kill vs escape의 최적점을 데이터로 |
| 커버리지 구멍 | 시간 축(VRT, 잠재 신뢰성), 조건 축(온도·전압·속도·패턴), 시점 축(조립 후). 축별로 대책 다름(반복 측정·스크리닝 / 조건 확대·가드밴드 / 후공정·PPR·ECC) |
| 최신 이슈 | HBM KGSD·TSV 테스트·스택 수율 거듭제곱, row hammer 대응(TRR/RFM/PRAC), 온칩 ECC 마스킹, BIST/적응형 테스트, 300단+ NAND 층별 편차, 데이터 기반 맵 분류 |
| PE의 역할 | 테스트 조건을 설계 변수로 다루고, 비트맵을 공정 언어로 번역하며, 수율과 DPPM의 교환 비율을 정량화해 결정한다 |
