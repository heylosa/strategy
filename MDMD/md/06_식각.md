# 06. 식각 공정

## 1. 한눈에 보기

### 1.1 왜 PE에게 중요한가

- 식각(Etch)은 리소그래피가 그린 패턴을 실제 물질에 "새기는" 단계다. CD(Critical Dimension), 프로파일, 깊이가 여기서 최종 결정되므로 전기적 특성(Vt, Ion, Cs, 저항)의 산포 절반 이상이 식각에서 나온다.
- DRAM 커패시터 홀(종횡비 50:1 이상)과 NAND 채널 홀(100:1 이상)은 반도체 공정 중 가장 어려운 고종횡비(HAR, High Aspect Ratio) 식각이며, 여기서 발생하는 bowing/twisting/미개구가 곧 셀 불량(single bit fail, 브리지, 오픈)이 된다.
- 플라즈마 식각은 웨이퍼에 이온·UV·전하를 쏟아부으므로 소자 손상(plasma damage)이 생긴다. Ioff 증가, GOI(Gate Oxide Integrity) 저하, retention 열화처럼 "식각 장비에서 시작해 제품 신뢰성으로 끝나는" 불량 사슬을 PE가 추적해야 한다.
- 식각은 챔버 상태(폴리머 축적, 부품 소모)에 따라 드리프트가 심하다. PE는 웨이퍼 맵(센터-에지, 노치 방향), 로트 추이, 챔버별 차이를 전기 데이터와 연결해 원인을 좁혀야 한다.
- A!SK/면접에서 "이방성 식각의 원리", "선택비와 마스크 소모", "HAR 식각의 어려움", "플라즈마 데미지가 소자에 미치는 영향"은 거의 빠지지 않는 단골 문항이다.

### 1.2 핵심 키워드

| 용어 | 한 줄 정의 |
|---|---|
| 이방성(Anisotropy) | 수직 방향 식각 속도가 수평보다 훨씬 큰 성질. 1 − (수평 속도/수직 속도)로 정의 |
| 선택비(Selectivity) | 목표 물질 식각 속도 / 마스크(또는 하부막) 식각 속도. 예: 산화막 대 포토레지스트 5:1 |
| RIE(Reactive Ion Etching) | 화학 반응(라디칼)과 물리 충격(이온)을 결합한 플라즈마 식각의 총칭 |
| CCP / ICP | 용량 결합(Capacitively Coupled)과 유도 결합(Inductively Coupled) 플라즈마 소스 방식 |
| 소스 파워 / 바이어스 파워 | 플라즈마 밀도(라디칼·이온 양)와 이온 에너지(가속 전압)를 각각 독립 제어하는 두 파워 |
| 시스(Sheath) | 플라즈마와 웨이퍼 사이 얇은 전위 강하층. 이온을 수직 가속시켜 이방성의 근원이 됨 |
| 종횡비(Aspect Ratio) | 깊이/폭. DRAM 커패시터 홀 50~100:1, NAND 채널 홀 100:1 이상 |
| ARDE | Aspect Ratio Dependent Etching. 종횡비가 클수록 식각 속도가 느려지는 현상(RIE lag) |
| Microloading | 패턴 밀도에 따라 국부적으로 식각 속도가 달라지는 현상 |
| Bowing | 홀/트렌치 측벽이 중간 부분에서 바깥으로 불룩해지는 프로파일 불량 |
| Notching | 절연막 위에서 식각이 멈출 때 하부 계면에서 옆으로 파이는 국부 식각 |
| Charging damage | 플라즈마 전하 불균일로 게이트 산화막에 전류가 흘러 손상되는 현상 |
| Striation | 측벽에 세로 줄무늬가 생기는 거칠기 불량. 마스크 LER이 전사된 것 |
| Twisting | HAR 홀 하부가 비틀려 옆 홀과 정렬이 어긋나는 현상 |
| Etch stop | 의도한 깊이에서 식각을 멈추게 하는 하부막, 또는 식각이 도중에 멈춰버리는 불량 |
| Ash / Strip | 식각 후 남은 포토레지스트를 산소 플라즈마나 습식으로 제거하는 공정 |
| OCD(Optical CD) | 산란광 분석으로 CD·프로파일·깊이를 비파괴 계측하는 광학 기법 |

## 2. 기초

### 2.1 식각이란 무엇인가

식각은 마스크(포토레지스트나 하드마스크)로 가려지지 않은 부분의 물질을 선택적으로 제거하는 공정이다. 리소그래피가 "어디를 파낼지"를 정하면, 식각은 "얼마나 깊이, 어떤 모양으로" 파낸다. 최종 CD와 프로파일은 식각이 결정한다.

식각의 3대 성능 지표는 다음과 같다.

| 지표 | 정의 | 목표 예시 |
|---|---|---|
| 식각 속도(Etch Rate) | 단위 시간당 제거 두께 | 산화막 300~800 nm/min(HAR은 훨씬 느림) |
| 이방성 | 수직/수평 식각 비 | 트렌치 측벽 각도 88~90° |
| 선택비 | 목표막/마스크 또는 목표막/하부막 속도 비 | 산화막:질화막 10:1 이상 |
| 균일도 | 웨이퍼 내(WIW), 웨이퍼 간(WTW) 속도 편차 | 3σ 2~3% 이내 |
| CD 바이어스 | 식각 후 CD − 마스크 CD | ±1 nm 수준 관리 |

> **[핵심]** 식각은 "속도, 이방성, 선택비, 균일도" 네 가지가 서로 상충한다. 이온 에너지를 올려 이방성을 확보하면 선택비가 떨어지고 마스크가 빨리 소모된다. 이 트레이드오프를 어디에서 타협했는지가 레시피의 본질이다.

### 2.2 습식 식각 vs 건식 식각

습식 식각(Wet Etch)은 용액 속에서 화학 반응으로 물질을 녹여 낸다. 건식 식각(Dry Etch)은 플라즈마에서 생성된 라디칼·이온으로 제거한다.

| 항목 | 습식 식각 | 건식(플라즈마) 식각 |
|---|---|---|
| 메커니즘 | 순수 화학 반응 | 화학(라디칼) + 물리(이온 충격) |
| 방향성 | 등방성(단결정 Si의 KOH 등 예외) | 이방성 제어 가능 |
| 선택비 | 매우 높음(100:1 이상 흔함) | 보통 5~50:1 |
| CD 제어 | 나쁨(언더컷 발생) | 좋음(nm 수준) |
| 손상 | 거의 없음 | 이온·UV·전하 손상 |
| 처리량 | 배치 처리 가능, 높음 | 단일 웨이퍼, 상대적으로 낮음 |
| 주 용도 | 막 제거(blanket), 세정, 희생막 제거, 언더컷 의도 공정 | 패턴 형성 전부 |

> **[예시]** 폭 20 nm 트렌치를 깊이 100 nm로 습식 식각하면 옆으로도 100 nm 파이므로 패턴이 사라진다. 그래서 패턴 형성은 건식이 필수다. 반대로 DRAM 커패시터 형성 후 몰드 산화막을 통째로 제거할 때는 높은 선택비(산화막:질화막 100:1 이상)를 위해 습식 HF 계열을 쓴다.

### 2.3 플라즈마 기초

플라즈마는 전기장으로 가스를 부분 이온화한 상태다. 전자, 양이온, 중성 라디칼, 중성 분자가 섞여 있다. 저압(수 mTorr~수백 mTorr) 공정 플라즈마의 특징은 다음과 같다.

- 이온화율은 매우 낮다(10⁻⁶~10⁻⁴). 대부분은 중성 분자다.
- 전자 온도(T_e)는 2~5 eV(약 2~6만 K)로 뜨겁지만, 이온과 중성 입자는 상온에 가깝다(비평형 플라즈마).
- 전자가 가벼워 빠르게 벽으로 빠지므로, 플라즈마 본체는 벽(웨이퍼)보다 양전위가 된다. 이 전위 차가 시스(sheath)에 집중된다.

```text
   플라즈마 본체 (V_p, 준중성, 전위 거의 균일)
   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
        |  시스 (sheath, 두께 수십 um ~ mm)
        |  전기장 E 수직 방향 -> 이온을 수직 가속
        v  이온 에너지 = e * (V_p - V_wafer) ~ 수십 ~ 수천 eV
   ==================================================  웨이퍼
```

시스에서 이온은 웨이퍼 표면에 거의 수직으로 입사한다. 이것이 이방성 식각의 물리적 뿌리다. 중성 라디칼은 전하가 없어 방향성 없이 확산하므로 등방성 화학 식각을 유발한다.

### 2.4 식각 메커니즘 4가지

| 메커니즘 | 원리 | 특징 | 예 |
|---|---|---|---|
| 화학적 식각 | 라디칼이 표면과 반응해 휘발성 생성물 형성 | 등방성, 선택비 높음, 손상 적음 | F 라디칼 + Si → SiF₄ |
| 물리적 스퍼터링 | 이온 운동에너지로 원자를 튕겨냄 | 이방성, 선택비 매우 낮음, 손상 큼 | Ar⁺ 스퍼터 |
| 이온 유도 식각 | 이온 충격이 화학 반응을 촉진(시너지) | 이방성 + 적당한 선택비 | Cl₂/Ar⁺ Si 식각 |
| 이온 억제제 식각 | 측벽에 폴리머 보호막이 붙고 바닥만 이온이 제거 | 강한 이방성 | CF 폴리머 측벽 보호 |

이온 유도 식각의 시너지는 Coburn-Winters 실험(1979)으로 유명하다. XeF₂ 가스만으로는 Si 식각 속도가 매우 느리고 Ar⁺ 이온만으로도 느리지만, 둘을 동시에 가하면 속도가 10배 이상 뛴다. 이온 충격이 표면 결합을 깨고 반응 생성물 탈착을 촉진하기 때문이다.

> **[핵심]** 실제 이방성 식각 = "바닥은 이온이 두들겨 반응을 촉진하고, 측벽은 이온이 닿지 않는데다 폴리머 보호막이 덮여 화학 식각이 억제된다." 측벽 보호막(passivation)이 얇으면 bowing, 두꺼우면 taper가 된다.

### 2.5 식각 가스 화학의 기본

| 대상 물질 | 주 가스 | 반응 생성물 | 비고 |
|---|---|---|---|
| Si (poly, 단결정) | Cl₂, HBr, SF₆, CF₄, NF₃ | SiCl₄, SiBr₄, SiF₄ | HBr은 산화막 대비 선택비 우수 |
| SiO₂ | CF₄, CHF₃, C₄F₈, C₄F₆ + O₂/Ar | SiF₄, CO, CO₂ | C/F 비율이 폴리머 형성 조절 |
| Si₃N₄ | CH₂F₂, CHF₃, CH₃F, SF₆ | SiF₄, N₂, HCN | H 함유 가스로 산화막 대비 선택비 확보 |
| 금속(W, TiN) | SF₆, Cl₂, BCl₃ | WF₆, TiCl₄ | Cu는 휘발성 생성물이 없어 건식 곤란 |
| 포토레지스트/탄소 하드마스크 | O₂, N₂/H₂, CO₂ | CO, CO₂, H₂O | ash |
| Al | Cl₂, BCl₃ | AlCl₃ | 식각 후 부식(corrosion) 주의 |
| 고유전체(HfO₂, ZrO₂) | BCl₃, Cl₂ | 휘발성 낮음 | 물리적 성분 강함, 선택비 어려움 |

산화막 식각에서 C/F 비율이 핵심이다. F가 많으면(CF₄) 식각이 빠르고 폴리머가 적어 등방성으로 흐른다. C가 많으면(C₄F₈, C₄F₆) 측벽에 CF_x 폴리머가 두껍게 쌓여 이방성과 마스크 선택비가 오르지만 식각 속도가 느려지고 식각 정지(etch stop) 위험이 커진다. O₂를 조금 넣으면 폴리머를 태워 속도를 회복하고, H₂를 넣으면 F를 HF로 소모해 폴리머를 늘린다.

### 2.6 이방성과 프로파일의 정량화

```text
   마스크        마스크              마스크
   +----+        +----+              +----+
   |    |        |    |              |    |
   |    |  88-90  \    \   85 taper  /    /   >90 reverse
   |    |          \    \           /    /    taper (bowing)
   +----+           +----+         +----+
   vertical         taper(positive) reverse taper
```

- 측벽 각도 θ = 90°이면 완전 이방성. 88~90°를 일반적으로 "수직"이라 부른다.
- 종횡비 50:1 홀에서 측벽 각도가 89°에서 88.5°로 0.5° 기울면, 깊이 2 μm 기준 바닥 CD가 약 17 nm 더 작아진다(2000 nm × tan(0.5°) × 2). 바닥 CD 40 nm 목표라면 절반 가까이 사라지는 수준이다.
- 따라서 HAR 식각에서는 각도 0.1° 단위가 의미 있다.

> **[예시]** DRAM 커패시터 홀: 상부 CD 45 nm, 깊이 1.5 μm, 목표 바닥 CD 35 nm라면 요구되는 측벽 각도는 약 89.8°다. 이 정도면 "수직"이란 말보다 "각도 0.2° 이내"라는 관리 규격이 더 정확하다.

### 2.7 선택비와 마스크 예산

선택비 S = 목표막 식각 속도 / 마스크 식각 속도. 마스크 두께 예산은 다음처럼 계산한다.

- 목표 식각 깊이 D, 오버에치(over-etch) 여유 20%라면 실제 식각량은 1.2 D.
- 필요한 마스크 최소 두께 = 1.2 D / S + 여유(패싯, 코너 라운딩 고려 20~30%).
- 예: D = 2 μm 산화막, 탄소 하드마스크(ACL, Amorphous Carbon Layer) 선택비 15:1이면 마스크 소모 160 nm, 여유 포함 약 200~250 nm 필요. 실제 HAR 식각에서는 마스크 상부 패싯(facet) 때문에 이보다 두껍게 잡는다.

하부막 선택비도 중요하다. 식각이 하부 etch stop 막(예: 질화막)에 도달하면 웨이퍼 내 속도 편차와 오버에치 시간 동안 하부막이 깎인다. 선택비가 10:1이고 오버에치가 목표 깊이의 20%(예: 200 nm 상당 시간)면 하부막은 약 20 nm 손실된다. 하부막이 게이트 산화막이거나 얇은 라이너라면 치명적이다.

> **[주의]** 선택비는 "평지" 값과 "홀 바닥" 값이 다르다. HAR 홀 바닥에는 라디칼이 적게 도달하고 이온 에너지 성분이 상대적으로 크므로 하부막 선택비가 평지 측정치보다 나빠진다. 평지 블랭킷 웨이퍼로 잰 선택비 20:1을 믿고 오버에치를 설계하면 실제 홀 바닥에서는 하부막이 예상보다 2~3배 깎이는 일이 흔하다.

### 2.8 오버에치와 종점 검출의 필요성

식각 속도는 웨이퍼 내에서 ±2~3%, 패턴 밀도에 따라 ±5~10% 차이가 난다. 가장 느린 지점까지 식각을 끝내려면 평균 지점 기준으로 추가 식각(오버에치)이 필요하다.

- 예: 평균 식각 시간 100초, WIW 편차 3%, 마이크로로딩 편차 7%면 가장 느린 지점은 약 110초에 도달한다. 여기에 안전 여유 10%를 더해 120초, 즉 20% 오버에치를 건다.
- 그 20% 동안 먼저 뚫린 지점에서는 하부막이 노출되어 깎인다. 그래서 하부막 선택비와 오버에치는 항상 함께 설계한다.
- 종점 검출(EPD): OES로 특정 파장(예: CO 483 nm, SiF 440 nm, N₂ 337 nm)의 세기 변화를 감시해 하부막 도달 시점을 잡는다. 오픈 면적이 1% 미만인 컨택 식각은 시그널이 약해 EPD가 어렵고 시간 식각에 의존한다.

```text
  OES 세기
    ^
    |  ----------\           <- 목표막 식각 중 (SiF 발광 일정)
    |             \
    |              \_________ <- 하부막 노출, 생성물 변화 (종점)
    |              ^
    +--------------|---------> 시간
                 EPD 트리거 -> 이후 오버에치 스텝 진입
```

### 2.9 식각 결과가 소자에 보이는 경로

식각 결과는 네 가지 경로로 전기 특성에 나타난다.

| 경로 | 물리량 | 대표 전기 특성 | 예시 |
|---|---|---|---|
| 치수(CD, 깊이) | 채널 길이·폭, 전극 면적, 컨택 면적 | Vt, Ion, Cs, 접촉 저항 | 게이트 CD −2 nm → Vt −20~40 mV |
| 형상(프로파일) | 코너 곡률, 측벽 각도 | 전계 집중 → 누설, GIDL, 브리지 | 각진 트렌치 바닥 → GIDL 증가 |
| 잔막·잔사 | 계면 절연층, 폴리머 | 컨택 오픈, 고저항 | 바닥 폴리머 1~2 nm → Rc 수 배 |
| 손상 | 비정질층, 산화막 트랩, 계면 상태 | Vt shift, Ioff, SS, GOI, NBTI | charging → 안테나 비례 Vt shift |

이 네 경로를 항상 머리에 두면 "전기 데이터 → 어떤 식각 결과가 흔들렸나"를 거꾸로 추적할 수 있다.

## 3. 공정/기술 상세

### 3.1 플라즈마 식각 장비 비교

| 방식 | 플라즈마 생성 | 이온 밀도 | 이온 에너지 제어 | 압력 범위 | 주 용도 |
|---|---|---|---|---|---|
| CCP (2주파 이상) | 평행판 전극 사이 RF 전압 | 10⁹~10¹⁰ cm⁻³ | 저주파(2~13 MHz) 바이어스로 독립 제어 | 10~200 mTorr | 산화막/질화막 유전체 식각, HAR |
| ICP (TCP) | 코일에 RF 전류 → 유도 전기장 | 10¹¹~10¹² cm⁻³ | 별도 바이어스 RF로 독립 | 2~50 mTorr | Si, 금속, 게이트, 도전막 |
| ECR / 마이크로파 | 마이크로파 + 자기장 공명 | 10¹¹~10¹² cm⁻³ | 별도 바이어스 | 1~10 mTorr | 저손상, 일부 특수 |
| 원격 플라즈마(Remote) | 플라즈마를 챔버 밖에서 생성, 라디칼만 공급 | 이온 거의 없음 | 해당 없음 | 수백 mTorr~Torr | 등방성 화학 식각, 세정, ash |
| 원자층 식각(ALE) | 표면 개질 + 제거를 사이클로 반복 | 저에너지 | 정밀 | 다양 | 원자 단위 두께 제어 |

CCP는 고밀도 플라즈마를 만들기 어렵지만 이온 에너지를 크게(수백~수천 eV) 올릴 수 있어 결합 에너지가 큰 산화막 식각에 유리하다. 최신 HAR 식각 장비는 60 MHz 소스 + 2 MHz 또는 400 kHz 바이어스처럼 다중 주파수 CCP를 쓰고, 바이어스에 펄스나 DC 중첩을 더한다.

ICP는 이온 밀도가 높아 식각 속도가 빠르고 압력을 낮게 유지해 이온 산란이 적으므로 Si 게이트나 금속처럼 CD 정밀도가 중요한 공정에 쓰인다.

### 3.2 챔버 구성 요소

```text
       가스 인렛 (MFC로 유량 제어)
            |
   +--------v--------+  <- 상부 전극/샤워헤드 (CCP) 또는 유전체 창 + 코일 (ICP)
   |   플라즈마 영역   |
   |  ~~~~~~~~~~~~~~  |
   |   [ 웨이퍼 ]     |  <- ESC(정전 척): 온도 제어(멀티존), He 배면 냉각
   |  ==============  |  <- 하부 전극: 바이어스 RF, 엣지 링(focus ring)
   +--------|---------+
            v
     터보 펌프 + 스로틀 밸브 (압력 제어)
```

- 정전 척(ESC, Electrostatic Chuck): 웨이퍼를 정전기력으로 고정하고 배면 He 가스로 열을 전달한다. 다중 존(4~100존 이상) 히터로 센터-에지 온도를 1°C 단위로 조절해 CD 균일도를 맞춘다.
- 엣지 링(Focus ring): 웨이퍼 가장자리의 시스 형상과 플라즈마 밀도를 보정한다. 소모품이며, 소모될수록 에지 CD·프로파일이 드리프트한다.
- 종점 검출(EPD, End Point Detection): OES(광학 발광 분석)로 반응 생성물 발광 세기가 바뀌는 시점을 잡거나, 간섭계로 남은 두께를 실시간 계측한다.

### 3.4 프로파일의 종류와 원인

| 프로파일 | 모양 | 주 원인 | 제품 영향 |
|---|---|---|---|
| Vertical | 측벽 88~90° | 이온·보호막 균형 | 목표 |
| Taper (positive) | 아래로 좁아짐 | 측벽 폴리머 과다, 이온 산란, 바이어스 부족 | 바닥 CD 감소 → 접촉 저항 증가, 커패시터 면적 감소 |
| Bowing | 중간이 불룩 | 마스크 패싯에서 반사된 이온이 측벽 충격, 보호막 부족, 온도 높음 | 인접 홀 브리지, 커패시터 간 단락 |
| Undercut | 마스크 아래 파임 | 등방성 화학 식각, 낮은 바이어스, 높은 압력 | CD 확대, 마스크 리프트 |
| Footing | 바닥 모서리 남음 | 바닥 코너에 폴리머 축적, 하부막 위 charging | 접촉 면적 감소, 잔막 |

### 3.5 로딩 효과와 ARDE

- 매크로로딩(Macro loading): 웨이퍼 전체의 노출 면적이 클수록 라디칼이 소모되어 식각 속도가 떨어진다. 제품별 오픈 비율이 다르면 같은 레시피에서도 속도가 다르다.
- 마이크로로딩(Micro loading): 패턴이 밀집된 영역(셀)과 고립된 영역(페리)의 속도가 다르다. 밀집 영역은 라디칼 고갈로 느리고, 고립 영역은 빠르다. 셀-페리 경계에서 CD·깊이 편차가 생긴다.
- ARDE(RIE lag): 종횡비가 클수록 홀 바닥에 도달하는 이온·라디칼이 줄고 생성물 배출이 어려워 속도가 떨어진다. 종횡비 10:1에서 속도가 평지의 70%, 50:1에서 30~40% 수준까지 떨어질 수 있다(공정마다 다름).

ARDE의 원인은 세 가지다. (1) 이온 각도 분포: 몇 도라도 기울어진 이온은 측벽에 막힌다. (2) Knudsen 수송: 중성 라디칼은 홀 안에서 벽과 충돌하며 확산하므로 바닥 플럭스가 깊이에 반비례로 감소한다. (3) 충전(charging): 전자는 등방적으로 움직여 홀 상부 측벽에 붙고, 이온은 바닥에 쌓여 바닥이 양전위가 되면 후속 이온이 감속·편향된다.

> **[주의]** ARDE 때문에 서로 다른 CD의 홀을 같은 웨이퍼에서 동시에 식각하면 작은 홀은 덜 파인다. 큰 홀이 하부막에 도달해 오버에치되는 동안 작은 홀은 아직 못 파인 상태가 된다. 이것이 "오픈 불량은 작은 CD 사이트에서 먼저 난다"는 경험칙의 물리적 근거다.

### 3.6 HAR 식각: DRAM 커패시터 홀

DRAM 커패시터는 몰드 산화막(두께 1~2 μm 이상, 중간에 지지대 질화막 삽입)에 CD 30~50 nm 홀을 뚫고 그 안에 하부 전극(TiN)을 채운다. 종횡비 40~80:1이 일반적이다.

식각의 핵심 과제는 다음과 같다.

- 마스크: 다층 하드마스크(ACL 또는 도핑 탄소, 그 위 SiON, 폴리Si 등). 탄소 하드마스크 두께 1 μm 안팎으로 마스크 자체도 HAR 식각 대상이다.
- 가스: C₄F₆, C₄F₈, CH₂F₂ 등 고C/F 가스 + O₂ + Ar. 폴리머 두께로 프로파일 제어.
- 바이어스: 수 kV급 저주파 바이어스로 바닥까지 이온 에너지 전달. 펄싱으로 충전 완화.
- 온도: 저온일수록 측벽 보호에 유리. 최신은 극저온(−60°C 이하) 식각도 적용.
- 지지대 질화막 관통: 산화막과 질화막을 한 번에 뚫어야 하므로 계면에서 프로파일 꺾임(kink)이 생기기 쉽다.

전기적 결과와 연결하면, 바닥 CD가 작아지면 커패시터 하부 전극 접촉이 나빠져 tRCD/tWR 특성이 저하되고, bowing으로 인접 홀이 붙으면 커패시터 간 단락(2-bit fail, 이웃 셀 간섭)이 된다. 홀이 아예 안 뚫리면(미개구) 해당 셀은 오픈 불량이다.

### 3.7 HAR 식각: NAND 채널 홀

3D NAND는 ON(산화막/질화막) 스택 또는 OP(산화막/폴리) 스택을 수십~수백 층 쌓은 뒤 채널 홀을 한 번에 뚫는다. 200단 이상에서는 스택 높이 6~10 μm, 홀 CD 100~120 nm로 종횡비 60~100:1에 이르고, 단수가 늘면 2~3개 덱(deck)으로 나누어 식각한 뒤 정렬한다.

| 항목 | DRAM 커패시터 홀 | NAND 채널 홀 |
|---|---|---|
| 대상 | 산화막 몰드(질화막 지지대 포함) | 산화막/질화막 교대 적층 |
| CD | 30~50 nm | 100~130 nm |
| 깊이 | 1~2 μm | 5~10 μm (덱 당) |
| 종횡비 | 40~80:1 | 60~100:1 이상 |
| 핵심 이슈 | bowing, 미개구, 브리지 | twisting, tilting, 층별 CD 편차, 덱 미스얼라인 |
| 결과 특성 | Cs, 셀 간 단락, tWR | 셀 Vt 산포, 층간 특성 편차, WL-채널 거리 |

NAND 채널 홀에서는 홀 위쪽(상층)과 아래쪽(하층)의 CD 차이가 층별 셀 특성 차이(Vt 분포, 프로그램 속도)로 나타난다. 홀이 좁은 아래 층은 채널 곡률이 커서 전계가 집중되어 프로그램이 빠르고, 넓은 위 층은 느리다. PE는 이 층별 산포를 읽고 레시피 방향(taper 보정)을 요구하게 된다.

### 3.8 습식 식각의 실제

| 용액 | 조성 | 대상 | 선택비/특징 |
|---|---|---|---|
| DHF (희석 HF) | HF:H₂O 1:100~1:1000 | SiO₂, 자연 산화막 | 산화막:Si 매우 높음. 열산화막 속도 대략 수 nm/min(농도 따라) |
| BOE | HF + NH₄F 완충 | SiO₂ | 속도 안정적, 포토레지스트 손상 적음 |
| 인산(H₃PO₄, 고온 150~180°C) | 85% H₃PO₄ | Si₃N₄ | 질화막:산화막 30~50:1. NAND 질화막 희생층 제거에 필수 |
| SC1 (APM) | NH₄OH:H₂O₂:H₂O 1:1:5~1:4:20, 40~70°C | 파티클, 유기물, 얇은 Si/산화막 | 산화-식각 반복으로 표면 약간 식각(Si 손실 수 Å) |
| SC2 (HPM) | HCl:H₂O₂:H₂O | 금속 이온 | 세정용 |
| DSP | 희석 H₂SO₄ + H₂O₂ (+ HF) | 포토레지스트 잔사, 폴리머 | 식각 후 폴리머 제거 |
| SPM (피라냐) | H₂SO₄:H₂O₂ 3~4:1, 90~130°C | 유기물, 포토레지스트 | 강산화, 금속 노출 시 사용 불가 |
| TMAH / KOH | 알칼리 | Si (결정 방향 의존) | 이방성 습식(111면 느림), MEMS·Si 리세스 |
| Cl₂ 계 건식 대체 | — | 금속 | — |

습식 식각의 함정은 (1) 언더컷과 패턴 리프트, (2) 패턴 붕괴(stiction: 건조 시 표면장력으로 인접 구조가 붙는 현상, HAR 구조에서 심각), (3) 갈바닉 부식(서로 다른 금속이 용액에 노출될 때), (4) 로딩(용액 농도 소모), (5) 배치 내 위치 편차다. 패턴 붕괴를 피하기 위해 IPA 건조, 초임계 CO₂ 건조, 표면 소수화 처리 등을 쓴다.

> **[예시]** DRAM 커패시터 하부 전극(높이 1.5 μm, 폭 30 nm) 형성 후 몰드 산화막을 습식으로 제거하면 기둥이 홀로 서게 된다. 세정 후 물이 마르면서 표면장력(물 약 72 mN/m)이 이웃 기둥끼리 잡아당겨 붕괴(leaning)한다. 그래서 지지대(supporter) 질화막을 남기고, 표면장력이 낮은 IPA(약 21 mN/m)나 초임계 건조를 쓴다.

### 3.9 후처리: Ash와 습식 세정

식각 후 남은 포토레지스트, 측벽 폴리머, 식각 잔사(residue)를 제거한다.

- Ash(스트립): O₂ 플라즈마(원격 또는 직접)로 유기물을 CO₂, H₂O로 태운다. 저k 유전체나 금속이 노출된 경우 O₂가 산화 손상을 주므로 N₂/H₂ 환원성 ash를 쓴다.
- 습식 세정: DSP, SC1, 유기 용제로 폴리머와 금속 잔사를 제거한다. HF 계열은 노출된 산화막(게이트 산화막 측면, 라이너)을 깎으므로 시간·농도 관리가 필수다.
- 이온 주입 후 레지스트는 표면이 탄화(crust)되어 일반 ash로 잘 안 벗겨진다. 고온 ash나 두 단계(crust 제거 후 벌크) 공정을 쓴다.

Ash 자체도 플라즈마 공정이므로 charging damage와 산화가 생긴다. 특히 게이트 식각 후 ash에서 게이트 산화막에 전하가 들어가면 Vt shift와 GOI 열화가 발생한다.

### 3.10 계측

| 계측 | 측정 항목 | 특징 | PE 활용 |
|---|---|---|---|
| CD-SEM | 상부 CD, LER/LWR | 비파괴, 인라인, 수 nm 정밀도. 바닥 CD는 직접 보기 어려움 | CD 트렌드, 사이트 맵, 셀-페리 편차 |
| X-SEM (단면 SEM) | 프로파일, 깊이, 측벽 각도, bowing | 파괴 분석. 웨이퍼 절단 필요 | 프로파일 불량 확인, 레시피 튜닝 |
| TEM / STEM | 잔막, 계면, 손상층, nm 이하 두께 | 파괴, 시료 준비 오래 걸림(FIB) | 잔막·notch·미세 손상 확정 |
| OCD (스캐터로메트리) | CD, 깊이, 측벽 각도, 다층 두께 | 비파괴, 인라인, 모델 기반. 모델 오차 존재 | 전 웨이퍼 프로파일 맵, 공정 제어 |
| 간섭계/OES EPD | 실시간 식각 깊이, 종점 | 장비 내장 | 챔버 드리프트 감시 |
| 전기적 테스트 구조(TEG) | 접촉 저항, 라인 저항, 브리지/오픈 체인 | 최종 전기적 결과 | 식각 결과 ↔ 전기 특성 직결 |
| 파티클 검사(dark field) | 웨이퍼 표면 파티클, 폴리머 낙하 | 인라인 | 챔버 세정 주기 결정 |
| EBI (E-beam inspection) | 컨택 오픈/단락(전압 대비 이미지) | 느리지만 전기적 결함 직접 탐지 | HAR 홀 미개구 스크리닝 |
| GOI / 안테나 TEG | 플라즈마 charging 손상 | 전기적 | 손상 모니터 |

OCD는 산란된 빛의 스펙트럼을 시뮬레이션 모델과 맞춰 구조를 역산한다. bowing이나 층별 CD 같은 다중 파라미터도 모델에 넣으면 추출되지만, 파라미터가 많아지면 상관(correlation) 때문에 오차가 커진다. 반드시 주기적으로 X-SEM/TEM으로 교정(reference)해야 한다.

> **[핵심]** PE의 계측 원칙: "인라인 비파괴(CD-SEM, OCD)로 전수 감시, 파괴 분석(X-SEM, TEM)으로 원인 확정, 전기 테스트(TEG, 웨이퍼 테스트 맵)로 제품 영향 확인." 세 층이 서로 맞아야 결론을 낸다.

### 3.11 하드마스크 스택

HAR 식각에서 마스크는 단일 포토레지스트가 아니라 다층 스택이다. 각 층은 위 층을 마스크로 순서대로 식각된다.

```text
   포토레지스트 (EUV 30~40 nm 또는 ArF 100~200 nm)
   ------------------------------------------------
   SiON / SiO2 (반사 방지 + 탄소막 식각 마스크, 30~60 nm)
   ------------------------------------------------
   탄소 하드마스크 (ACL, 도핑 탄소, 0.5~3 um)   <- 실제 HAR 식각의 마스크
   ------------------------------------------------
   폴리Si 또는 금속(W, TiN) 하드마스크 (선택적)
   ------------------------------------------------
   목표막 (몰드 산화막 / ON 스택, 1~10 um)
```

| 마스크 재질 | 산화막 대비 선택비(대략) | 장점 | 단점 |
|---|---|---|---|
| 포토레지스트 | 2~5:1 | 패턴 형성 그 자체 | 두께 부족, 열·플라즈마에 변형 |
| ACL (비정질 탄소) | 10~20:1 | 두껍게 증착 가능, ash로 제거 쉬움 | 응력·wiggling, 투명도 낮아 정렬 어려움 |
| 보론/텅스텐 도핑 탄소 | 20~40:1 | 밀도·경도 향상, 마스크 두께 절감 | 제거 어려움, 증착 비용 |
| 폴리Si | 5~15:1(산화막 식각 시) | 저렴, 후속 공정 호환 | 선택비 제한 |
| 금속(W, TiN, TiO₂) | 50:1 이상 | 얇게 써도 됨 | 금속 오염 우려, 제거 공정 필요 |

마스크 스택의 wiggling은 마스크 라인 종횡비가 5:1을 넘고 압축 응력이 크면 라인이 뱀처럼 휘는 현상이다. 홀 배열에서는 홀 위치 이탈, 라인에서는 LWR 폭증으로 나타난다. 대책은 응력 저감 증착(온도·이온 충격 조정), 마스크 두께 최소화, 도핑 탄소 적용이다.

### 3.12 게이트·금속 식각의 특징

유전체 HAR 식각과 달리 Si·금속 식각은 CD 정밀도와 하부 게이트 산화막 보호가 최우선이다.

- 폴리Si 게이트 식각: HBr/Cl₂/O₂ 계열, ICP. 메인 식각 후 게이트 산화막(2~5 nm) 직전에 "soft landing" 스텝(저바이어스, 고선택비)으로 전환하고, 마지막 오버에치는 산화막:Si 선택비 100:1 이상으로 진행한다. 산화막 관통은 Si 기판 리세스와 접합 누설로 이어진다.
- 금속 게이트/W 식각: SF₆, NF₃, Cl₂. W은 F와 반응해 WF₆로 휘발한다. TiN은 Cl₂/BCl₃로 식각한다. 하부 고유전체(HfO₂)와의 선택비가 낮아 스텝 분리가 필요하다.
- NAND WL 리세스: 희생 질화막을 인산으로 제거한 자리에 TiN/W을 채운 뒤, 슬릿 내부에 남은 W을 등방성 건식(원격 플라즈마 F 계열) 또는 습식으로 리세스해 WL을 층별로 분리한다. 리세스 깊이 편차는 WL 저항·인접 WL 단락과 직결된다.

### 3.13 플라즈마 손상의 세 경로

| 손상 종류 | 원인 입자 | 침투 깊이 / 대상 | 소자 영향 | 회복 가능성 |
|---|---|---|---|---|
| 이온 손상 | 수백 eV~수 keV 이온 | 표면 1~10 nm 비정질화, 도펀트 재분포, F/C 침투 | Rc 증가, 접합 누설, Si 리세스, 산화막 두께 변화 | 어닐로 일부 회복, 손상층 습식 제거 |
| 전하 손상 | 시스 전위 불균일, 전자 shading | 게이트 산화막 전체(F-N 터널링 전류) | Vt shift, SS 열화, GOI/Qbd 저하, NBTI 가속 | 수소 어닐로 부분 회복, 심하면 영구 |
| 광 손상 | 진공 UV(5~20 eV 광자) | 산화막·계면 수십 nm 깊이까지 전자-정공 생성, 결합 절단 | 계면 트랩 밀도(D_it) 증가, 1/f 노이즈, 이동도 저하 | 400~450°C H₂/D₂ 어닐로 대부분 회복 |

전자 shading 메커니즘: 마스크 패턴 사이 좁은 트렌치에서, 등방적으로 움직이는 전자는 마스크 상부와 측벽 상단에 붙고, 수직으로 오는 이온은 바닥까지 도달한다. 결과로 트렌치 바닥은 양전위, 상부는 음전위가 되고, 바닥에 연결된 게이트 산화막에 전류가 흐른다. 패턴 종횡비가 클수록, 플라즈마 밀도가 높을수록, 전자 온도가 높을수록 심해진다. 안테나 비율(게이트에 연결된 도체 면적 / 게이트 산화막 면적)이 클수록 모이는 전하가 많아 손상이 커진다.

```text
   e- (등방, 상부에 포획)          Ar+ (수직, 바닥 도달)
     \  |  /                            |
      v v v                             v
   +------+  - - -  +------+         +------+
   | mask |         | mask |         | mask |
   +------+         +------+         +------+
   |      | + + + + |      |  <- 바닥 양전하 -> 게이트 산화막에 전류
   |  ==========================  게이트 산화막
```

> **[핵심]** 전하 손상은 "패턴 종횡비 × 플라즈마 비균일 × 안테나 비율"의 곱으로 생각하면 된다. 셋 중 어느 하나를 줄이면 완화된다. 공정은 펄싱과 마감 스텝으로 앞 둘을, 설계는 안테나 규칙과 보호 다이오드로 마지막을 담당한다.

> **[예시]** 폴리Si 게이트 식각에서 오버에치 스텝 선택비가 100:1이고, 마이크로로딩으로 고립 라인 영역이 셀 영역보다 20 nm 상당 먼저 끝났다면, 그 지점의 게이트 산화막은 0.2 nm 깎인다. 3 nm 산화막에서는 무시할 수 있지만, 1.5 nm급 페리 고성능 트랜지스터에서는 Vt와 GOI에 영향을 줄 수 있어 스텝을 더 잘게 나눈다.

## 4. 결함·불량 유형

### 4.1 프로파일·CD 관련

| 결함명 | 현상 | 발생 원인 | 검출/분석 방법 | 대책 |
|---|---|---|---|---|
| Bowing | 홀/트렌치 중간 부분 CD가 상부보다 큼 | 마스크 패싯 반사 이온, 측벽 보호막 부족, 고온, O₂ 과다 | X-SEM, OCD 모델(bow CD), 브리지 TEG | 저온화, C 함량 증가, 마스크 형상 개선, 바이어스 주파수 낮춤 |
| Taper (바닥 CD 부족) | 하부 CD 감소, 접촉 면적 축소 | 폴리머 과다, 이온 산란, 바이어스 부족, ARDE | X-SEM, 접촉 저항 TEG, 커패시터 Cs 감소 | O₂ 소량 증가, 바이어스 증가, 압력 저하 |
| Undercut | 마스크 아래 파임 | 화학 식각 성분 과다, 낮은 이온 에너지 | X-SEM, CD 바이어스 양(+) | 바이어스 증가, 압력 저하, 보호 가스 추가 |
| CD 바이어스 shift | 식각 후 CD가 목표에서 이탈 | 챔버 상태 변화, 온도 드리프트, 마스크 CD 변동 | CD-SEM 트렌드, 챔버 별 비교 | APC(피드백/피드포워드), 챔버 시즈닝, 부품 교체 |
| 센터-에지 CD 편차 | 웨이퍼 중심과 가장자리 CD 차이 | 플라즈마 밀도 분포, ESC 온도 분포, 엣지 링 소모, 가스 분포 | CD-SEM/OCD 반경 방향 맵 | 멀티존 온도 튠, 엣지 링 교체, 가스 분배 조정 |
| Footing | 바닥 코너에 잔막 | 코너 폴리머 축적, 하부막 charging | X-SEM, 접촉 저항 증가 | 오버에치 조정, 펄싱, 코너 clearing step 추가 |
| Micro-trenching | 측벽 옆 바닥이 더 깊게 파임 | 측벽 반사 이온 집중 | X-SEM, 하부막 관통 누설 | 압력·각도 분포 조정, 폴리머 증가 |
| Faceting | 마스크 모서리 깎임 → 상부 CD 확대 | 스퍼터 수율 각도 의존성 | X-SEM 마스크 형상, 상부 CD 증가 | 마스크 경화(implant, 도핑 탄소), 선택비 향상 |
| Kink (계면 꺾임) | 이종막 계면(산화막/질화막)에서 프로파일 단차 | 막별 식각 속도·폴리머 차이 | X-SEM | 계면 전용 스텝, 가스 전환 |

### 4.2 HAR 특유 결함

| 결함명 | 현상 | 발생 원인 | 검출/분석 방법 | 대책 |
|---|---|---|---|---|
| ARDE / RIE lag | 좁은 홀·고종횡비에서 깊이 부족 | 이온 각도 분포, 라디칼 수송 제한, 충전 | X-SEM(사이즈별 깊이), 오픈 불량 맵 | 저압, 고바이어스, 펄싱, 극저온, 사이클 식각 |
| 미개구 (Not open) | 홀이 하부까지 뚫리지 않음 | ARDE, etch stop(폴리머), 마스크 결함, 클로깅 | EBI, X-SEM, 오픈 체인 TEG, 셀 오픈 fail 맵 | 오버에치 증가, 폴리머 저감, 마스크 개선 |
| Twisting | 홀 하부가 비틀려 위치 이탈 | 충전 불균일, 마스크 비대칭, 측벽 폴리머 비대칭, 이온 각도 편향 | 상면 SEM 하부 CD 이미지(디레이어), X-SEM 여러 방향, 인접 셀 간섭 | 펄싱, 저압, 마스크 형상 대칭성, 덱 분할 |
| Tilting | 홀 전체가 일정 방향으로 기울어짐(에지에서 심함) | 에지 시스 왜곡, 엣지 링 소모, 플라즈마 비대칭 | 에지 사이트 X-SEM, 덱 오버레이 | 엣지 링 교체·설계, 에지 전위 튠 |
| Striation | 측벽 세로 줄무늬 | 마스크 LER/LWR 전사, 마스크 폴리머 불균일 | 경사 SEM, LWR 계측, TEM 측벽 | 마스크 스무딩(트리밍, 리플로우), 보호막 균일화 |
| Clogging | 홀 입구가 폴리머로 막힘 | C/F 높은 가스 과다, 저온, 좁은 CD | 상면 SEM, 깊이 부족, 파티클 | O₂ 증가, 온도 조정, 폴리머 제거 스텝 삽입 |
| Etch stop | 식각이 중간에 멈춤 | 바닥 폴리머 축적, 이온 에너지 부족, 충전 | 시간 대비 깊이 포화, X-SEM 바닥 폴리머 | 바이어스 증가, 사이클 clearing, 가스 O₂ |
| 마스크 소모/붕괴 | 마스크 두께 부족, 좁은 마스크 라인이 휘거나 넘어짐 | 선택비 부족, 마스크 종횡비 과다, 정전기 | 상면 SEM(마스크 wiggling), 상부 CD 확대 | 마스크 재질 변경(도핑 ACL, 금속 하드마스크), 두께·CD 최적화 |
| 브리지(인접 홀 연결) | 인접 홀이 측면에서 연결 | bowing, twisting, 마스크 결함 | 브리지 TEG, EBI, 2-bit fail 패턴 | bowing 억제 |
| 덱 미스얼라인 | 상하 덱 채널 홀 정렬 이탈 | 오버레이 오차 + tilting | 디레이어 상면 SEM, 오버레이 계측 | 오버레이 보정, tilting 억제, 랜딩 패드 확대 |

| Corrosion (Al, W) | 금속 부식, 시간 경과 후 오픈 | Cl 잔류 + 수분 → HCl | 지연 불량, SEM/EDX | 식각 후 즉시 패시베이션(F 치환), 수분 관리 |
| 파티클 | 챔버 벽 폴리머 낙하 | 폴리머 박리, 부품 마모 | 파티클 검사, 랜덤 불량 증가 | 정기 세정(in-situ 플라즈마, 습식), 시즈닝 |
| 하부막 관통 (Punch-through) | etch stop 막 뚫림 | 선택비 부족, 오버에치 과다, micro-trench | TEM, 누설 TEG | 선택비 향상, EPD 정밀화, 오버에치 축소 |
| 패턴 붕괴 (Stiction) | 습식 후 HAR 구조 기울어져 붙음 | 건조 시 표면장력 | 상면 SEM, 브리지 | IPA/초임계 건조, 지지대 |

### 4.4 습식·후처리 관련

| 결함명 | 현상 | 발생 원인 | 검출/분석 방법 | 대책 |
|---|---|---|---|---|

| Stiction | HAR 구조 기울어져 이웃과 붙음 | 건조 시 표면장력 | 상면 SEM, 브리지 TEG | IPA·초임계 건조, 지지대, 소수화 |

| Ash 잔류(스컴) | 레지스트 잔사 | crust(주입 후 탄화층), 폴리머 과다 | SEM, 후속 증착 접착 불량 | 2단계 ash, 온도 상승, 습식 보강 |
| Ash 산화 손상 | 저k·금속 표면 산화, k 값 상승 | O₂ 플라즈마 | 커패시턴스 TEG, XPS | N₂/H₂ 환원 ash |
| Ash charging | 게이트 산화막 트랩, Vt shift | 직접 플라즈마 ash의 전하 불균일 | 안테나 TEG | 원격 플라즈마 ash, 펄싱 |
| 금속 오염 | 용액·챔버에서 Fe, Cu, Ni 전이 | 화학액 순도, 부품 | TXRF, VPD-ICPMS, 접합 누설·retention | 화학액 등급 관리, 부품 재질 |
| 배치 내 편차 | 카세트 위치별 CD·두께 차이 | 유동·농도 구배 | 슬롯별 계측 | 순환·교반 개선, 단일 웨이퍼 장비 |

> **[면접]** "식각 후 세정이 왜 중요한가?"에는 "결론: 식각의 부산물과 손상층이 그대로 남으면 다음 공정의 접착·전기 접촉·신뢰성을 망치기 때문입니다. 예로 컨택 홀 바닥에 1~2 nm 폴리머가 남으면 접촉 저항이 수 배 뛰고, 이온 주입 후 레지스트는 표면이 탄화되어 일반 ash로 안 벗겨져 잔사가 남습니다. 그러나 세정 자체도 HF가 노출된 게이트 산화막을 깎거나 건조 과정에서 HAR 구조를 붕괴시킬 수 있어, 세정 시간·농도·건조 방식을 식각 결과와 함께 설계해야 합니다."

> **[트러블슈팅]** 게이트 식각 후 특정 로트에서 Vt가 셀 어레이 가장자리에서만 낮게 나왔다. X-SEM에서 폴리Si 게이트 하부에 notching이 관찰되고, 그 위치가 어레이 최외곽 라인에 집중되었다. 원인은 오버에치 스텝에서 고립 라인(어레이 끝)의 전자 shading이 비대칭이라 국부 충전이 커진 것. 오버에치 스텝을 펄스 바이어스로 바꾸고 압력을 낮춰 notching 깊이를 2 nm 이내로 줄였다.

## 5. 공정 변수 ↔ 소자/제품 특성 상관관계

### 5.1 DRAM

| 식각 항목 | 변수 shift | 구조 변화 | 전기적 특성 변화 | 수율/신뢰성 영향 |
|---|---|---|---|---|
| BCAT(매립 채널) 트렌치 식각 | 깊이 증가 | 채널 길이 증가, 게이트 리세스 깊어짐 | Vt 상승, Ion 감소, tRCD 열화 가능, GIDL 변화 | 속도 빈 하락, retention은 GIDL 방향 따라 변화 |
| BCAT 트렌치 CD | CD 증가 | 게이트 폭 증가, 인접 액티브 간 거리 감소 | Ion 증가, 인접 WL 간섭(row hammer 취약) 증가 | 간섭 불량, 신뢰성 |
| BCAT 프로파일 | 바닥 라운딩 부족(각진 바닥) | 게이트 산화막 전계 집중 | GIDL 증가, 누설 증가 | retention 열화(tail bit) |
| 커패시터 홀 바닥 CD | 감소 | 하부 전극 접촉 면적 감소, 전극 높이 손실 | Cs 감소, 접촉 저항 증가 → tWR/tRCD 열화, 센싱 마진 감소 | retention fail, 속도 fail |
| 커패시터 홀 bowing | 증가 | 인접 전극 간 거리 감소 → 유전체 증착 후 브리지 | 셀 간 단락, 2-bit/컬럼 fail | 수율 직접 하락 |
| 커패시터 홀 미개구 | 발생 | 하부 전극이 랜딩 패드에 미접촉 | 셀 오픈(쓰기 불가) | single bit fail, 리페어 소모 |
| SNC/BC(스토리지 노드 컨택) 식각 | 잔막 | 컨택 오픈 또는 고저항 | tWR 열화, 쓰기 fail | 리페어 한계 초과 시 수율 하락 |
| 게이트(페리) 식각 | CD 감소 | 채널 길이 감소 | Vt 저하, Ioff 증가, DIBL 증가 | 대기 전류(IDD6) 증가 |
| 게이트 식각 손상 | charging 증가 | 게이트 산화막 트랩 | Vt shift, GOI 열화, NBTI 가속 | 신뢰성 fail, 번인 스크린 증가 |
| 소자 분리(STI) 식각 | 깊이 부족 | 인접 액티브 간 격리 약화 | 누설 증가, 래치업 | retention, 대기 전류 |
| 스페이서 식각 | 과식각(하부 Si 리세스) | 소스/드레인 영역 손실, 접합 손상 | Rs 증가, 접합 누설 증가 | Ion 감소, retention |

> **[예시]** 커패시터 홀 바닥 CD가 목표 35 nm에서 30 nm로 5 nm 줄면, 원통형 전극 면적이 하부에서 약 14% 감소한다. 커패시터 전체 면적에는 수 % 영향이지만, 바닥 접촉 저항은 면적에 반비례해 30% 이상 증가할 수 있다. 결과적으로 tWR 마진이 줄고, 쓰기 시간이 빠듯한 셀에서 write fail이 tail로 나타난다.

### 5.2 NAND

| 식각 항목 | 변수 shift | 구조 변화 | 전기적 특성 변화 | 수율/신뢰성 영향 |
|---|---|---|---|---|
| 채널 홀 CD (층별) | 상층 대비 하층 CD 감소(taper) | 하층 채널 곡률 증가, 터널 산화막 전계 집중 | 하층 셀 프로그램 속도 빠름, Vt 분포 층별 편차 | 층별 보정 알고리즘 부담, 읽기 마진 감소 |
| 채널 홀 bowing | 발생 | 중간 층 채널 직경 증가, 인접 홀 간 절연 거리 감소 | 중간 층 프로그램 느림, 인접 셀 간섭 증가 | 층별 Vt 산포, 블록 fail |
| 채널 홀 twisting | 발생 | 하부 홀 위치 이탈, 덱 접합부 오정렬 | 채널 저항 증가·오픈, WL 간 거리 불균일 | 스트링 오픈, 블록 불량 |
| 채널 홀 striation | 증가 | 터널 산화막 두께 국부 변동, 채널 폴리 거칠기 | 셀 Vt 산포 증가, 전계 집중 → endurance 저하 | 신뢰성(P/E cycle) 열화 |
| 채널 홀 미개구 | 발생 | 채널이 소스 라인과 미접속 | 스트링 오픈 | 컬럼 fail |
| WL 슬릿(게이트 라인 컷) 식각 | 프로파일 기울어짐, 바닥 미도달 | 질화막 희생층 제거 불완전, 인접 블록 간 WL 단락 | WL 단락, 소스 접촉 저항 | 블록 fail |
| 계단(staircase) 식각 | 스텝 CD 오차 | WL 패드 위치 이탈 → 컨택 랜딩 실패 | WL 오픈 또는 인접 WL 단락 | 블록 fail |
| WL 컨택 식각(다단 깊이) | ARDE로 얕은 컨택 오버에치 | 상층 WL 패드 관통 → 하층 WL과 단락 | WL 간 단락 | 블록 fail |
| 질화막 희생층 습식 제거(인산) | 제거 불완전 | 게이트 금속(W) 충진 공간 부족 | WL 저항 증가, RC delay 증가 | 동작 속도, 읽기 타이밍 |
| 페리 CMOS 게이트 식각 | CD/손상 | DRAM 페리와 동일 | Vt, Ioff | 대기 전류, 페이지 버퍼 산포 |

### 5.3 변수 → 특성 요약 흐름

```text
  바이어스 부족 / 폴리머 과다 ---> taper, 바닥 CD 감소 ---> Rc 증가, Cs 감소
                                                      ---> tWR, tRCD 열화
  온도 상승 / O2 과다 / 패싯 ---> bowing ---------------> 인접 브리지, 2-bit fail

  플라즈마 비균일 / 안테나 ---> charging damage --------> Vt shift, GOI, Ioff 증가
  마스크 LER ---------------> striation ---------------> 셀 Vt 산포, endurance 저하
  오버에치 과다 / 저선택비 ---> 하부막 손실 --------------> 누설, 접합 손상, retention
```

> **[면접]** "식각 공정 변수 하나가 DRAM 특성에 미치는 영향을 예로 들어라"에는 커패시터 홀 바닥 CD를 든다. "바이어스 파워가 부족하거나 폴리머가 과다하면 홀이 아래로 좁아져 바닥 CD가 줄어듭니다. 예를 들어 35 nm 목표가 30 nm가 되면 하부 전극 접촉 면적이 약 14%, 접촉 저항은 30% 이상 늘어날 수 있습니다. 결과는 tWR 마진 감소와 쓰기 fail tail, 그리고 Cs 감소에 따른 센싱 마진·retention 악화입니다. 그래서 상부 CD뿐 아니라 OCD 바닥 CD를 인라인 관리 항목으로 둡니다."

> **[심화]** NAND에서 층별(WL별) Vt 분포는 채널 홀 프로파일의 "전기적 X-SEM"이다. 프로그램 속도가 빠른 층은 홀이 좁은 층, 느린 층은 넓은 층에 대응한다. PE는 WL별 프로그램 펄스 수(PGM loop count)를 뽑아 층 방향 프로파일을 역추정하고, 이를 식각 X-SEM과 맞춰 레시피 방향을 제시한다. 덱 접합부(joint)에서 특성이 튀면 덱 간 오정렬이나 접합부 CD 확대를 의심한다.

## 6. 트러블슈팅 케이스

### 6.1 케이스 1: DRAM 커패시터 홀 bowing에 의한 인접 셀 브리지

**증상**
- 신규 세대 DRAM 개발 로트에서 웨이퍼 테스트 결과 2-bit fail(인접 두 셀이 동시에 fail)이 기존 대비 5배 증가. 웨이퍼 맵에서 센터에 집중.
- fail 비트 페어의 방향이 특정 대각선 방향(홀 배열의 최근접 방향)으로 편중.

**1차 데이터**
- 웨이퍼 테스트 fail 비트맵: 인접 셀 페어 fail, 센터 집중.
- 인라인 OCD: 센터 사이트에서 bow CD가 에지보다 3 nm 큼. 상부 CD는 차이 없음.
- 식각 챔버 이력: 해당 로트 전후로 엣지 링 교체 이력 없음, 챔버 누적 RF 시간이 세정 주기 후반.

**가설**
1. 마스크(ACL) 형상 변화로 패싯 반사 이온 증가 → bowing.
2. 챔버 폴리머 축적으로 센터 부근 라디칼/폴리머 균형 변화 → 센터 측벽 보호 부족.
3. ESC 센터 존 온도 상승(히터 드리프트) → 폴리머 부착 감소 → bowing.
4. 유전체(ZAZ) 증착 두께 증가로 인접 전극 사이 공간이 메워짐(식각 아닌 증착 원인).

**검증**
- 가설 4: 유전체 증착 두께 인라인 데이터는 정상 범위 → 기각.
- 가설 1: 마스크 식각 후 X-SEM 마스크 형상은 정상 로트와 동일 → 기각.
- 가설 3: ESC 존별 온도 로그에서 센터 존 설정 −20°C 대비 실측 −17°C로 3°C 드리프트 확인. 동일 시기 센터 CD 바이어스도 +1 nm 추세.
- 가설 2: 챔버 세정 직후 웨이퍼와 세정 후반 웨이퍼의 bow CD 비교 → 차이 1 nm 이내로 부차적.
- X-SEM으로 fail 센터 사이트 단면 확인: bow 위치 깊이 40~60% 구간에서 인접 홀 간 잔여 산화막 두께 5 nm 이하, 일부 관통.

**근본 원인**
- ESC 센터 존 히터 제어 드리프트로 센터 온도가 3°C 높아져 측벽 폴리머 부착이 줄고 bowing이 3 nm 커짐. 인접 홀 간 잔여 몰드가 얇아져 후속 유전체 증착 후 전극 간 브리지 발생.

**조치**
- ESC 온도 센서 교정 및 히터 제어 보드 교체. 센터 존 설정 −2°C 오프셋 임시 적용.
- 레시피 측면: 메인 식각 스텝 C₄F₆ 비율 소폭 증가로 측벽 보호 여유 확보(속도 5% 손실 감수).

**재발 방지**
- ESC 존 온도 실측값을 SPC 항목에 추가, 설정 대비 ±1°C 이탈 시 인터락.
- OCD bow CD를 인라인 SPC로 관리(현재는 상부 CD만 관리했음).
- 2-bit fail 방향성 분석을 웨이퍼 테스트 자동 리포트에 추가.

> **[아이디어]** bowing의 근본은 마스크 패싯에서 반사된 이온이다. 마스크 상단을 의도적으로 라운딩 대신 "역 taper"로 만들거나, 마스크 상부에 저스퍼터 수율 재질(금속 산화물)을 얇게 씌우면 반사 각도 분포가 바뀌어 bowing이 완화될 수 있다. 또 바이어스 펄스의 off 구간에 저에너지 폴리머 증착 스텝을 넣는 사이클 식각(deposition-etch 교대)도 검토 대상이다.

### 6.2 케이스 2: ARDE에 의한 센터-에지 미개구 불량

**증상**
- 양산 DRAM에서 특정 식각 챔버 통과 로트만 웨이퍼 에지 3 mm 링 영역에서 single bit fail(오픈성)이 급증. 리페어 후 수율 3% 하락.

**1차 데이터**
- 웨이퍼 테스트 fail 맵: 에지 링 형태, 노치 기준 특정 방위에서 조금 더 두꺼움.
- 인라인 CD-SEM: 에지 상부 CD는 센터보다 1.5 nm 작음(기존에도 1 nm 정도 있었음).
- EBI 스크리닝: 에지에서 커패시터 홀 미개구(dark voltage contrast) 밀도 증가.
- 챔버: 문제 챔버의 엣지 링 누적 사용 시간이 교체 기준의 90%.

**가설**
1. 마스크 상부 CD가 에지에서 작아 ARDE로 바닥 도달 시간이 늘어남(같은 시간 식각 시 미개구).
2. 엣지 링 소모로 에지 시스가 기울어 이온이 tilting → 유효 바닥 도달 이온 감소.
3. 에지 플라즈마 밀도 저하로 식각 속도 자체가 느림.
4. 하드마스크 에지 두께가 두꺼움(증착 균일도).

**검증**
- 가설 4: 하드마스크 두께 맵 정상 → 기각.
- 가설 1과 3: 에지 사이트 X-SEM에서 깊이가 센터 대비 4% 부족. 상부 CD 1.5 nm 차이만으로는 ARDE 계산상 깊이 차이 1~2% 수준 → 부분 기여.
- 가설 2: 에지 X-SEM에서 홀이 약 0.3° 바깥 방향으로 tilting. 정상 챔버는 0.1° 이하. 엣지 링 두께 측정 결과 신품 대비 0.5 mm 감소.
- 엣지 링 교체 후 동일 레시피 재실행: 에지 깊이 차이 1% 이내로 회복, 미개구 소멸.

**근본 원인**
- 엣지 링 소모로 웨이퍼 에지 시스 형상이 왜곡되어 이온 입사각이 기울고 에지 플라즈마 밀도도 저하. 이것이 ARDE와 겹쳐 에지 홀의 바닥 도달이 지연되어 미개구.

**조치**
- 엣지 링 즉시 교체. 교체 기준을 누적 RF 시간 90%에서 75%로 강화.
- 레시피에 에지 보정: 에지 존 ESC 온도 소폭 하강(속도 미세 증가), 오버에치 시간 3% 연장.

**재발 방지**
- 엣지 링 소모량을 in-situ 계측(광학 또는 임피던스 변화)으로 감시하는 예지보전 항목 도입.
- EBI 샘플링을 챔버별 주 1회에서 엣지 링 후반기에는 로트별로 확대.
- 웨이퍼 테스트 에지 링 fail 자동 알람과 식각 챔버 ID 연동.

### 6.3 케이스 3: 게이트 식각 plasma damage에 의한 페리 Ioff 증가

**증상**
- DRAM 페리 회로 nMOS 트랜지스터의 Ioff가 로트 평균 대비 3~5배 증가, 대기 전류(IDD6) 규격 tail 발생. 셀 어레이는 정상.

**1차 데이터**
- 웨이퍼 테스트: IDD6 fail이 웨이퍼 전면에 랜덤하되 센터 약간 우세.
- TEG 데이터: 안테나 비율(게이트 배선 면적/게이트 면적)이 큰 트랜지스터에서 Vt가 −30 mV shift, 서브스레숄드 스윙(SS) 열화. 안테나 비율 작은 소자는 정상.
- GOI TEG: Qbd(전하 대 파괴) 분포 하위 tail 증가.
- 공정 이력: 게이트 식각 장비 RF 매칭 부품 교체 직후 로트.

**가설**
1. 게이트 식각 오버에치 스텝에서 charging damage 증가.
2. 식각 후 ash 공정에서 charging.
3. 게이트 산화막 자체 품질 저하(산화 공정).
4. 이온 주입 손상.

**검증**
- 가설 3, 4: 동일 산화·주입 장비를 거친 다른 식각 챔버 로트는 정상 → 기각.
- 가설 1 vs 2: 스플릿 실험(식각 챔버 A/B × ash 챔버 A/B) 결과 식각 챔버 B에서만 불량 재현 → 식각 원인.
- 식각 챔버 B의 RF 매칭 교체 후 바이어스 전압 실측이 설정 대비 8% 높음(매칭 튠 불량). 오버에치 스텝에서 플라즈마 밀도 균일도 저하(센터 우세)로 전자 shading 불균형 증가.
- 안테나 TEG 상관: 안테나 비율에 비례한 Vt shift는 charging damage의 전형적 시그니처.

**근본 원인**
- RF 매칭 부품 교체 후 튜닝 불량으로 오버에치 스텝의 실제 바이어스와 플라즈마 균일도가 변해 charging damage 증가. 게이트 산화막에 트랩이 생겨 Vt shift, SS 열화, Ioff 증가.

**조치**
- RF 매칭 재튠 및 바이어스 전압 실측 교정.
- 오버에치 스텝을 펄스 플라즈마(듀티 50%)로 변경해 충전 완화.
- 영향 로트: 후속 수소 어닐(H₂ 포함 열처리) 조건 강화로 트랩 일부 회복 확인 후 조건부 출하 판단.

**재발 방지**
- RF 부품 교체 후 안테나 TEG 모니터 웨이퍼 필수 평가 절차 추가.
- 바이어스 전압·플라즈마 균일도(OES 센터/에지 비)를 FDC(Fault Detection) 항목에 추가.
- 설계 규칙: 페리 게이트 안테나 비율 상한 강화 및 보호 다이오드 배치 점검.

### 6.4 케이스 4: NAND 채널 홀 twisting에 의한 스트링 오픈

**증상**
- 3D NAND 신규 단수 제품 개발 로트에서 블록 단위 fail은 아니지만 특정 스트링(비트라인 방향) 오픈 불량이 웨이퍼 에지 및 다이 가장자리에서 증가.
- 하부 덱 셀의 읽기 마진이 상부 덱보다 나쁨.

**1차 데이터**
- 웨이퍼 테스트: 스트링 오픈 fail이 웨이퍼 에지에서 1.5배, 다이 내에서는 블록 가장자리 근접.
- 디레이어 후 상면 SEM(하부 덱 바닥 근처): 홀 중심이 설계 격자에서 최대 15 nm 이탈, 이탈 방향이 무작위(tilting이면 한 방향).
- X-SEM: 깊이 70% 이하 구간에서 홀이 좌우로 흔들리는 형상. 상부는 정상.
- 인라인 OCD: 상부 CD·bow CD 정상.

**가설**
1. 마스크 홀 형상 비대칭(타원율) → 이온 각도 비대칭 → twisting.
2. 홀 하부 충전 불균일 → 이온 궤도 편향(무작위 방향 twisting의 전형).
3. 측벽 폴리머 비대칭 축적.
4. 덱 간 오버레이 오차(하부 덱 랜딩 실패).

**검증**
- 가설 4: 덱 오버레이 계측 정상(±5 nm) → 15 nm 이탈 설명 불가 → 기각(부분 기여).
- 가설 1: 마스크 식각 후 상면 SEM 타원율 정상 → 기각.
- 가설 2, 3: 바이어스 펄싱 듀티를 낮춘 스플릿(연속 → 듀티 60% → 40%)에서 twisting 이탈량이 15 → 9 → 6 nm로 감소. 충전 기여 확인.
- 압력을 낮춘 스플릿에서도 개선. 이온 각도 분포 폭 축소가 유효.

**근본 원인**
- 종횡비 증가로 홀 하부 충전 불균일이 커져 이온 궤도가 무작위로 편향. 특히 플라즈마 밀도가 낮은 에지에서 이온 각도 분포가 넓어 twisting 심화. 하부 덱 채널 폴리 충진 시 국부 협착으로 채널 저항 증가·오픈.

**조치**
- 메인 식각 후반부 스텝을 저압 + 펄스 바이어스(듀티 40%)로 변경. 속도 저하 10%는 오버에치 시간 재조정으로 보상.
- 마스크 개구 CD를 2 nm 확대해 하부 도달 이온 플럭스 확보.

**재발 방지**
- twisting 전용 인라인 계측: 디레이어 샘플의 하부 CD 위치 이탈량(격자 대비)을 주기 모니터링.
- 하부 덱 WL별 스트링 저항 TEG 트렌드 관리.
- 차세대 단수에서는 덱 수 증가(2 → 3덱) 또는 극저온 식각 도입 검토.

> **[아이디어]** twisting은 홀 내부 충전이 근본이다. 홀 내부 전하를 중화하려면 (1) 전자빔이나 음이온 플라즈마를 off 구간에 주입, (2) 저주파(kHz) 펄스로 전자가 홀 바닥까지 도달할 시간을 확보, (3) 도전성 라이너를 마스크에 도입해 전위 균일화 등이 논의된다. 극저온 식각(−70°C 이하)은 폴리머 없이 물리흡착 층으로 측벽을 보호해 charging 경로를 바꿀 수 있어 유망하다.

## 7. 응용·심화(최신 이슈)

### 7.1 극저온 식각(Cryogenic Etch)

웨이퍼를 −40~−100°C로 냉각한 상태에서 식각하는 기술이다. 원리는 저온에서 반응 가스(HF, 불화 탄소, 수분 등)가 측벽에 물리 흡착해 별도 폴리머 없이 측벽을 보호하고, 바닥은 이온으로 활성화된다. 장점은 (1) HAR 산화막 식각 속도가 기존 대비 2~3배, (2) 폴리머 축적이 적어 clogging·etch stop 감소, (3) 마스크 선택비 향상이다. NAND 300단 이상 채널 홀에서 채택이 확대되고 있다. 단점은 ESC 냉각 인프라, 온도 균일도, 흡착 층 제어의 재현성이다.

### 7.2 펄스 플라즈마와 다중 주파수

- 소스 펄싱: 플라즈마 밀도를 주기적으로 끄면 off 구간에서 전자 온도가 급락해 음이온이 늘고, 충전이 중화된다. charging damage·notching·twisting 완화.
- 바이어스 펄싱: 이온 에너지를 주기적으로 끊어 마스크 소모와 충전을 줄인다. 듀티 20~60%.
- 동기 펄싱: 소스와 바이어스를 위상 차를 두고 펄싱해 원하는 이온 에너지 분포(IEDF)를 조각한다.
- Tailored waveform bias: 정현파 대신 톱니파·펄스 DC를 가해 이온 에너지를 단일 에너지(mono-energetic)로 만든다. HAR 바닥 도달성과 선택비를 동시에 확보.

### 7.3 원자층 식각(ALE)

증착의 ALD에 대응하는 개념이다. (1) 표면 개질(예: Cl₂ 흡착으로 Si 표면 한 층 염화), (2) 저에너지 Ar⁺ 이온으로 개질층만 제거, 두 스텝을 반복한다. 사이클당 제거량이 0.1~1 nm로 일정해 두께 제어가 극히 정밀하고, 손상층이 얇으며, 로딩 효과가 거의 없다. 게이트 스페이서, FinFET/GAA 채널 리세스, DRAM 게이트 산화막 근처의 정밀 식각에 쓰인다. 단점은 처리량(사이클당 수 초~수십 초).

### 7.4 3D DRAM과 수평 식각

4F² VCT(Vertical Channel Transistor)나 3D DRAM(셀을 수직으로 적층)에서는 NAND처럼 Si/SiGe 교대 적층을 한 뒤, SiGe만 선택적으로 옆으로 제거하는 수평(lateral) 식각이 필요하다. 이 식각은 (1) SiGe:Si 선택비 100:1 이상, (2) 수평 깊이 수백 nm를 균일하게, (3) 남은 Si 층이 얇아(10~20 nm) 손상 없이 진행해야 한다. 습식(HF/H₂O₂/아세트산 계열)과 원격 플라즈마 건식 모두 연구된다. PE 관점에서는 층별(수직 위치별) 수평 리세스 깊이 편차가 그대로 층별 셀 커패시턴스·Vt 편차로 나타난다.

### 7.5 EUV 패턴과 식각의 결합

EUV 리소그래피는 레지스트가 얇아(20~40 nm) 마스크 예산이 극히 부족하다. 그래서 식각은 (1) 얇은 레지스트를 하드마스크로 전사하는 "패턴 전사 식각"에서 LER/LWR을 오히려 줄여야 하고(스무딩 효과), (2) 확률적 결함(stochastic defect: 미개구 홀, 브리지)을 식각에서 키우지 않아야 한다. 식각 중 폴리머 재증착을 이용해 CD를 줄이는 트리밍/슈링크 기술이 함께 쓰인다.

### 7.6 HBM/TSV 식각

HBM의 TSV(Through Silicon Via)는 직경 5~10 μm, 깊이 50~100 μm(종횡비 10:1 안팎)의 Si 딥 식각이다. Bosch 공정(SF₆ 식각과 C₄F₈ 증착을 교대)으로 측벽에 스캘럽(scallop, 물결 모양)이 생기는데, 스캘럽이 크면 라이너 산화막·배리어 증착이 불연속이 되어 Cu 누설·신뢰성 문제가 된다. 스캘럽 깊이 100 nm 이하로 관리하고, 극저온 Si 식각으로 스캘럽 없는 측벽을 만들기도 한다. TSV 식각 후 Si 손상층과 응력이 인접 트랜지스터 특성(keep-out zone)에 영향을 준다.

### 7.7 300단 이상 NAND의 식각 한계

- 단일 덱으로 뚫을 수 있는 종횡비 한계(약 100:1 근방)를 넘기면서 덱 수가 늘어난다. 덱 접합부 CD 확대(landing pad)와 오버레이가 셀 특성 불연속을 만든다.
- 마스크: 탄소 하드마스크 두께가 2~3 μm에 이르러 마스크 자체의 wiggling(휘어짐)과 응력 문제가 생긴다. 금속 함유 하드마스크, 보론 도핑 탄소 등이 대안.
- 식각 시간이 수십 분에 이르러 처리량과 챔버 안정성이 원가에 직결된다. 극저온 식각과 고출력 바이어스(10 kW 이상)가 대응 기술.

### 7.8 식각 균일도의 APC

CD·깊이 균일도를 유지하기 위해 다음 제어가 결합된다.

- 피드포워드: 리소그래피 CD 맵을 받아 식각 트리밍 시간을 사이트별로 조정(ESC 멀티존 온도 활용).
- 피드백: 식각 후 CD-SEM/OCD 결과로 다음 로트 레시피 미세 조정.
- FDC/센서: OES, 임피던스, 바이어스 전압, ESC 온도, He 배면 압력 등 수백 개 신호를 실시간 감시해 이상 챔버를 조기 격리.
- 챔버 매칭: 동일 레시피의 챔버 간 결과 차이를 부품 상태·튠 값으로 보정.

### 7.9 PE가 식각 개선을 요청하는 방식

PE는 레시피를 직접 바꾸지 않는다. 대신 "어떤 전기 특성이, 어떤 웨이퍼 위치·패턴에서, 어떤 구조 변화와 상관을 보이는가"를 데이터로 제시하고 식각 팀이 변수 방향을 정한다. 효과적인 요청서의 요소는 다음과 같다.

- 증상의 정량화: fail 비율, 특성 shift 크기, 규격 대비 마진(예: tWR 마진 −15%).
- 공간 분포: 웨이퍼 맵(센터/에지/방위), 다이 내 위치(셀/페리, 어레이 가장자리), NAND 층 방향.
- 구조 상관: X-SEM/OCD 수치와 전기 특성의 회귀(예: 바닥 CD 1 nm 당 Rc 6% 증가).
- 챔버·시간 상관: 챔버 ID, 소모품 수명 구간, 세정 주기 위치.
- 요구 방향: "바닥 CD +3 nm, bow CD 증가 없이" 같이 상충 조건을 명시.

> **[주의]** 전기 특성 하나가 흔들리면 식각만 의심하기 쉽지만, 같은 구조 변화는 증착 두께나 리소 CD에서도 온다. 리소 CD 맵과 증착 두께 맵을 먼저 배제해야 식각 팀과의 논의가 빨라진다.

> **[면접]** "HAR 식각이 왜 어려운가?"에는 "결론: 깊어질수록 바닥까지 에너지와 반응물을 전달하기 어렵고, 그 과정에서 프로파일과 위치가 흔들리기 때문입니다. 근거는 세 가지, 이온 각도 분포·라디칼 수송 제한·홀 내부 충전입니다. 이 셋이 각각 ARDE, etch stop, twisting을 만듭니다. 예를 들어 NAND 채널 홀 100:1에서는 이온이 1°만 기울어도 바닥에 못 닿고, 하부 충전으로 홀이 비틀려 스트링 오픈이 됩니다. 대응은 저압·고바이어스·펄싱·극저온 식각과 덱 분할입니다."

## 8. 셀프 체크 질문

### 8.1 개념 (5)

1. 이방성 식각이 가능한 물리적 이유를 설명하라.
- 답: 결론은 시스에서의 수직 이온 가속과 측벽 보호막의 조합이다. 플라즈마는 웨이퍼보다 양전위이고 그 차이가 얇은 시스에 집중되어 이온이 표면에 거의 수직으로 입사한다. 바닥은 이온 충격으로 화학 반응이 촉진되고, 측벽은 이온이 거의 닿지 않으며 CF 폴리머 등 보호막이 라디칼의 등방성 식각을 막는다. 예를 들어 바이어스 파워를 올리면 이온 에너지가 커져 이방성이 좋아지지만 마스크 소모와 손상이 함께 커진다.

2. 선택비의 정의와, 마스크 두께 예산을 어떻게 계산하는지 예를 들어 설명하라.
- 답: 선택비는 목표막 식각 속도를 마스크(또는 하부막) 속도로 나눈 값이다. 마스크 최소 두께는 (목표 깊이 × 오버에치 계수) / 선택비에 패싯 여유를 더한 값이다. 예로 산화막 2 μm를 20% 오버에치로 식각하고 탄소 마스크 선택비가 15:1이면 소모량 160 nm, 여유 포함 200~250 nm가 필요하다. 하부막 선택비도 같은 논리로, 10:1에 20% 오버에치면 하부막이 목표 깊이의 2%만큼 깎인다.

3. 습식 식각과 건식 식각의 장단점을 비교하고 각각 어디에 쓰이는지 말하라.
- 답: 습식은 순수 화학 반응으로 선택비가 매우 높고 손상이 없지만 등방성이라 CD 제어가 안 된다. 건식은 이온 충격을 이용해 이방성과 nm 수준 CD 제어가 가능하지만 선택비가 낮고 이온·UV·전하 손상이 있다. 그래서 패턴 형성은 건식, 막 전체 제거·세정·희생막 제거는 습식이다. 예로 DRAM 커패시터 몰드 산화막 제거는 HF 습식, NAND 질화막 희생층 제거는 고온 인산이다.

4. ARDE(RIE lag)가 무엇이고 왜 생기는가?
- 답: 종횡비가 클수록 식각 속도가 느려지는 현상이다. 원인은 세 가지다. 이온 각도 분포로 기울어진 이온이 측벽에 막히고, 중성 라디칼은 Knudsen 확산으로 바닥 도달 플럭스가 깊이에 반비례해 줄고, 홀 상부에 전자·바닥에 이온이 쌓여 충전 전위가 이온을 감속한다. 결과적으로 같은 웨이퍼에서 작은 홀이 덜 파여 오픈 불량은 작은 CD에서 먼저 난다.

5. 소스 파워와 바이어스 파워는 각각 무엇을 제어하는가?
- 답: 소스 파워는 플라즈마 밀도, 즉 라디칼과 이온의 양을 제어해 식각 속도와 화학 성분을 결정한다. 바이어스 파워는 웨이퍼 시스 전압, 즉 이온 에너지를 제어해 이방성·바닥 도달성·마스크 소모·손상을 결정한다. 둘을 분리한 것이 현대 식각 장비의 핵심이다. 예로 소스만 올리면 속도는 오르지만 등방성 성분이 늘어 CD가 커지고, 바이어스만 올리면 프로파일은 수직해지지만 선택비가 떨어진다.

### 8.2 응용 (5)

6. 커패시터 홀 식각 후 웨이퍼 센터에서만 2-bit fail이 늘었다. 무엇을 의심하고 어떻게 검증하겠는가?
- 답: 결론은 센터 bowing에 의한 인접 전극 브리지를 먼저 의심한다. 근거로 2-bit fail은 인접 셀 단락의 시그니처이고, 센터 집중은 플라즈마 밀도·ESC 온도의 반경 방향 분포를 시사한다. 검증은 OCD bow CD 센터-에지 비교, fail 사이트 X-SEM으로 인접 홀 간 잔여 몰드 두께 확인, ESC 존 온도 로그 점검이다. 유전체 증착 두께 맵도 확인해 증착 원인을 배제한다.

7. 게이트 식각 후 안테나 비율이 큰 트랜지스터에서만 Vt shift가 나타났다. 원인과 대책은?
- 답: 결론은 plasma charging damage다. 안테나 비율에 비례하는 Vt shift는 배선이 모은 플라즈마 전하가 게이트 산화막을 통해 방전되며 트랩을 만든 전형적 시그니처다. 원인은 오버에치나 ash 스텝에서의 전자 shading 불균일이나 플라즈마 비균일이다. 대책은 펄스 플라즈마, 저밀도 마감 스텝, 안테나 비율 설계 규칙, 보호 다이오드, 후속 수소 어닐이다. 검증은 스플릿 실험과 GOI Qbd 분포다.

8. NAND 하층 셀이 상층보다 프로그램이 빠르다. 식각 관점에서 해석하라.
- 답: 채널 홀 하부 CD가 작아진(taper) 결과로 해석한다. 홀이 좁으면 채널 곡률이 커져 터널 산화막 전계가 집중되고 프로그램 속도가 빨라진다. WL별 프로그램 루프 수가 층 방향 프로파일의 전기적 지표가 된다. 대책은 식각 후반부 바이어스 증가나 O₂ 소량 증가로 바닥 CD를 확보하는 taper 보정이며, 동시에 bowing이 커지지 않도록 X-SEM으로 확인한다.

9. 특정 식각 챔버 로트에서만 에지 미개구가 늘었다. 챔버에서 무엇을 먼저 보겠는가?
- 답: 엣지 링 소모 상태를 먼저 본다. 엣지 링이 얇아지면 에지 시스가 왜곡되어 이온이 tilting하고 에지 플라즈마 밀도가 떨어져 ARDE와 겹쳐 바닥 도달이 지연된다. 검증은 에지 X-SEM의 tilting 각도와 깊이 비교, 엣지 링 두께 측정, 교체 후 재현 여부다. 함께 ESC 에지 존 온도, 가스 분배, 하드마스크 에지 두께도 확인한다.

10. 식각 후 CD-SEM은 정상인데 접촉 저항 TEG가 높다. 어떤 결함을 의심하는가?
- 답: 상부 CD는 정상이므로 바닥 CD 부족(taper), 바닥 잔막(footing, 폴리머 잔사), 손상층을 의심한다. CD-SEM은 상부만 보기 때문이다. 검증은 OCD의 바닥 CD 파라미터, X-SEM/TEM의 바닥 형상과 잔막, EDX로 잔사 성분 확인이다. 대책은 오버에치나 clearing 스텝 조정, 세정 강화, 저에너지 마감 스텝이다.

### 8.3 심화 (5)

11. 극저온 식각이 HAR 식각에서 유리한 이유를 메커니즘 수준에서 설명하라.
- 답: 저온에서는 반응 가스와 생성물이 측벽에 물리 흡착해 폴리머 없이 측벽을 보호하고, 바닥은 이온 에너지로 흡착층이 활성화되어 식각된다. 폴리머 축적이 적으니 clogging·etch stop이 줄고 바닥 도달 라디칼 플럭스가 유지되어 속도가 2~3배 빨라진다. 마스크 위 폴리머도 적어 선택비도 개선된다. 대신 온도 균일도 1°C 수준 제어와 흡착층의 재현성이 관리 과제다.

12. 펄스 플라즈마가 charging damage와 twisting을 줄이는 원리는?
- 답: 소스 펄스 off 구간에 전자 온도가 급락해 전자가 홀 안으로 확산해 바닥의 양전하를 중화하고, 음이온도 생성되어 전하 균형을 돕는다. 바이어스 펄스는 이온 플럭스가 끊기는 동안 축적 전하가 풀리게 한다. 홀 내부 전위 불균일이 줄면 이온 궤도 편향(twisting, notching)과 게이트 산화막 방전(charging damage)이 함께 감소한다. 듀티 40~60%에서 속도 손실 대비 효과가 크다.

13. ALE의 사이클 구조와, 기존 RIE 대비 소자에 유리한 점을 말하라.
- 답: 표면 개질(반응종 흡착으로 한 층만 약화)과 저에너지 이온으로 그 층만 제거하는 두 스텝을 반복한다. 사이클당 제거량이 자기 제한적이어서 두께 제어가 0.1~1 nm 단위이고, 이온 에너지가 낮아 손상층이 얇으며, 로딩 효과가 거의 없다. GAA 채널 리세스나 게이트 산화막 인접 스페이서 식각에서 Vt 산포와 접합 누설 개선에 기여한다. 처리량이 낮은 것이 단점이다.

14. 3D DRAM의 수평 SiGe 식각에서 PE가 관리해야 할 지표는?
- 답: 층별(수직 위치별) 수평 리세스 깊이와 잔류 Si 층 두께 균일도다. 이 깊이가 셀 트랜지스터 채널·커패시터 면적을 결정하므로 편차가 층별 Vt·Cs 산포로 직결된다. 선택비(SiGe:Si 100:1 이상)와 Si 표면 손상도 관리 대상이다. 계측은 X-TEM 층별 리세스, 전기적으로는 층별 셀 특성 TEG다.

15. TSV Bosch 식각의 스캘럽이 HBM 신뢰성에 미치는 영향은?
- 답: 스캘럽이 크면 라이너 산화막과 배리어 금속이 측벽에 불연속으로 증착되어 Cu 확산·누설 경로가 생기고, 응력 집중으로 크랙이 생길 수 있다. 결과는 TSV 간 누설, 인접 트랜지스터 특성 변동(keep-out zone 증가), 열 사이클 신뢰성 저하다. 대책은 사이클 시간 단축, 극저온 Si 식각, 후속 스무딩이다.
