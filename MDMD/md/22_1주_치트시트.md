# 22. 1주일 치트시트와 암기 카드

## 0. 사용법

이 장은 읽는 장이 아니다. 백지에 다시 그려내는 장이다.
매일 아침 해당 Day의 절을 백지에 재현하고, 저녁에 이 장과 대조해 빠진 칸을 채운다.
문장은 짧다. 숫자는 대략값이다. 확실치 않은 값은 범위로 적었다.

| Day | 재현 범위 | 관련 절 | 관련 챕터 |
|---|---|---|---|
| 1 | 공식, 자릿수, 소자 한 줄 | 1, 2 | 01, 02 |
| 2 | DRAM 전부 | 3 | 02, 13 |
| 3 | NAND 전부 | 4 | 02, 14 |

> **[핵심]** 백지 재현 기준은 "표의 첫 열을 보고 나머지 열을 채울 수 있는가"다. 첫 열조차 못 쓰면 그 절을 다시 읽는다.

## 1. 공식과 자릿수

### 1.1 기초 공식 카드

| 공식 | 뜻 | 대표 값 |
|---|---|---|
| E_g(Si) = 1.12 eV | 밴드갭 | Ge 0.66, GaAs 1.42 |
| kT = 26 meV (300 K) | 열에너지 | 85 °C에서 약 31 meV |
| n_i ≈ 1×10^10 /cm3 | Si 진성 캐리어 | 10 °C당 약 2배 |
| n·p = n_i² | 질량작용 법칙 | 도핑 10^17이면 소수 10^3 |
| σ = q(n·μ_n + p·μ_p) | 전도도 | μ_n 1400, μ_p 450 cm2/V·s |
| V_th = V_FB + 2φ_F + Q_dep/C_ox | 문턱전압 | 0.3~0.7 V |
| C_ox = ε_ox/t_ox | 산화막 정전용량 | t_ox 2 nm → 1.7 µF/cm2 |
| EOT = t_hk × 3.9/k_hk | 등가 산화막 두께 | HfO2 3 nm, k 22 → 0.53 nm |
| I_D,sat = (1/2)·μ·C_ox·(W/L)·(V_GS − V_th)² | 포화 전류 | 롱채널 근사 |
| SS = ln10·(kT/q)·(1 + C_dep/C_ox) | 서브스레숄드 스윙 | 한계 60 mV/dec |
| I_off ∝ 10^(−V_th/SS) | 오프 누설 | Vt 100 mV 하락 → 10배 |
| C = ε_0·ε_r·A/d | 커패시터 | DRAM 셀 약 10 fF |
| Q = C·V | 저장 전하 | 10 fF × 1 V = 10 fC |
| ΔV_BL = ΔV·C_s/(C_s + C_BL) | 전하 공유 | 약 80~100 mV |
| τ = R·C | 지연 | 배선 RC |

| Y = exp(−A·D) | 포아송 수율 | A 1 cm2, D 0.1 → 90% |
| R = k1·λ/NA | 해상도 | EUV 13.5 nm, NA 0.33 |
| DOF = k2·λ/NA² | 초점 심도 | NA 오르면 급감 |
| RR = K·P·V | 프레스턴(CMP) | 압력·속도 비례 |
| x_ox² + A·x_ox = B(t + τ) | Deal-Grove | 얇으면 선형, 두꺼우면 포물선 |
| R_p ∝ E | 주입 깊이 | B 10 keV → 약 35 nm |
| θ = ΔT/P | 열 저항 | 단위 K/W |
| q = −k·∇T | 푸리에 열전도 | Si k 약 150 W/m·K |
| FIT = 고장 수 / (10^9 소자·시간) | 고장률 | 서버 목표 수십 이하 |

| 항목 | 값 |

| tREFW (85 °C 초과) | 32 ms |

### 3.5 DRAM 동작 순서 카드

1. 프리차지: BL과 BLB를 VDD/2로.
2. ACT: WL을 VPP로 올림, 셀 전하 공유, ΔV 약 80~100 mV.
3. 센싱: SA가 차이를 VDD와 0으로 증폭(tRCD 대부분).
4. RD/WR: 컬럼 선택, 데이터 이동.
5. 복원: 증폭된 값이 셀에 다시 채워짐(tRAS 안).
6. PRE: WL을 VBB로 내리고 BL을 VDD/2로(tRP).

### 4.4 NAND 열화 방향 카드

| 현상 | Vt 이동 방향 | 가장 취약한 상태 | 원인 |
|---|---|---|---|
| Retention 손실 | 아래로 | 최상위 상태 | 트랩 방출, SILC, 측면 이동 |
| Read disturb | 위로 | 이레이즈 상태 | Vpass 약한 프로그램 |
| Program disturb | 위로 | 이레이즈 상태 | 부스팅 누설 |
| 사이클링 | 분포 넓어짐 | 전체 | 터널 산화막 트랩 |
| 초기 전하 손실 | 아래로(수 초~분) | 프로그램 직후 | 얕은 트랩 |
| Cross temperature | 양방향 | 전체 | 프로그램·읽기 온도 차 |

### 4.5 NAND 동작 순서 카드

1. Erase: 블록 선택, 바디 약 20 V, WL 0 V, 모든 셀 이레이즈 상태.
2. Program: 페이지 선택, ISPP 펄스 → verify 반복, 상태별 목표 Vt 도달.
3. Read: Vref를 상태 사이에 두고 Vpass로 나머지 WL 통과, 스트링 전류 판정.
4. Read retry: 분포 이동 시 Vref 조정 후 재읽기.
5. ECC: 남은 오류 정정, 실패 시 soft decoding.

### 모의 7. 본인 보고서 오류로 잘못된 조치가 시작되었다. 어떻게 하는가. (STAR)

| 항목 | 내용 |
|---|---|
| S | 좌표 변환 오류, 잘못된 챔버 점검 시작 |
| T | 손실 최소화, 신뢰 회복 |
| A | 즉시 공개 → 영향 범위 명시 → 같은 날 수정본 → 절차 개선 |
| R | 조치 중단, 실제 원인 도달, 이중 검토 절차 |
| 함정 | 조용히 수정, 개인 실수로만 마무리 |

### 모의 채점 후 행동

| 점수 | 행동 |
|---|---|
| 90 이상 | 다음 문항 |
| 70~89 | 빠진 항목만 21장에서 다시 읽고 재녹음 |
| 70 미만 | 해당 카테고리 절(3~9절) 백지 재현 후 재도전 |

## 13. 백지 재현 체크리스트

각 항목을 백지에 쓸 수 있으면 체크한다. 못 쓰면 해당 절로 돌아간다.

### 13.1 Day1

- 공식 카드 1.1의 왼쪽 열 20개 이상
- 자릿수 카드 1.2의 왼쪽 열을 보고 오른쪽 값
- Vt 식과 네 요소
- 누설 네 종류와 각 원인

### 13.2 Day2

- DRAM 동작 6단계 순서
- 타이밍 6개(tRCD, tRP, tRAS, tWR, tRFC, tREFI) 정의와 값
- 전압 카드(VDD, VPP, VBB, VBLP)
- Retention 3원인, VRT, Row Hammer 숫자
- Fail 패턴 5종과 원인

### 13.3 Day3

- NAND 셀 스택 5층과 두께
- 동작 전압 표(Program, Erase, Read) 세 행
- TLC/QLC 상태 수, 간격, P/E
- 열화 4종의 방향과 취약 상태
- 블록·페이지·짝 블록 fail 원인

### 13.4 Day4

- 8대 공정 한 줄 각각
- 공정별 변수 → 영향 표에서 각 공정 2행 이상
- 공정별 결함 3개와 원인·검출·대책
- EUV 숫자 4개, 식각 트레이드오프, ALD 원리, 임플란트 4변수

### 13.5 Day5

- 맵 형태 → 공정 표 10행
- DRAM shift → 변수 표 10행
- NAND shift → 변수 표 8행
- 의존성 → 메커니즘 표 전부
- FA 순서와 EFA 3종, FIB 손상, 대조군

### 13.6 Day6

- HBM 숫자 카드 10행
- 본딩 3방식 비교
- 열전도율 5개, Ea 4개, 신뢰성 시험 조건 4개
- 답변 골격 5단, STAR 4단, 금지 표현 5개

### 13.7 Day7

- 모의 7문항 녹음 후 채점 평균 80 이상
- 21장 숫자 카드 64개 중 50개 이상 즉답
- 21장 함정 표에서 자기 함정 3개 확인

> **[핵심]** 백지 재현에 실패한 칸이 곧 면접장에서 막히는 칸이다. 채우지 못한 칸만 21장으로 돌아가 60초 모범을 다시 소리 내어 읽는다.

> **[면접]** 마지막 날 밤에는 새 내용을 넣지 않는다. 숫자 카드 1.2와 답변 골격 10절만 한 번 더 보고 잔다. 시험 직전에는 "결론부터, 숫자 하나, PE 관점으로 마무리" 세 단어만 되새긴다.
