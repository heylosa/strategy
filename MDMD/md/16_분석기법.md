# 16. 분석 기법 (인라인·전기·FA)

## 1. 한눈에 보기

### 1.1 왜 PE에게 중요한가

- PE(Product Engineering)의 일은 "제품에서 관찰된 이상"을 "공정·설계의 원인"으로 되돌리는 것이다. 그 사이를 이어 주는 유일한 다리가 분석(analysis)이다. 분석 기법을 모르면 가설은 세워도 검증할 수 없다.
- 분석은 세 층으로 나뉜다. 인라인(in-line) 계측·검사는 공정 중에 "지금 만들어지는 것"을, 전기(electrical) 분석은 완성된 다이가 "어떻게 동작하는가"를, 물성 FA(Failure Analysis)는 불량 위치를 열어 "무엇이 실제로 거기 있는가"를 본다. PE는 이 셋을 순서대로, 그리고 서로 대조해 쓴다.
- 분석 하나가 수십만 원에서 수천만 원, 수 시간에서 수 주가 든다. 어느 기법을 어떤 순서로 쓰느냐가 트러블슈팅 속도와 비용을 결정한다. "가장 싸고 빠른 비파괴 기법부터, 가장 비싸고 느린 파괴 기법으로"가 원칙이다.
- 잘못 고른 기법, 잘못 준비한 시편은 존재하지 않는 결함을 만들어 내거나(아티팩트, artifact) 진짜 결함을 지운다. 오진(misdiagnosis) 한 번이면 공정팀이 엉뚱한 변수를 몇 주 동안 흔들게 된다. 기법의 한계를 아는 것이 기법 자체를 아는 것보다 중요하다.
- A!SK에서 "불량 분석 절차를 설명하라", "SEM과 TEM의 차이", "비파괴 분석에는 무엇이 있나", "웨이퍼맵을 보고 다음에 무엇을 할 것인가"는 PE 직무 문항의 단골이다.

### 1.2 핵심 키워드

| 용어 | 한 줄 정의 |
|---|---|
| 계측(metrology) | 치수·두께·조성 등 수치를 재는 것. 정밀도(precision)와 정확도(accuracy)로 평가 |
| 검사(inspection) | 결함의 존재와 위치를 찾는 것. 감도(sensitivity)와 포착률(capture rate)로 평가 |
| CD-SEM | 저에너지 전자빔으로 패턴 선폭(Critical Dimension)을 재는 인라인 SEM |
| OCD(Optical CD) | 분광 산란 스펙트럼을 모델에 피팅해 CD·높이·측벽각을 비파괴로 재는 기법 |
| 오버레이(overlay) | 현재 층 패턴과 아래 층 패턴의 위치 어긋남. 1x nm DRAM에서 허용 수 nm |
| BF/DF 검사 | 명시야(Bright Field)/암시야(Dark Field) 광학 결함 검사. 패턴 웨이퍼 결함의 주력 |
| e-beam 검사 | 전자빔 기반 결함 검사. 수 nm 감도, 전기적(VC, voltage contrast) 결함 검출 가능 |
| PCM/WAT | 스크라이브 라인 테스트 소자 전기 측정. 공정과 제품을 잇는 첫 전기 데이터 |
| FBM(Fail Bit Map) | 불량 비트의 어레이 내 위치 지도. 단일 비트·행·열·블록 패턴으로 원인 분류 |
| Shmoo | 두 변수(전압·타이밍 등)를 축으로 pass/fail 영역을 그린 2차원 지도 |
| FIB(Focused Ion Beam) | 집속 이온빔으로 국소 단면 가공·TEM 시편 제작·회로 수정 |
| TEM/STEM | 투과 전자 현미경. 0.1 nm급 분해능, 원자 배열·박막 두께·계면 관찰 |
| EDX/EELS | 특성 X선/전자 에너지 손실로 조성 분석. EELS는 경원소·결합 상태에 강함 |
| SIMS | 이차 이온 질량분석. 도펀트 깊이 프로파일, ppm~ppb 검출 한계 |
| EMMI/OBIRCH | 발광 현미경/레이저 유도 저항 변화. 누설·쇼트 위치를 비파괴로 지목 |
| 나노프로빙(nanoprobing) | 디레이어(delayer) 후 개별 트랜지스터·컨택에 탐침을 대고 I-V 측정 |
| 아티팩트(artifact) | 시편 준비나 측정 자체가 만든 가짜 신호. 오진의 주범 |

## 2. 기초

### 2.1 분석은 3계층이다

```text
  +----------------------+   +----------------------+   +----------------------+
  |  In-line metrology / |   |  Electrical analysis |   |  Physical FA         |
  |  inspection          |   |                      |   |                      |
  |  "what is being made"|-->|  "how does it behave"|-->|  "what is really     |
  |  CD, OVL, THK, DEF   |   |  PCM, EDS FBM, shmoo |   |   there"             |
  |  during process      |   |  I-V, C-V, noise     |   |  SEM/TEM/EDX/SIMS    |
  +----------------------+   +----------------------+   +----------------------+
    fast, non-destructive       fast~medium, mostly       slow, mostly
    100% or sampled             non-destructive           destructive, N=1~10
```

- 인라인은 웨이퍼가 공정 중일 때 찍는다. 빠르고 파괴하지 않으므로 많이 찍을 수 있다. 대신 "이 CD가 제품 불량을 일으킬지"는 직접 말해 주지 않는다.
- 전기 분석은 소자가 완성된 뒤(PCM은 M1 이후, EDS는 전 공정 완료 후) 동작을 본다. 제품 불량과 직접 연결되지만 "어디가 어떻게 깨졌는지"는 간접 추론이다.
- 물성 FA는 불량 위치를 물리적으로 열어 본다. 가장 확실하지만 가장 느리고 비싸며 시편을 잃는다. 표본 수가 1~10개이므로 통계적 대표성이 없다.

> **[핵심]** 세 층 중 하나만 보면 반드시 틀린다. 인라인은 "가능성", 전기는 "증상", FA는 "한 점의 실체"다. 세 층이 같은 이야기를 할 때만 근본 원인이라고 부른다.

### 2.2 파괴 vs 비파괴, 비용과 시간

| 구분 | 대표 기법 | 시편 상태 | 대략 소요 | 대략 비용(1건) | 표본 수 |
|---|---|---|---|---|---|
| 비파괴 인라인 | CD-SEM, OCD, 엘립소, BF/DF, 파티클 | 그대로 다음 공정 진행 | 웨이퍼당 수 분 | 장비 감가 외 미미 | 웨이퍼 전수~샘플 |
| 비파괴 전기 | PCM, EDS, FBM, shmoo | 그대로(다이는 소팅) | 웨이퍼당 수십 분~수 시간 | 테스트 시간 비용 | 다이 전수 |
| 비파괴 FA | OM, EMMI, OBIRCH, SAT, X-ray, TDR | 패키지·다이 유지 | 수 시간~1일 | 수십만 원대 | 1~수 개 |
| 반파괴 FA | 디캡(decap), 디레이어, 나노프로빙 | 패키지 파손, 다이 일부 층 제거 | 1~3일 | 수십만~수백만 원 | 1~수 개 |
| 파괴 FA | FIB 단면, TEM, SIMS, XPS | 시편 소멸 | 1일~2주 | 수백만 원대 | 1~수 개 |

비용은 회사·외주 여부에 따라 크게 다르므로 예시 값이다. 중요한 것은 순서다. 비파괴로 위치를 최대한 좁힌 뒤 파괴로 들어간다. 위치를 모른 채 FIB로 자르면 확률적으로 결함을 놓치고 시편만 잃는다.

> **[예시]** 16 Gb DRAM 다이 한 개는 대략 60 mm² 안에 약 170억 개 셀이 있다. 단일 비트 불량 하나의 물리적 크기는 수십 nm다. 위치를 모르는 상태에서 FIB로 찾는 것은 축구장에서 모래알 하나를 삽으로 찾는 것과 같다. 그래서 FBM으로 행/열 주소를 얻고, 레이아웃 좌표로 변환하고, EMMI/OBIRCH로 재확인한 뒤에야 FIB를 댄다. 이 순서를 지키면 한 번에 맞히고, 어기면 세 번 잘라도 못 찾는다.

### 2.3 분해능·검출 한계·샘플링

분석 기법을 고를 때 항상 세 숫자를 확인한다.

- 공간 분해능(spatial resolution): 얼마나 작은 것을 구별하나. 광학 현미경 대략 0.2~0.3 μm, SEM 1~3 nm, TEM 0.1 nm 이하.
- 검출 한계(detection limit): 얼마나 적은 양을 감지하나. EDX 대략 0.1~1 at%, XPS 대략 0.1 at%, SIMS ppm~ppb.
- 정보 깊이(information depth): 어디까지 보나. XPS/Auger 표면 수 nm, SEM SE 수 nm~수십 nm, EDX(벌크 SEM) 대략 1 μm, SIMS는 스퍼터하며 깊이 방향 프로파일.

| 기법 | 공간 분해능 | 검출 한계 | 정보 깊이 |
|---|---|---|---|
| OM | 0.2~0.3 μm | 형상만 | 표면 |
| SEM(SE) | 1~3 nm | 형상만 | 수 nm~수십 nm |
| TEM/STEM | 0.05~0.2 nm | 형상·격자 | 시편 두께(50~100 nm) |
| EDX(SEM) | 대략 1 μm | 0.1~1 at% | 대략 1 μm |
| EDX(STEM) | 1~5 nm | 0.5~1 at% | 시편 두께 |
| EELS | 0.1~1 nm | 0.1~1 at%, 경원소 가능 | 시편 두께 |
| SIMS | 수 μm(스폿), 깊이 1~2 nm | ppm~ppb | 스퍼터 깊이 |
| XPS | 10 μm~수백 μm | 0.1~1 at% | 5~10 nm |
| Auger | 10~50 nm | 0.1~1 at% | 1~5 nm |

샘플링 문제도 함께 본다. 웨이퍼 한 장에 CD-SEM 측정점을 9점 찍으면 반경 방향 경향은 보이지만 샷 내 편차는 놓친다. FA에서 다이 1개의 TEM 결과를 로트 전체로 일반화하면 오진이 된다.

> **[주의]** "TEM에서 결함이 보였다"는 "그 다이의 그 위치에 그것이 있었다"까지만 말한다. 같은 불량 시그니처의 다이 3~5개에서 같은 결함이 재현될 때 비로소 "이 불량 모드의 원인"이라고 말할 수 있다.

### 2.4 신호가 생기는 원리: 전자·광자·이온

거의 모든 분석은 "프로브(probe)를 시편에 쏘고 나오는 신호를 읽는다"로 요약된다. 프로브와 신호의 종류가 기법을 결정한다.

```text
                       incident probe
                            |
        +-------------------+---------------------+
        |                   |                     |
     electron             photon                 ion
   (SEM/TEM/CD-SEM)    (OM/ellipso/OCD/         (SIMS/FIB)
        |               Raman/XRD/XPS)             |
        v                   v                      v
  SE  -> topography    reflect/polarize -> THK   sputtered ions -> mass
  BSE -> Z contrast    scatter spectrum -> CD     -> composition vs depth
  X-ray-> composition  photoelectron -> bonding   (destructive)
  EELS-> bonding       diffraction -> crystal
  transmitted-> lattice Raman shift -> stress
```

- 전자가 시편에 들어가면 이차전자(SE, Secondary Electron), 후방산란전자(BSE, Backscattered Electron), 특성 X선, 오제(Auger) 전자, 에너지를 잃은 투과 전자가 나온다. SE는 표면 형상, BSE는 원자번호 대비(무거운 원소가 밝음), X선과 EELS는 조성이다.
- 전자의 침투 깊이는 가속 전압에 비례한다. 1 kV면 수십 nm, 30 kV면 수 μm. 그래서 CD-SEM은 300~800 V의 저에너지로 표면 패턴만 보고, 벌크 EDX는 10~20 kV로 깊게 본다.
- 광자는 표면을 깨지 않는다. 반사·편광 변화(엘립소메트리), 산란 스펙트럼(OCD), 회절(XRD), 비탄성 산란(Raman), 광전자 방출(XPS)로 두께·형상·결정·응력·결합을 읽는다.
- 이온은 시편을 깎는다. 깎이며 나오는 이차 이온의 질량을 분석하면 깊이별 조성(SIMS)이 된다. Ga 또는 Xe 이온빔을 집속하면 국소 가공(FIB)이 된다.

### 2.5 전기 측정 기초

- I-V: 게이트 전압을 훑으며 드레인 전류를 읽는다(Id-Vg). Vt, 서브스레숄드 스윙(SS, subthreshold swing), Ioff, Ion, DIBL을 뽑는다. 선형 영역 Id는 `I_D ≈ μ·C_ox·(W/L)·(V_GS − V_th)·V_DS`, 포화 영역은 `I_D ≈ (1/2)·μ·C_ox·(W/L)·(V_GS − V_th)²`.
- Vt 추출법: 정전류법(예: `I_D = 100 nA × W/L`일 때의 Vg), 선형 외삽법(gm 최대점 접선의 x절편), 상수 gm법. 방법이 다르면 같은 소자라도 Vt가 수십 mV 다르므로 PCM 스펙과 방법을 함께 적어야 한다.
- C-V: 게이트에 DC 바이어스 + 소신호 AC(10 kHz~1 MHz)를 걸어 커패시턴스를 읽는다. 축적(accumulation) 영역 C에서 EOT(Equivalent Oxide Thickness)를, 공핍(depletion) 영역에서 기판 도핑을, 고주파-저주파 차이(또는 컨덕턴스법)에서 계면 트랩 밀도 Dit를 얻는다. `C_ox = ε_ox·A/t_ox`이므로 면적 100 μm × 100 μm, t_ox 2 nm면 C ≈ 3.45 × 10⁻¹¹ × 10⁻⁸ / 2 × 10⁻⁹ ≈ 173 pF.
- 4단자(Kelvin) 측정: 전류 인가 단자와 전압 측정 단자를 분리해 접촉 저항을 배제한다. 컨택 저항 Rc, 면저항 Rs 측정의 기본.
- 면저항(Rs, sheet resistance): 단위 Ω/sq. `R = Rs × (L/W)`. 4점 프로브로 무패턴 웨이퍼 측정, 반데르파우(van der Pauw)나 브리지 구조로 패턴 측정.

> **[예시]** W 컨택 플러그 하나의 저항이 100 Ω 스펙에서 300 Ω로 올랐다. 켈빈 구조 PCM으로 재면 접촉 저항과 플러그 저항이 분리된다. 접촉 저항 증가면 계면 잔류물(세정·에치 문제), 플러그 저항 증가면 보이드나 핵생성층(nucleation layer) 문제로 가설이 갈린다. 측정 구조를 어떻게 설계했느냐가 가설 분기를 결정한다.

### 2.6 분석 결과를 읽는 통계 습관

분석 장비가 준 숫자는 항상 "측정값 = 참값 + 공정 산포 + 측정 오차"다. 세 성분을 분리하지 않으면 측정 오차를 공정 변화로 읽는다.

| 개념 | 정의 | 예시 값 | PE 실무 |
|---|---|---|---|
| 반복성(repeatability) | 같은 조건 같은 점 반복 측정 산포 | CD-SEM 0.3 nm(3σ) | 스펙 대비 P/T 30% 이하 확인 |
| 재현성(reproducibility) | 장비·오퍼레이터·일자 간 산포 | 장비 간 오프셋 0.5 nm | 장비 매칭(matching) 관리 |
| 정확도(accuracy) | 참값(기준 시편)과의 오프셋 | TEM 대비 +1.2 nm | 오프셋 보정, 절대값 비교 금지 |
| 게이지 R&R | 반복성+재현성 합산 | 스펙 폭의 10~30% | 신규 계측 도입 시 필수 |
| 검출력 | 진짜 변화를 잡아낼 확률 | 샘플 9점으로 1 nm shift 검출 | 샘플링 계획 설계 |

- 장비 두 대의 CD가 0.5 nm 다르다면 그것은 공정 차이가 아니라 장비 매칭 문제일 수 있다. 같은 기준 웨이퍼를 두 장비에 돌려 오프셋을 먼저 확정한다.
- 시간 축 추세를 볼 때는 계측 장비 자체의 드리프트(예: 전자빔 열화, 광원 수명)를 기준 시편 일일 측정으로 분리한다.
- "스펙 안"과 "정상"은 다르다. 스펙 안이지만 평균이 3 nm 이동했다면 공정은 이미 변한 것이고 제품 특성도 따라 움직인다. PE는 스펙 판정이 아니라 분포 이동을 본다.

> **[면접]** "계측 데이터가 흔들릴 때 공정 문제인지 계측 문제인지 어떻게 구분합니까?" 1분 답변. "먼저 기준 시편의 같은 기간 측정값을 봅니다. 기준 시편도 같이 움직였으면 계측 장비 드리프트입니다. 기준은 그대로인데 제품만 움직였으면 공정 변화입니다. 다음으로 다른 원리의 계측, 예를 들어 CD-SEM이 흔들리면 OCD, 엘립소가 흔들리면 XRR로 교차 확인합니다. 마지막으로 그 변화가 전기 데이터, 즉 PCM이나 EDS에 같은 방향으로 나타나는지 봅니다. 계측만 움직이고 전기가 그대로면 계측 쪽을, 전기도 같이 움직이면 공정 쪽을 먼저 의심합니다. 계측 능력 지표 P/T가 30%를 넘는 항목은 애초에 작은 변화를 판단할 근거가 약하다는 점도 함께 말합니다."

#### 3.1.2 CD-SEM

- 원리: 300~800 V 저에너지 전자빔을 주사하며 SE 신호 프로파일을 읽는다. 패턴 에지에서 SE 방출이 급증(에지 효과)해 밝은 선이 생기고, 그 간격을 알고리즘(threshold, 예: 50%)으로 CD로 환산한다.
- 성능: 정밀도(반복성) 대략 0.2~0.5 nm(3σ). 절대 정확도는 알고리즘·빔 조건에 따라 수 nm 오프셋이 있어 TEM 단면과 매칭(캘리브레이션)한다.
- 핵심 변수: 가속 전압(높으면 침투 깊어 하부 정보 섞임), 빔 전류(높으면 S/N 좋지만 손상), 프레임 수(적분 횟수), 배율, 측정 알고리즘.
- 함정: 레지스트 수축(shrinkage). ArF 레지스트는 전자빔 1회 조사에 대략 1~3 nm 줄어든다. 같은 점을 두 번 재면 두 번째가 작다. EUV 레지스트는 얇아 더 민감하다. 차징(charging)으로 상이 흐르거나 CD가 편향된다.
- 부가 정보: LER(Line Edge Roughness)/LWR(Line Width Roughness). 1x nm DRAM 워드라인 LWR 3σ 대략 1~2 nm 수준이 관리 대상이다.

> **[예시]** DRAM 액티브 CD 타깃 20 nm, 스펙 ±1.5 nm. CD-SEM 반복성 0.3 nm(3σ)면 측정 불확도가 스펙의 20%다. 계측 능력 지표 P/T(Precision/Tolerance) = 0.3/3.0 = 10%. 일반적으로 P/T 30% 이하를 요구하므로 사용 가능. 스펙이 ±0.5 nm로 조여지면 P/T가 30%로 한계에 닿아 OCD 병행이나 프레임 수 증가가 필요하다.

#### 3.1.3 OCD(Optical Critical Dimension, scatterometry)

- 원리: 주기 패턴에 광대역(대략 200~1,000 nm) 편광 빛을 쏘고 반사 스펙트럼(엘립소메트리 파라미터 Ψ, Δ 또는 뮐러 행렬)을 받는다. RCWA(Rigorous Coupled-Wave Analysis) 등으로 모델 구조의 스펙트럼을 계산해 실측과 피팅, 구조 파라미터(CD, 높이, 측벽각, 하부 막 두께)를 역산한다.
- 장점: 3D 프로파일을 비파괴로, 점당 수 초에. 매립 구조(예: 리세스 게이트 깊이, 캡 홀 바닥 CD)를 볼 수 있어 CD-SEM이 못 보는 것을 본다.
- 한계: 모델이 틀리면 답도 틀린다. 파라미터 간 상관(correlation)이 높으면 CD가 변한 것을 높이 변화로 잘못 피팅한다. 새 구조·새 재료마다 모델을 세우고 TEM으로 검증해야 한다.
- PE 관점: OCD 결과가 흔들리면 "정말 구조가 변했나, 모델이 깨졌나"를 먼저 묻는다. 예: 하부 막 굴절률이 공정 변경으로 바뀌면 OCD가 CD 변화로 오보한다.

#### 3.1.4 오버레이(overlay)

- 정의: 현재 층 패턴 중심과 기준(하부) 층 패턴 중심의 위치 차. x, y 각각 측정. 스캐너 보정 모델(선형: 이동, 배율, 회전; 고차: 샷 내 왜곡)의 입력.
- 방식: IBO(Image-Based Overlay, 박스-인-박스 타깃을 광학 이미지로), DBO(Diffraction-Based Overlay, 회절 격자 쌍의 비대칭 세기로). DBO가 더 작은 타깃과 높은 정밀도.
- 성능: 정밀도 대략 0.1~0.3 nm. 하지만 타깃과 실제 소자 패턴 사이 차이(타깃-디바이스 오프셋)와 툴 유도 시프트(TIS, Tool Induced Shift)가 nm 단위로 존재한다.
- 예산: 1x nm DRAM에서 층간 오버레이 허용치는 대략 2~4 nm(3σ)로 알려진다. 워드라인-액티브, 비트라인 컨택-액티브, 스토리지 노드 컨택 등 핀치(pinch) 위험 층이 핵심.
- 검증: 인라인 오버레이 값과 EDS 수율 맵의 상관, 필요하면 e-beam VC 검사나 단면 TEM으로 실제 정렬 확인.

> **[트러블슈팅]** 증상: 특정 샷 열(column)에서 오버레이 x 방향 3 nm 편향, 같은 위치 EDS 수율 저하. 원인: 스캐너 스테이지 그리드(grid) 왜곡 또는 레티클 열팽창. 조치: 스캐너 매칭 재측정, 고차 보정 모델 업데이트, 해당 레티클 교체 여부 판단. 확인: 보정 후 오버레이와 수율 동시 회복.

#### 3.1.5 결함 검사: BF / DF / e-beam

- BF(명시야): 넓은 파장 조명을 수직 입사·정반사 수집. 다이-투-다이(die-to-die) 또는 셀-투-셀 비교로 차이를 결함으로 표시. 패턴 결함(브리지, 오픈, 잔류 레지스트, 패턴 붕괴)에 유효. 감도 대략 20~30 nm.
- DF(암시야): 경사 조명, 산란광만 수집. 파티클·스크래치가 밝게 뜬다. 평탄한 결함(예: 미세 CD 편차)은 놓친다. 감도 대략 10~30 nm(배경 패턴에 따라).
- e-beam 검사: 전자빔 주사 이미지 비교. 광학 한계 이하 결함, 그리고 전압 대비(VC, Voltage Contrast) 결함. 플로팅된 컨택은 차징돼 어둡거나 밝게 튀어 매립 오픈/쇼트를 검출한다. 대신 느려서 웨이퍼 일부 영역(예: 몇 %)만 샘플링하거나 핫스팟(hot spot) 좌표만 찍는다.
- 결함 분류: 검사 장비는 좌표와 크기만 준다. 이어서 리뷰 SEM(review SEM)이 좌표로 가서 고배율 이미지를 찍고 ADC(Automatic Defect Classification)가 브리지·파티클·스크래치 등으로 분류한다.
- 지표: 포착률(capture rate), 뉴슨스율(nuisance rate, 결함이 아닌데 결함이라 표시), 킬러(killer) 비율. 감도를 올리면 뉴슨스가 폭증한다. 레시피 튜닝은 감도와 뉴슨스의 타협이다.
- 킬 비율(kill ratio): 결함 종류별로 그 결함이 있는 다이가 실제 EDS에서 죽는 비율. 인라인 결함 밀도 × 킬 비율 = 예상 수율 손실. PE가 인라인 검사팀과 대화하는 언어다.

> **[예시]** 어떤 층에서 BF 검사 결함 밀도 0.3 ea/cm², 다이 면적 0.6 cm²면 다이당 평균 0.18개. 포아송 모델로 무결함 확률 e^(−0.18) ≈ 0.84. 그런데 킬 비율이 30%라면 실제 수율 손실은 대략 1 − e^(−0.18 × 0.3) ≈ 5%. 킬 비율을 모르면 결함 밀도만으로 수율 영향을 과대·과소 평가한다.

#### 3.1.6 두께 계측: 분광 엘립소메트리, XRR

- 분광 엘립소메트리(SE, Spectroscopic Ellipsometry): 편광된 빛이 박막에서 반사될 때 편광 상태 변화(Ψ, Δ)를 파장별로 측정. 광학 모델(굴절률 n, 소광계수 k)에 피팅해 두께를 얻는다. 게이트 산화막 2 nm를 0.01~0.05 nm 정밀도로 잰다.
- 함정: 두께와 굴절률은 상관이 크다. 막이 얇을수록(수 nm) n을 고정해야 두께가 안정된다. 조성 변화(예: SiON의 N 농도 변화)는 n을 바꿔 두께 오보를 만든다. 다층막(ONO)에서는 각 층 두께가 서로 보상되어 총 두께는 맞아도 개별 두께는 틀릴 수 있다.
- XRR(X-Ray Reflectivity): X선을 임계각 근처 저각으로 입사해 반사율 진동(Kiessig fringe)을 측정. 진동 주기에서 두께, 임계각에서 밀도, 감쇠에서 거칠기를 얻는다. 엘립소가 못 주는 밀도를 준다. 예: ALD TiN 밀도가 5.2에서 4.8 g/cm³로 떨어지면 저항 상승·배리어 성능 저하를 의심한다.
- 기타: XRF(X-Ray Fluorescence)로 금속막 두께·조성(예: W, Cu 두께, SiGe의 Ge 농도). 4점 프로브 Rs로 도핑 웨이퍼 활성화나 금속 두께의 전기적 대리값.

#### 3.1.7 파티클 모니터

- 베어 웨이퍼(모니터 웨이퍼)를 장비에 통과시켜 전후 파티클 수 차이(adder)로 장비 청정도를 본다. 레이저 산란 방식, 감도 대략 20 nm 이상(세대에 따라 더 작게).
- 파티클 맵의 패턴이 원인을 말한다. 중심 집중은 가스 샤워헤드/척, 에지 링은 링·클램프, 직선 흔적은 로봇 암 접촉, 랜덤 증가는 챔버 오염 누적.
- PE 관점: 파티클 adder가 스펙 안이어도 제품에 킬러가 될 수 있다(모니터 웨이퍼와 패턴 웨이퍼의 표면 상태가 다름). 패턴 웨이퍼 BF/DF 결과와 교차 확인한다.

| DIBL | Vt(Vd 저)−Vt(Vd 고) | 수십 mV/V | 채널 길이, 접합 깊이 |
| GIDL | Vg 음, Vd 양 시 누설 | 드레인-게이트 오버랩 영역 | 접합 급준도, 산화막 계면, DRAM 리텐션과 직결 |
| BV | 접합/산화막 파괴 전압 | 접합 수 V~수십 V, GOX 2 nm 대략 3~4 V | 접합 프로파일, 산화막 품질 |

- Id-Vg 곡선의 형태 자체가 진단이다. 험프(hump, 두 번 꺾임)는 채널 코너나 STI 에지의 기생 트랜지스터. 서브스레숄드 기울기 악화는 계면 트랩. 오프 전류가 Vd에 강하게 의존하면 GIDL 또는 펀치스루.
- 게이트 누설(Ig-Vg): 산화막 두께·품질. 직접 터널링 vs 파울러-노드하임(F-N) 영역 구분. 2 nm SiO₂에서 1 V 인가 시 대략 10⁻² A/cm² 수준의 직접 터널링(예시 값).

#### 3.2.2 C-V 분석

- 무엇을 얻나: EOT(축적 C), 기판 도핑 프로파일(공핍 C의 1/C² 기울기), 플랫밴드 전압(일함수·고정 전하), 계면 트랩 밀도 Dit(고저주파법, 컨덕턴스법), 산화막 트랩(히스테리시스).
- 예: 고정 전하 Qf가 1 × 10¹¹ cm⁻² 늘면 플랫밴드가 `ΔV = Q/C_ox`만큼 이동. C_ox가 1.7 μF/cm²(EOT 2 nm)면 ΔV ≈ 1.6 × 10⁻¹⁹ × 10¹¹ / 1.7 × 10⁻⁶ ≈ 9 mV.
- 주파수 분산(frequency dispersion): 1 kHz와 1 MHz의 C가 다르면 계면 트랩이 저주파에 응답한 것. Dit 대략 10¹⁰ cm⁻²eV⁻¹(좋음)~10¹² cm⁻²eV⁻¹(나쁨).
- DRAM 커패시터 C-V: 셀 커패시터(대략 10~20 fF/셀 급, 예시)와 유전체 누설. 인가 전압에 따른 C 변화(비선형)로 유전체 상태 판단.

#### 3.2.3 차지 펌핑(charge pumping)

- 원리: 게이트에 펄스(축적↔반전)를 주면 계면 트랩이 매 주기 전자·정공을 교대로 포획해 기판으로 재결합 전류가 흐른다. `I_cp = q·f·A·D_it·ΔE`. f는 주파수, A는 게이트 면적, ΔE는 스캔되는 에너지 폭.
- 예: f = 1 MHz, A = 10 μm × 1 μm = 10⁻⁷ cm², Dit = 10¹¹ cm⁻²eV⁻¹, ΔE = 0.6 eV → I_cp ≈ 1.6 × 10⁻¹⁹ × 10⁶ × 10⁻⁷ × 10¹¹ × 0.6 ≈ 1 pA. 피코암미터로 잰다.
- 장점: C-V보다 작은 소자에서 Dit를 직접, 감도 좋게. 펄스 상승·하강 시간을 바꾸면 에너지 위치별 트랩 분포도 얻는다. HCI/NBTI 후 계면 손상 정량에 쓴다.

#### 3.2.4 노이즈: 1/f와 RTN

- 1/f(플리커) 노이즈: 산화막 트랩이 캐리어를 포획·방출해 채널 전류가 흔들린다. 스펙트럼 밀도 `S_Id/I_d² ∝ N_t/(f·W·L)`. 트랩 밀도 Nt의 척도. 게이트 산화막 품질, 고유전율 막의 트랩 평가에 쓴다.
- RTN(Random Telegraph Noise): 소자가 작아지면 트랩 1개가 전류를 두 준위로 뛰게 한다. 전류 시간 파형이 계단형. 포획 시간·방출 시간에서 트랩 위치(산화막 깊이)와 에너지를 얻는다.
- 제품 영향: DRAM 셀 트랜지스터 RTN은 리텐션 시간이 시간에 따라 튀는 VRT(Variable Retention Time)로 나타나 리프레시 마진의 꼬리(tail)를 만든다. NAND는 RTN이 Vt 산포에 더해져 읽기 마진을 갉는다. 셀 트랜지스터 폭 20 nm급에서 단일 트랩의 Vt 영향 대략 수십 mV.

#### 3.2.5 PCM 파라미터 해석

| PCM 항목 | 대표 구조 | 결정하는 공정 모듈 | 흔들릴 때 의심 |
|---|---|---|---|
| Vt(n/p, 셀/주변) | 단일 Tr | 게이트 스택, 채널 임플란트, 열 이력 | 임플란트 도즈, GOX 두께, 어닐 온도 |
| Idsat, Ioff | 단일 Tr | 채널 길이(게이트 CD), S/D | 포토/에치 CD, 스페이서 두께 |
| Rs(액티브, 폴리, 금속) | 반데르파우, 브리지 | 도핑·실리사이드·금속 두께 | 임플란트, 어닐, CMP 과연마 |
| Rc(컨택, 비아) | 켈빈, 체인 | 컨택 에치·세정·배리어 | 에치 잔류, 언더에치, 배리어 두께 |

해석 요령: 한 파라미터가 아니라 세트를 본다. nMOS Vt만 오르고 pMOS Vt는 그대로면 n채널 임플란트 또는 n 전용 공정. 둘 다 같은 방향이면 게이트 산화막 또는 공통 열 공정. Vt는 그대로인데 Idsat만 떨어지면 기생 저항(컨택, 실리사이드) 또는 이동도.

> **[핵심]** PCM은 "공정이 스펙 안인가"를 말하고, EDS는 "제품이 되는가"를 말한다. PCM이 다 스펙 안인데 수율이 나쁠 수 있다(PCM 구조가 실제 셀 어레이를 대변하지 못함). PCM이 스펙 밖인데 수율이 좋을 수도 있다(스펙이 과보수적). 둘의 상관을 항상 데이터로 확인한다.

#### 3.2.6 페일 비트맵(FBM)

| 패턴 | 형태 | 대표 원인 | 다음 단계 |
|---|---|---|---|
| 단일 비트(SBF) | 흩어진 점 | 셀 커패시터/채널 결함, 파티클, RTN, 리텐션 tail | 리던던시로 구제. 밀도가 스펙 넘으면 FA |
| 행(row) 불량 | 가로 줄 | 워드라인 오픈/쇼트, 서브 워드라인 드라이버 | 워드라인 공정(게이트 에치, 컨택) |
| 열(column) 불량 | 세로 줄 | 비트라인 오픈/쇼트, 센스앰프 | 비트라인 공정, BLC |
| 페어 비트(쌍) | 인접 2비트 | 스토리지 노드 브리지, 액티브 브리지 | SNC 에치, 캡 하부 전극 브리지 |
| 블록·매트 단위 | 사각 영역 | 디코더, 전원, 로컬 회로 | 주변 회로 검토, 레이아웃 |
| 클러스터 | 국소 덩어리 | 파티클·스크래치·국소 결함 | 인라인 결함 맵과 좌표 매칭 |
| 체커보드·주기 | 규칙적 반복 | 특정 셀 위상(짝/홀), 설계 민감도 | 레이아웃-공정 상호작용 |
| 다이 내 그라데이션 | 한쪽으로 증가 | 다이 내 공정 불균일(에치 로딩, 열) | 다이 내 CD/두께 분포 |

FBM은 다이 좌표 → 어레이 물리 주소로 변환해야 한다. 논리 주소와 물리 주소는 스크램블되어 있으므로 설계팀의 주소 맵이 필요하다. 테스트 조건(전압, 온도, 타이밍, 패턴)을 바꾸며 FBM이 어떻게 변하는지 보는 것이 가설 분기의 핵심이다.

#### 3.2.7 Shmoo

- 두 축(예: VDD vs tRCD, 온도 vs VDD, Vpgm vs 펄스 폭)에서 pass/fail을 그린다. pass 영역의 경계 형태가 메커니즘을 말한다.
- 해석 예: VDD를 낮추면 tRCD 마진이 급격히 줄어드는 곡선 경계 → 센스앰프 구동력·비트라인 RC. 온도 상승에 fail 영역이 늘면 누설(리텐션)형. 전압과 무관하게 특정 타이밍에서 절벽이면 로직 타이밍 문제.
- 가드밴드 평가: 스펙 조건 대비 pass 경계까지 거리가 마진. 마진이 부족하면 스크리닝을 세게(가드밴드 확대) 하거나 공정을 고친다(17장).

#### 3.2.8 온도·전압 가속 측정

- 리텐션·누설류 불량은 온도로 가속한다. 대략 10°C 상승에 누설 2배(Ea 대략 0.6~0.7 eV 가정) 수준을 기본 감으로 둔다. 85°C에서 64 ms 리텐션은 25°C에서 대략 수 초일 수 있다.
- 산화막·유전체 신뢰성은 전압으로 가속한다(TDDB, 18장). 테스트에서 VDD보다 높은 전압으로 짧은 시간에 약한 셀을 걸러낸다(번인, 스트레스 테스트).
- 가속의 함정: 가속 조건에서만 나타나는 메커니즘(다른 Ea, 다른 전압 의존성)이 끼면 실사용 예측이 틀린다. 두 온도 이상, 두 전압 이상에서 재어 기울기(Ea, 전압 가속계수)를 실측한다.

#### 3.3.2 광학·비파괴 패키지 계열

- OM: 첫 관문. 패키지 외관 크랙, 몰드 변색(과열), 핀 오염, 다이 표면 스크래치·변색. 광학 한계 0.2 μm라 소자 결함은 못 보지만 "어디를 더 볼지"를 정한다.
- SAT(Scanning Acoustic Tomography)/CSAM(C-mode Scanning Acoustic Microscopy): 물에 담근 패키지에 15~230 MHz 초음파를 주사. 재료 경계에서 반사, 특히 공기층(박리, 보이드)은 위상이 반전되어 뚜렷하다. HBM·FC 패키지의 언더필 보이드, 다이-몰드 박리, TSV 인터포저 박리 검출. 주파수가 높으면 분해능은 좋고 투과 깊이는 얕다.
- 2D X-ray: 밀도 차. 솔더(Sn, 무거움)는 어둡고 보이드는 밝다. 범프 보이드율(면적 %), 브리지, 와이어 스윕. 겹친 층은 구분 못한다.
- 3D X-ray CT(Computed Tomography): 시편을 회전하며 수백~수천 장을 찍어 3D 재구성. HBM처럼 8~16단 범프가 겹친 구조에서 특정 단의 범프만 잘라 볼 수 있다. 분해능 서브 μm급 장비는 시야가 좁아 관심 영역(ROI)을 먼저 좁혀야 한다.
- TDR(Time Domain Reflectometry): 빠른 전기 펄스를 핀에 넣고 반사 파형을 읽는다. 오픈은 양의 반사, 쇼트는 음의 반사. 반사 시간 × 전파 속도 / 2 = 거리. 기존 TDR은 mm급, EOTPR(Electro-Optical Terahertz Pulse Reflectometry)은 대략 10 μm급으로 HBM TSV·마이크로범프 구간 구분 가능.

> **[예시]** HBM 스택에서 특정 채널 오픈. EOTPR로 반사 지점을 재니 베이스 다이 위 약 3번째 코어 다이 높이. 3D X-ray CT를 그 높이로 좁혀 보니 마이크로범프 하나가 비접촉(non-wet). 그 뒤 FIB 단면으로 범프 표면 산화막과 언더필 침투를 확인. 비파괴 두 기법으로 위치를 좁혔기에 FIB를 한 번만 썼다.

#### 3.3.3 전기적 위치 추적(fault localization)

- EMMI/PEM(Photon Emission Microscopy): 소자에 바이어스를 걸면 역방향 누설 접합, 포화 영역 트랜지스터, 산화막 터널링 전류에서 미약한 빛(가시~근적외선)이 난다. 냉각 CCD/InGaAs 카메라로 수 분~수십 분 적분해 위치를 찍는다. 다층 금속에 가려지므로 보통 다이 후면(back side)을 연마·박형화해 Si를 통해 적외선(1,000 nm 이상)으로 본다.
- 함정: 정상 동작 회로(예: 클록 버퍼, 레퍼런스)도 빛을 낸다. 정상 다이와 불량 다이의 발광 이미지를 같은 조건으로 비교해 "차이"만 본다. 저항성 쇼트(금속-금속)는 빛이 거의 없어 EMMI에 안 잡힌다.
- OBIRCH(Optical Beam Induced Resistance Change)/TIVA(Thermally Induced Voltage Alteration): 1,300 nm 레이저를 주사하며 국소 가열. 금속의 저항이 온도로 변하는데(TCR), 전류가 흐르는 경로에서만 저항 변화가 전체 전류 변화로 나타난다. 쇼트 경로·고저항 비아·보이드 있는 배선을 지목한다. EMMI가 못 잡는 금속성 쇼트에 강하다.
- LVP/LVI(Laser Voltage Probing/Imaging): 후면에서 레이저로 트랜지스터 노드 파형을 읽는다. 로직 타이밍 불량 위치 추적. 메모리에서는 주변 회로 디버그에 쓴다.
- 나노프로빙: 디레이어로 컨택 또는 M1 층을 노출한 뒤 SEM 안에서 6~8개 탐침(팁 수십 nm)을 대고 개별 트랜지스터 I-V를 잰다. FBM으로 지목한 불량 셀 트랜지스터의 Vt, Ioff, 컨택 저항을 이웃 정상 셀과 직접 비교한다. "이 셀이 진짜 전기적으로 다른가"를 결정하는 마지막 전기 증거이며, 그 뒤 같은 위치를 FIB/TEM으로 잘라 물리 원인을 맞춘다.

> **[핵심]** 위치 추적의 순서는 "넓고 빠른 것 → 좁고 느린 것"이다. FBM(주소) → EMMI/OBIRCH(μm) → 나노프로빙(개별 소자) → FIB/TEM(nm). 한 단계를 건너뛰면 다음 단계의 성공 확률이 급락한다.

#### 3.3.4 시편 준비: 디캡, 디레이어, FIB

- 디캡(decapsulation): 몰드 컴파운드를 발연 질산·황산(화학), 레이저, 플라즈마로 제거해 다이를 노출. 과하면 본드 패드·범프 손상. HBM은 스택 구조라 위 다이를 제거하면 아래 다이 신호를 잃으므로 후면 접근이나 측면 단면을 선택한다.
- 디레이어(delayering): 위층부터 금속·절연막을 CMP, 습식 에치, 플라즈마로 한 층씩 제거. 층 두께가 수십 nm라 층 정지(stop)가 어렵다. 균일도 실패 시 다이 한쪽은 M2, 다른 쪽은 M1이 노출되는 "우물" 현상.
- FIB: Ga⁺(30 kV) 또는 Xe⁺ 플라즈마(대면적 고속) 이온빔으로 밀링. 단면 관찰(cross-section), TEM 라멜라(lamella, 두께 50~100 nm) 제작, 금속 절단·연결(회로 수정). 보호막(Pt, C)을 먼저 증착해 상부 손상을 막는다.
- FIB 아티팩트: 커튼(curtaining, 밀도 차로 생기는 세로 줄무늬, 보이드로 오해), 재증착(redeposition, 파낸 물질이 벽에 붙음, 브리지로 오해), Ga 주입(EDX에서 Ga 피크, 비정질화 층 수 nm), 열·전하에 의한 저융점 금속(Al, Sn, In) 변형. 저전압 마무리 밀링(2~5 kV)으로 손상층을 줄인다.
- 단면 위치 정밀도: 목표 결함이 20 nm면 FIB 슬라이스 위치 오차도 수 nm 안이어야 한다. 좌표계 정합(FBM 주소 → 레이아웃 → SEM 정렬 마크), 그리고 "슬라이스 앤 뷰(slice and view)"로 수 nm씩 깎으며 연속 관찰한다.

#### 3.3.5 전자현미경: SEM과 TEM

- SEM: 1~30 kV 전자빔 주사, SE는 형상, BSE는 조성 대비. 저전압(1 kV 이하)이면 표면 민감·차징 감소. 인렌즈(in-lens) 검출기로 1 nm급. 단면 SEM으로 개관(수 μm 시야)을 먼저 잡고, 필요한 곳만 TEM으로 간다.
- TEM: 80~300 kV 전자가 50~100 nm 두께 시편을 투과. BF(명시야) TEM에서 질량-두께·회절 대비, HRTEM(고분해능)에서 격자 무늬. STEM(주사 투과) 모드의 HAADF(고각 환형 암시야)는 원자번호 Z²에 비례하는 대비로 W, Ti, Hf는 밝고 Si, O는 어둡다. 두께 측정(GOX 1.5 nm, ONO 각 층), 계면 거칠기, 결정 결함(전위, 적층 결함), 보이드, 심(seam)을 본다.
- 시편 두께 아티팩트: 두꺼운 시편은 여러 층이 겹쳐 보여 계면이 흐려지고 두께가 과대 평가된다. 얇게 갈면 Ga 손상층 비율이 커진다. 시편 두께를 EELS 로그비로 확인한다.
- 3D 정보: 단면 하나는 2D 투영이다. 홀 형상(타원, 보잉)을 알려면 평면(plan-view) TEM과 단면을 함께 보거나 STEM 토모그래피를 쓴다.

#### 3.3.6 조성 분석: EDX, EELS, SIMS, XPS, Auger

- EDX(EDS, Energy Dispersive X-ray Spectroscopy): 전자빔이 내각 전자를 튕겨내고 채워질 때 나오는 특성 X선의 에너지로 원소 식별. SEM에서는 상호작용 부피가 μm급이라 박막 분석이 어렵고, STEM-EDX는 시편이 얇아 nm급 맵이 된다. 경원소(B, N, O)는 감도가 낮고 피크 겹침(예: W M선과 Si K선, Ti과 N)이 잦다.
- EELS(Electron Energy Loss Spectroscopy): 투과 전자가 잃은 에너지 스펙트럼. 코어 손실 에지에서 원소, 미세 구조(ELNES)에서 결합 상태(Si⁰ vs Si⁴⁺, 산화 정도). N, O, B, Li 같은 경원소에 강하다. 1 nm 이하 분해능으로 GOX/고유전율 계면의 SiOx 중간층 두께를 잰다.
- SIMS: O₂⁺ 또는 Cs⁺ 1차 이온으로 표면을 깎으며 튀어나온 이차 이온을 질량 분석. B, P, As 도펀트의 깊이 프로파일(농도 vs 깊이)을 10¹⁵~10²¹ cm⁻³ 동적 범위로 준다. 접합 깊이, 도펀트 확산, 금속 오염(Fe, Cu, Ni) 검출. 매트릭스 효과(같은 원소도 주변 재료에 따라 이온화율이 달라 정량 오차)와 노크온(knock-on, 스퍼터로 도펀트가 밀려 프로파일이 깊게 보임)이 함정. 표준 시편으로 정량한다. 측정 면적이 수십 μm 이상이라 개별 소자가 아닌 테스트 패드나 넓은 어레이에서 쓴다.
- ToF-SIMS: 시간 비행형, 표면 분자 정보. 유기 잔류물(레지스트, 세정 잔류) 식별.
- XPS(X-ray Photoelectron Spectroscopy): X선으로 방출된 광전자의 결합 에너지에서 원소와 화학 상태(예: Si-O vs Si-N, Ti 산화 여부). 정보 깊이 5~10 nm. 스폿 10 μm 이상이라 국소 소자 분석은 어렵고, 표면 오염·자연산화막·질화 정도 평가에 쓴다.
- Auger(AES): 전자빔 유도 오제 전자. 표면 1~5 nm, 스폿 10~50 nm로 XPS보다 국소적. 컨택 바닥 잔류물, 본드 패드 오염 분석. 화학 상태 정보는 XPS보다 약하다.

> **[주의]** EDX에서 Ga 피크가 나오면 대부분 FIB 주입이다. Cu가 뜬다면 FIB 그리드(Cu)일 수 있다. Pt/C는 보호막이다. 이런 "시편 준비 기원 원소"를 공정 오염으로 보고하면 공정팀이 존재하지 않는 오염원을 찾게 된다. 항상 기준 시편(정상 위치)에서 같은 조건으로 스펙트럼을 찍어 비교한다.

#### 3.3.7 탐침 계열: AFM, SCM, SSRM

- AFM(Atomic Force Microscopy): 나노 탐침이 표면을 훑으며 힘을 읽어 높이 지도를 만든다. 수직 분해능 0.1 nm 이하. CMP 후 디싱(dishing)·이로전(erosion), 표면 거칠기(RMS 0.1~1 nm), 스텝 높이, 패턴 붕괴. 팁 마모와 팁 곡률 반경(대략 5~10 nm)이 좁은 홈 깊이를 과소 측정하게 한다.
- SCM(Scanning Capacitance Microscopy): 도전성 탐침에 AC를 걸어 국소 dC/dV를 읽는다. 캐리어 농도가 높으면 dC/dV가 작다. 단면 시편에서 n/p 영역과 접합 위치, 채널 도핑 분포를 2D로 본다. 정량은 어렵다(반정량).
- SSRM(Scanning Spreading Resistance Microscopy): 다이아몬드 코팅 탐침으로 단면을 세게 눌러 국소 저항을 읽는다. 저항률은 캐리어 농도의 함수이므로 표준 시편으로 정량 도핑 지도를 얻는다. 분해능 수 nm, 동적 범위 10¹⁵~10²⁰ cm⁻³. 3D NAND 채널 폴리 도핑, DRAM 셀 트랜지스터 채널·접합 프로파일 분석에 쓴다.

#### 3.3.8 구조·응력: XRD, Raman

- XRD(X-Ray Diffraction): 브래그 조건 `nλ = 2d·sinθ`로 결정면 간격 d를 얻는다. 결정상 식별(ZrO₂의 정방/입방/단사정, HfO₂ 결정화 여부, TiN 배향), 결정 크기(피크 폭, Scherrer), 잔류 응력(피크 이동), 박막 두께(XRR 모드). DRAM 커패시터 유전체(ZAZ 등)의 결정화 정도는 유전율과 누설을 동시에 결정하므로 XRD가 표준 도구다.
- Raman: 레이저(예: 532 nm)를 쏘고 포논에 의한 진동수 이동을 읽는다. Si 피크(약 520 cm⁻¹)가 압축 응력에서 높은 쪽으로, 인장 응력에서 낮은 쪽으로 이동. 대략 1 cm⁻¹ 이동이 수백 MPa 응력에 해당. a-Si는 넓은 피크(약 480 cm⁻¹), poly-Si는 날카로운 피크로 결정성 구분. STI·컨택 주변 응력, 3D NAND 채널 폴리 결정성 평가.

#### 3.3.9 FA 요청서와 보고서에 반드시 들어갈 것

FA는 PE가 요청하고 분석팀이 수행한다. 요청서가 부실하면 분석팀은 "어디를 어떻게 잘라야 할지" 모른 채 시작한다.

| 요청서 항목 | 내용 | 빠지면 생기는 일 |
|---|---|---|
| 증상과 데이터 | FBM, shmoo, 온도·전압 의존, PCM 상관 | 목표 위치 불명, 랜덤 절단 |
| 가설과 우선순위 | 가설 3개 이상, 각 가설이 예측하는 관찰 | 결과가 나와도 해석 불가 |
| 목표 좌표 | 물리 주소, 레이아웃 좌표, 레이아웃 이미지 | 엉뚱한 셀 절단 |
| 절단 방향·깊이 | 워드라인 방향/비트라인 방향, 관심 층 | 관심 구조가 단면에 없음 |
| 기준 시편 | 같은 웨이퍼 정상 다이, 같은 좌표 | 아티팩트와 결함 구별 불가 |
| 요청 기법과 순서 | 예: EMMI → FIB S&V → STEM-EDX/EELS | 비파괴 정보 소실 |
| 시편 이력 | 테스트 조건, 열 이력, 디캡 방법 | 이력에 의한 변화를 결함으로 오독 |

보고서에는 관찰(observation)과 해석(interpretation)을 분리해 쓴다. "컨택 바닥에 2 nm 저밀도 층 관찰(관찰), EELS에서 C·F 검출(관찰), 에치 후 폴리머 잔류로 해석(해석), 기준 시편에는 없음(대조), N=3/3 재현(통계)". 이 형식이면 읽는 사람이 증거의 강도를 스스로 판단할 수 있다.

### 3.4 언제 무엇을 쓰는가: 결정 트리

```text
 START: symptom observed
   |
   +-- Where? (in-line / PCM / EDS / FT / reliability / customer)
   |
   +-- Is there a spatial signature? (wafer map, FBM)
   |      yes -> match with in-line defect/metrology map (same layer? same tool?)
   |      no  -> random -> statistics first (lot/wafer/site), then sample dies
   |
   +-- Is it electrical-parametric (Vt, R, C shift) or functional (bit fail)?
   |      parametric -> PCM correlation -> in-line metrology (CD/THK/OVL)
   |                 -> if still open: cross-section TEM + composition (EDX/EELS)
   |      functional -> FBM pattern -> address -> layout coordinate
   |
   +-- Package-level suspicion? (HBM/FC: open/short channel, no wafer-level clue)
   |      yes -> OM -> SAT -> 2D X-ray -> TDR/EOTPR -> 3D X-ray CT -> FIB
   |
   +-- Die-level localization needed?
   |      leakage/short  -> EMMI (junction) or OBIRCH (metal) from back side
   |      open/resistive -> OBIRCH, nanoprobing
   |      single cell    -> nanoprobing (compare with neighbor)
   |
   +-- Physical root cause
   |      shape/size     -> FIB-SEM (overview) -> TEM/STEM (detail)
   |      composition    -> STEM-EDX (heavy), EELS (light, bonding)
   |      doping         -> SIMS (1D, large area), SSRM/SCM (2D, local)
   |      surface chem   -> XPS (area), Auger (spot)
   |      crystal/stress -> XRD, Raman
   |
   +-- Verify: reproduce on 3+ dies with same signature, and on reference die
```

기법 선택의 원칙 다섯 가지.

1. 비파괴 먼저, 파괴 나중. 파괴는 되돌릴 수 없다.
2. 위치를 좁힌 뒤 자른다. 위치 없는 FIB는 도박이다.
3. 항상 기준(정상) 시편을 같은 조건으로 함께 분석한다. 차이만이 증거다.
4. 결과가 가설과 일치해도 다른 기법으로 교차 확인한다(예: TEM 두께 ↔ 엘립소 두께, EDX ↔ EELS).
5. 표본 수를 기록한다. N=1은 관찰, N≥3 재현은 증거다.

### 3.5 제품별 대표 시퀀스

#### 3.5.1 DRAM: 리텐션 tail 비트

```text
 EDS retention test fail (tREF margin low)
  -> FBM: single-bit scatter, density vs wafer position (center heavy?)
  -> temperature / voltage dependence (Ea extraction, GIDL vs junction)
  -> PCM correlation: cell Tr Vt, GIDL, cap C, cap leakage by site
  -> in-line correlation: GOX THK, WL recess depth (OCD), SNC CD, cap dielectric THK
  -> address -> layout -> nanoprobing on 3~5 tail cells + neighbors
        (cell Tr Ioff? cap leakage? contact R?)
  -> FIB slice-and-view -> STEM: WL recess, junction, SNC, cap bottom electrode
  -> STEM-EDX/EELS: dielectric composition, interface layer
  -> SSRM (optional): 2D junction profile
```

전기적 분기가 먼저다. 온도 의존성(Ea)이 접합 누설형(대략 0.6~1.0 eV)인지, GIDL형(약한 온도 의존, 강한 전압 의존)인지, 유전체 누설형인지에 따라 FA 목표 위치가 셀 트랜지스터인지 커패시터인지 갈린다.

#### 3.5.2 NAND: 특정 워드라인(단)의 Vt 분포 이상

```text
 EDS / FT: program or read fail concentrated on WL k (or WL group)
  -> Vt distribution (histogram) per WL: shift? widening? tail?
  -> cycling/retention dependence (intrinsic vs reliability)
  -> in-line: mold ONON THK per layer (XRR/ellipso on monitor), channel hole CD
             vs depth (OCD/CD-SEM at top; cross-section for depth profile),
             WL replacement (W fill) monitoring
  -> FIB cross-section along channel hole through WL k: hole CD, bowing,
     ONO thickness (STEM), W fill void, blocking oxide
  -> STEM-EELS on charge trap nitride and tunnel oxide at WL k vs others
  -> plan-view TEM at WL k depth: hole shape (ellipticity), pitch walking
  -> (bulk) SIMS on channel poly doping if all WLs affected
```

3D NAND에서 "특정 단"은 깊이 방향 위치다. 채널 홀 에치의 깊이별 CD 변화(상부 넓고 하부 좁거나, 중간 보잉), 몰드 적층 두께의 단별 편차, 텅스텐 치환 시 특정 단의 채움 부족이 후보다. 단면은 반드시 해당 단을 관통해야 하고, 이웃 단과 동일 시편에서 비교한다.

#### 3.5.3 HBM: 스택 간 채널 오픈/고저항

```text
 Package FT: channel open / high resistance / marginal timing on die k
  -> boundary scan / loopback test: which die-to-die link?
  -> OM (external), SAT/CSAM (delamination, underfill void)
  -> 2D X-ray (quick), then 3D X-ray CT focused on die k microbumps
  -> TDR/EOTPR: distance to discontinuity (which bump level?)
  -> thermal / mechanical stress test: does it recover/worsen? (TCT)
  -> mechanical cross-section (polish) or Xe-FIB large-area cross-section
  -> SEM/EDX on bump: non-wet, IMC thickness, void, crack, Cu pillar tilt
  -> TSV: void, seam, liner crack (FIB-SEM, TEM if needed)
  -> hybrid bonding (if applicable): Cu-Cu interface void, dishing (AFM on
     reference), particle at interface
```

패키지 FA는 열·기계적 이력이 증상을 바꾼다. 분석 전 온도 사이클을 몇 번 돌렸는지, 리플로우를 거쳤는지 기록한다. 또 3D X-ray CT 결과가 있어도 단면으로 확인해야 IMC(Intermetallic Compound) 두께·크랙 같은 μm 이하 정보를 얻는다.

> **[면접]** "불량이 발생했을 때 어떤 순서로 분석하겠습니까?"에 대한 1분 답변. "먼저 어디서 발견된 불량인지, 웨이퍼맵이나 페일 비트맵에 공간 패턴이 있는지 봅니다. 패턴이 있으면 같은 층의 인라인 결함·계측 맵과 대조해 공정 후보를 좁힙니다. 다음으로 전기 데이터, 즉 PCM 상관과 온도·전압 의존성으로 메커니즘을 접합 누설, GIDL, 저항성 오픈 등으로 분기합니다. 그 뒤 비파괴 위치 추적, 예를 들어 EMMI나 OBIRCH, 패키지면 SAT와 3D X-ray로 μm 수준까지 좁히고, 마지막에 FIB 단면과 TEM, EDX로 물리 원인을 확인합니다. 이때 정상 시편을 같은 조건으로 함께 분석하고 최소 3개 이상 재현되는지 확인해 아티팩트를 배제합니다. 비파괴에서 파괴로, 넓은 곳에서 좁은 곳으로 가는 것이 핵심입니다."

| 웨이퍼 휨(warpage) 증가 | 에지 범프 비접촉 | 에지 다이 채널 불량 | 휨 계측, SAT |
| TSV 보이드율 증가 | TSV 저항·용량 변화 | 타이밍 마진, 신뢰성 | 3D X-ray, FIB 단면 |
| IMC 두께 과다(>수 μm) | 취성 증가 | TCT 후 크랙 | 단면 SEM/EDX |
| 언더필 보이드 | 열 경로 차단, 응력 집중 | 열 불량, 크랙 | SAT, 단면 |
| 하이브리드 본딩 Cu 디싱 편차 | Cu-Cu 미접촉 | 오픈, 고저항 | AFM(본딩 전), 단면 TEM |

> **[면접]** "인라인 계측 데이터와 전기 데이터를 어떻게 연결합니까?" 1분 답변. "저는 사이트(site) 단위 상관을 기본으로 합니다. 웨이퍼 안 같은 위치의 인라인 값, 예를 들어 GOX 두께나 액티브 CD와, 같은 위치의 PCM Vt, 그리고 그 위치 다이들의 EDS 수율을 나란히 놓고 상관계수와 산점도를 봅니다. 예를 들어 GOX가 0.1 nm 얇은 사이트에서 Vt가 15 mV 낮고 리텐션 fail이 두 배라면 인과 사슬이 성립합니다. 상관이 없으면 그 계측 항목은 용의선상에서 지우고, 상관이 있으면 스플릿 로트로 그 변수만 의도적으로 흔들어 재현하는 것이 확증입니다. 계측 하나만 보고 결론 내리지 않고 반드시 전기 데이터로 닫는 것이 원칙입니다."

## 6. 트러블슈팅 케이스

### 6.1 케이스 A: DRAM 컨택 저항 상승, FIB "보이드"의 함정

- 증상: 신규 세대 램프업 중 특정 로트 그룹에서 열(column) 불량 증가. PCM 비트라인 컨택 켈빈 Rc가 평균 대비 2배.
- 1차 데이터: FBM에서 열 불량이 다이 에지 쪽 집중. 인라인 BLC 홀 CD-SEM은 스펙 내. 오버레이도 스펙 내. 컨택 체인 저항 상승.
- 가설: (1) 컨택 바닥 잔류물(세정 불충분), (2) W 플러그 보이드, (3) 배리어 TiN 두께 과다, (4) 컨택 언더에치.
- 1차 FA: 불량 다이 FIB 단면에서 W 플러그 중앙에 어두운 세로 띠 관찰. "보이드"로 보고됨. 공정팀이 W 증착 조건 조사 착수.
- 재검토: 기준(정상) 다이 단면에도 같은 위치에 같은 띠. 밀링 방향을 90° 바꿔 재밀링하니 띠가 사라짐. FIB 커튼 아티팩트로 판정. 2주 손실.
- 재분석: 저전압 마무리 밀링 후 STEM-HAADF로 컨택 바닥 관찰. 바닥에 두께 약 2 nm의 어두운 층. EELS에서 C, F 신호. 에치 후 폴리머 잔류물. Auger로 바닥 조성 확인.
- 근본 원인: 컨택 에치 후 세정과 배리어 증착 사이 큐타임(Q-time)이 특정 로트 그룹에서 초과. 잔류 폴리머가 굳어 세정 효율 저하.
- 조치: 큐타임 인터록 강화, 세정 레시피 보강. 해당 로트 그룹 Rc 회복 확인.
- 재발 방지: FA 보고서 템플릿에 "기준 시편 동일 조건 분석 여부" 필수 항목 추가. 커튼 의심 시 반대 방향 밀링 절차화.

> **[주의]** 이 케이스의 교훈은 FA 결과가 가설 중 하나와 "그럴듯하게" 맞을 때가 가장 위험하다는 것이다. 보이드 가설이 있었기에 커튼을 보이드로 읽었다. 기준 시편이 없는 FA 결과는 증거가 아니다.

### 6.2 케이스 B: NAND 특정 단 리텐션 열화, TEM 단면이 지목한 것

- 증상: 고온 리텐션 베이크 후 특정 워드라인 그룹(중간 단 근처)에서 Vt 하향 shift 과다.
- 1차 데이터: WL별 Vt 분포에서 해당 단만 하향 tail. 사이클링 전에도 약하게 존재. 인라인 몰드 ONON 두께(모니터 XRR)는 정상.
- 가설: (1) 해당 단 채널 홀 보잉으로 블로킹 산화막·질화막 실효 두께 변화, (2) 해당 단 W 치환 시 블로킹 산화막 손상, (3) 몰드 특정 단 질화막 조성 이상, (4) 채널 폴리 결정 결함이 해당 깊이에 집중.
- 가장 싼 검증: 이레이즈·프로그램 속도의 단별 분포. 해당 단이 프로그램은 빠르고 이레이즈 후 리텐션이 나쁘다면 터널 산화막 박막화 또는 트랩 질화막 이상 방향.
- FA: 채널 홀을 따라 해당 단을 관통하는 FIB 단면. STEM-HAADF에서 해당 단 홀 CD가 이웃 단보다 약 4 nm 크고(보잉), 터널 산화막 두께는 동일. EELS 라인 프로파일에서 해당 단 차지 트랩 질화막의 N/Si 비가 낮음.
- 교차 확인: 플랜뷰 TEM으로 해당 깊이 홀 형상 확인. 다이 3개 재현.
- 근본 원인: 채널 홀 에치 중 보잉 구간에서 홀 측벽에 증착된 질화막이 상대적으로 얇고 조성이 다름(측벽 각도에 의한 ALD 컨포멀리티 한계). 얇고 산소 비율이 높은 질화막은 트랩 밀도가 낮고 리텐션이 약함.
- 조치: 에치 보잉 억제(가스 비·바이어스 프로파일 조정), ALD 질화막 사이클 보정.
- 재발 방지: 단면 TEM에서 단별 CD 프로파일과 EELS 조성 프로파일을 신규 세대 인수 항목으로 추가.

### 6.3 케이스 C: HBM 채널 간헐 불량, 위치 추적의 순서

- 증상: 시스템 고객에서 특정 HBM 스택 한 채널이 온도 사이클 후 간헐적으로 오픈.
- 1차 데이터: 패키지 FT에서 상온 pass, 고온에서 fail. 루프백 테스트로 특정 코어 다이 링크 지목.
- 가설: (1) 마이크로범프 크랙, (2) 범프 비접촉(부분 접촉), (3) TSV 라이너 크랙, (4) 언더필 박리로 응력 집중.
- 비파괴 순서: OM 외관 정상. SAT에서 해당 다이 근처 언더필 국소 보이드. 2D X-ray는 겹침으로 불명. EOTPR로 반사 거리 측정, 해당 코어 다이 상부 범프 레벨. 3D X-ray CT를 그 범프 열에 집중, 범프 하나가 다른 것보다 얇고 비대칭.
- 파괴 확인: 기계 연마 단면 + SEM/EDX. 해당 범프에 미세 크랙, IMC 두께가 정상보다 약 2배. 크랙 경로가 IMC-Cu 계면. 이웃 정상 범프는 IMC 얇고 크랙 없음.
- 근본 원인: 언더필 보이드 근처 범프가 리플로우·TCT 중 국소 응력 집중과 열 이력 차이로 IMC 과성장, 취성 파괴.
- 조치: 언더필 도포·큐어 조건 조정, 보이드 SAT 전수 검사 강화.
- 재발 방지: SAT 보이드 크기 기준 설정, TCT 후 EOTPR 샘플링을 신뢰성 인수 항목에 추가.

> **[아이디어]** 3D X-ray CT는 분해능과 시야가 상충한다. 전체 스택 저분해능 스캔에서 이상 후보 범프를 AI로 자동 선별하고, 그 좌표만 고분해능 재스캔하는 2단계 스킴이면 HBM 16단에서도 분석 시간이 크게 줄 수 있다. 또 EOTPR 반사 파형을 정상 스택 라이브러리와 비교해 "범프 레벨 확률"을 주는 방법도 검토 가치가 있다.

### 6.4 케이스 D: 오버레이 "정상"인데 컨택 쇼트, 타깃과 디바이스의 차이

- 증상: DRAM 스토리지 노드 컨택(SNC)과 비트라인 사이 쇼트로 페어 비트·열 불량 증가.
- 1차 데이터: 오버레이 계측(DBO 타깃)은 스펙 내. SNC CD 스펙 내. e-beam VC 검사에서 다이 특정 영역 SNC가 밝음(비트라인과 연결).
- 가설: (1) 타깃-디바이스 오버레이 오프셋(타깃은 맞고 소자는 틀림), (2) SNC 에치 측벽 각도로 바닥에서 인접, (3) 스페이서 두께 부족.
- 검증: e-beam VC 밝은 SNC 좌표에서 FIB 단면. SNC가 비트라인 스페이서 쪽으로 약 3 nm 치우쳐 스페이서 두께가 국소적으로 얇음. 오버레이 타깃 위치는 다이 스크라이브 라인이고, 소자는 다이 중앙. 샷 내 고차 왜곡이 스크라이브와 중앙에서 다름.
- 근본 원인: 스캐너 샷 내 고차 왜곡 변화. 타깃은 샷 가장자리(스크라이브)라 중앙의 왜곡을 대변하지 못함.
- 조치: 다이 내 디바이스 유사 오버레이 타깃 추가, 샷 내 고차 보정 모델 갱신, e-beam VC를 오버레이 검증 수단으로 정례화.
- 재발 방지: 오버레이 스펙 검증에 "타깃-디바이스 오프셋 측정"을 세대 초기 필수 항목으로.

## 7. 응용·심화(최신 이슈)

### 7.1 EUV 시대의 계측: 확률적 결함과 CD-SEM 한계

- EUV(13.5 nm) 노광은 광자 수가 적어 확률적(stochastic) 결함(랜덤 브리지, 미싱 홀)이 생긴다. 발생률 10⁻⁶~10⁻⁹ 수준이라 CD-SEM 몇십 점 측정으로는 못 잡고, 대면적 e-beam 검사(수 mm² 이상)로 통계를 모아야 한다.
- 얇은 EUV 레지스트(20~30 nm)는 전자빔 수축·손상에 더 민감. 저전압(300 V 이하)·저도즈 CD-SEM, 그리고 OCD와 병행이 표준화된다.
- LER/LWR이 CD 자체보다 중요해진다. LWR 3σ 1 nm가 셀 트랜지스터 Vt 산포 수십 mV로 이어질 수 있다. 계측 자체의 노이즈(SEM 이미지 노이즈)를 LWR에서 분리하는 PSD(Power Spectral Density) 기반 분석이 필요하다.

### 7.2 HAR(High Aspect Ratio) 구조 계측

- 3D NAND 채널 홀(종횡비 50~100 이상), DRAM 커패시터 홀(종횡비 수십)은 CD-SEM이 상부만 본다. 바닥 CD·보잉·틸트는 OCD(모델 기반), 저에너지 X선 산란(CD-SAXS, 연구 단계), 또는 파괴 단면에 의존한다.
- 인라인 단면 대체: 웨이퍼 한 장을 희생해 여러 위치 FIB 단면을 자동으로 찍는 "인라인 FIB" 샘플링이 신규 세대 램프업에 도입되고 있다.
- 틸트(tilt) 계측: 수 μm 깊이 홀이 0.1° 기울면 바닥이 수십 nm 이동. 상부·하부 오버레이 타깃 비교, 또는 e-beam 후방산란(BSE) 고전압 이미징으로 바닥 위치를 투시하는 기법이 검토된다.

### 7.3 e-beam 검사의 확장과 VC(전압 대비)

- 멀티빔 e-beam 검사(수십~수백 빔 동시)로 처리량이 개선되어 EUV 층 전면 검사에 근접하고 있다.
- VC 검사는 매립 컨택의 전기 상태를 인라인에서 본다. 플로팅 컨택은 빔 전하가 빠지지 않아 밝거나(양 전하) 어둡게(음 전하) 보인다. 오픈/쇼트/누설 컨택을 EDS 두 달 전에 잡는다. DRAM SNC, BLC, 3D NAND 셀 컨택에 적용.
- 한계: 차징 조건에 따라 신호가 뒤집힐 수 있고, 하부 회로 연결 상태(접지 여부)에 따라 정상도 이상처럼 보인다. 레퍼런스 다이·레이아웃 정보를 함께 쓴다.

### 7.4 3D DRAM·하이브리드 본딩 FA

- 3D DRAM(수직 적층 셀)은 3D NAND처럼 깊이 방향 위치 정보가 필요하다. 셀 트랜지스터가 수평 채널로 누워 있어 기존 단면 방향과 다른 시편 절단 계획이 필요하다.
- 하이브리드 본딩(Cu-Cu 직접 접합)은 범프가 없어 X-ray로 오픈을 볼 수 없다. 본딩 계면의 Cu 디싱·파티클·보이드는 본딩 전 AFM/검사와 본딩 후 SAT(고주파, 분해능 μm급 필요), IR 현미경, 그리고 단면 TEM에 의존한다. 접합 계면 μm 이하 보이드를 비파괴로 찾는 것이 미해결 과제다.

### 7.5 데이터 기반 분석: 맵 매칭과 자동 분류

- 인라인 결함 맵, 계측 맵, PCM 맵, EDS 맵을 웨이퍼 좌표계로 정합해 공간 상관을 자동 계산하는 시스템이 표준이 되고 있다. 특정 결함 종류의 킬 비율을 매 로트 자동 갱신한다.
- FBM 패턴 자동 분류(CNN 기반), 리뷰 SEM 이미지 ADC, TEM 이미지 두께 자동 측정 등은 분석 처리량을 높이지만, 학습 데이터에 없는 신규 결함을 놓칠 수 있다. PE는 "미분류(unknown)" 버킷을 반드시 사람이 검토하도록 운영해야 한다.

### 7.6 원자 수준 계측의 한계

- GOX 1.5 nm, 유전체 각 층 수 옹스트롬 시대에 TEM 두께 측정 불확도(0.1~0.2 nm)가 스펙의 10% 이상이다. 시편 두께·초점·정렬 조건을 표준화하고, 여러 위치 평균으로 통계를 만들어야 한다.
- 원자 프로브 토모그래피(APT, Atom Probe Tomography): 팁 형태 시편을 전계 증발시켜 원자 하나하나의 3D 위치와 질량을 얻는다. 도펀트의 3D 분포(10 nm 채널 안 B 원자 수 세기)가 가능하다. 시편 제작 난이도가 높고 처리량이 매우 낮아 연구·핵심 이슈에만 쓴다.

> **[심화]** STEM-EELS 스펙트럼 이미징으로 HfO₂/SiO₂/Si 스택의 계면 SiOx 층을 0.3 nm 단위로 정량하는 것이 고유전율 게이트 스택 분석의 표준이 되었다. O K-edge ELNES의 형태가 Si-O 결합 vs Hf-O 결합에 따라 다르므로, 계면 층 두께뿐 아니라 화학 상태 분포까지 얻는다. 이것이 C-V EOT와 맞는지 확인하는 것이 PE와 분석팀의 공동 작업이다.

> **[면접]** "SEM과 TEM의 차이를 설명하고 어떤 상황에 각각 쓰겟습니까?" 1분 답변. "SEM은 전자빔을 표면에 주사해 이차전자나 후방산란전자로 표면 형상을 보며 분해능은 1~3 nm 수준이고 시편 준비가 간단해 빠릅니다. TEM은 50~100 nm로 얇게 만든 시편을 전자가 투과하며 0.1 nm급으로 단면 내부 구조, 박막 두께, 계면, 격자까지 봅니다. 대신 FIB로 시편을 만들어야 해서 하루 이상 걸리고 시편이 파괴됩니다. 그래서 저는 SEM으로 단면 개관을 잡아 컨택 오픈이나 큰 보이드처럼 수십 nm 이상 결함을 먼저 확인하고, 게이트 산화막 두께나 계면층, 유전체 결정 상태처럼 nm 이하 정보가 필요할 때 TEM으로 갑니다. TEM에서는 EDX나 EELS로 조성까지 같이 봅니다."

## 8. 셀프 체크 질문

### 8.1 개념

1. 계측(metrology)과 검사(inspection)의 차이는 무엇인가?
- 답: 계측은 치수·두께 같은 수치를 재고 정밀도·정확도로 평가한다. 검사는 결함의 존재와 위치를 찾고 감도·포착률·뉴슨스율로 평가한다. 예: CD-SEM은 계측, BF 검사는 검사. 둘은 연결된다. 검사 결함 좌표를 리뷰 SEM으로 분류하고 킬 비율을 붙여야 수율 손실 예측이 된다.

2. CD-SEM과 OCD는 각각 무엇을 잘 보고 무엇을 못 보나?
- 답: CD-SEM은 표면 패턴을 직접 관찰해 국소 CD·LER을 0.2~0.5 nm 반복성으로 재지만 2D 정보만이고 레지스트 수축·차징이 있다. OCD는 산란 스펙트럼을 모델에 피팅해 CD·높이·측벽각·매립 두께를 비파괴로 빠르게 얻지만 모델이 틀리면 답도 틀리고 주기 패턴에만 쓴다. 신규 구조에서는 TEM으로 OCD 모델을 검증한다.

3. 파괴 분석과 비파괴 분석을 순서대로 쓰는 이유는?
- 답: 파괴 분석은 시편을 잃고 N=1이며 위치를 틀리면 결함을 놓친다. 비파괴(EMMI, OBIRCH, SAT, X-ray)로 위치를 μm까지 좁히면 FIB 한 번에 맞힐 확률이 높아진다. 비용·시간도 비파괴가 훨씬 적다. 원칙은 "넓고 빠른 것에서 좁고 느린 것으로".

4. EDX와 EELS의 차이는?
- 답: EDX는 특성 X선 에너지로 원소를 식별하며 중원소에 강하고 사용이 쉽다. 경원소(N, O, B) 감도가 낮고 피크 겹침이 있다. EELS는 투과 전자의 에너지 손실로 원소와 결합 상태(산화 정도)를 1 nm 이하 분해능으로 얻어 경원소와 계면 화학 분석에 강하다. 둘을 교차 확인하면 피크 겹침 오진을 피한다.

5. FBM에서 행 불량과 열 불량은 각각 어디를 의심하나?
- 답: 행 불량은 워드라인 방향 전체가 죽은 것이므로 워드라인 오픈·쇼트, 서브 워드라인 드라이버, 게이트 에치·컨택을 의심한다. 열 불량은 비트라인 오픈·쇼트, 비트라인 컨택, 센스앰프다. 논리 주소를 물리 주소로 변환한 뒤 판단해야 하며, 테스트 조건(전압·온도)에 따른 변화로 저항성인지 완전 오픈인지 분기한다.

### 8.2 응용

6. 컨택 저항이 올랐다. 켈빈 구조와 체인 구조를 어떻게 함께 해석하나?
- 답: 켈빈은 컨택 하나의 저항을 정확히 재고, 체인은 수천 개의 합으로 오픈 확률을 본다. 켈빈 평균이 2배 올랐는데 체인은 정상이면 전체적으로 균일하게 저항이 오른 것(계면 잔류물, 배리어 두께)이다. 켈빈은 정상인데 체인이 튄다면 일부 컨택만 오픈·부분 오픈(에치 미개방, 파티클)이다. 전자는 세정·증착, 후자는 에치·결함을 본다.

7. 인라인 오버레이가 스펙 안인데 컨택 쇼트가 난다. 무엇을 의심하나?
- 답: 타깃-디바이스 오프셋을 의심한다. 오버레이 타깃은 스크라이브 라인에 있고 소자는 다이 중앙이어서 샷 내 고차 왜곡이 다를 수 있다. 검증은 e-beam VC 검사로 쇼트 컨택 좌표를 얻고 그 위치 FIB 단면에서 실제 정렬을 재는 것이다. 대책은 다이 내 디바이스 유사 타깃 추가와 고차 보정 모델 갱신이다.

8. EMMI에서 핫스팟이 보였다. 바로 FIB로 가도 되는가?
- 답: 안 된다. 정상 회로도 발광하므로 기준 다이를 같은 바이어스로 찍어 차이 이미지를 만들어야 한다. 또 금속성 쇼트는 EMMI에 안 잡히므로 OBIRCH로 교차 확인한다. 핫스팟이 불량 다이에만 있고 두 기법이 같은 위치를 가리키면 그때 좌표를 레이아웃에 정합하고 FIB 슬라이스 앤 뷰로 들어간다.

9. HBM 채널 오픈에서 비파괴 분석 순서를 설계하라.
- 답: OM 외관 → SAT로 박리·언더필 보이드 → 2D X-ray 신속 확인 → EOTPR로 불연속 지점 거리(어느 다이 레벨) → 3D X-ray CT를 그 레벨 범프에 집중 → 이상 범프 좌표 확정 후 단면(연마 또는 Xe-FIB) SEM/EDX로 크랙·IMC·비접촉 확인. 분석 전 열 이력(TCT, 리플로우 횟수)을 기록한다.

10. 리텐션 tail 비트의 온도 의존성이 왜 FA 목표 위치를 바꾸나?
- 답: 활성화 에너지가 0.6~1.0 eV급이면 접합 누설(SRH 생성)이라 셀 트랜지스터 접합·금속 오염을 본다. 온도 의존이 약하고 전압 의존이 강하면 GIDL 또는 유전체 터널링이라 게이트 에지·산화막·커패시터 유전체를 본다. 즉 FIB 절단면을 트랜지스터 쪽으로 잡을지 커패시터 쪽으로 잡을지가 전기 데이터에서 결정된다.

### 8.3 심화

11. FIB 커튼 아티팩트를 진짜 보이드와 어떻게 구별하나?
- 답: 커튼은 밀도 차 재료 아래로 이어지는 세로 줄무늬로 밀링 방향을 따라 생긴다. 시편을 회전하거나 로킹 밀링으로 방향을 바꾸면 사라지거나 위치가 변한다. 진짜 보이드는 방향과 무관하게 같은 위치에 있고 STEM-HAADF에서 경계가 뚜렷하다. 기준 시편 동일 조건 분석과 반대 방향 재밀링을 절차로 둔다.

12. SIMS 도펀트 프로파일이 실제보다 깊게 나오는 이유와 대책은?
- 답: 1차 이온이 도펀트 원자를 앞으로 밀어 넣는 노크온과, 스퍼터 초기 과도 영역, 표면 거칠기 발달이 깊이 분해능을 악화시킨다. 매트릭스 효과로 농도도 왜곡된다. 대책은 저에너지(수백 eV) 1차 이온, 경사 입사, 표준 시편으로 RSF 보정, 그리고 SSRM 등 다른 방법과 교차 확인이다.

13. 차지 펌핑 전류 식을 쓰고 Dit 정량 절차를 설명하라.
- 답: `I_cp = q·f·A·D_it·ΔE`. 게이트에 축적↔반전 펄스를 주며 기판 전류를 재고, 주파수 f를 바꿔 I_cp가 f에 비례하는지 확인해 기하 전류를 분리한다. 게이트 면적 A와 스캔 에너지 폭 ΔE(펄스 진폭·상승 시간에서 결정)를 넣어 Dit를 얻는다. 예: 1 MHz, 10⁻⁷ cm², ΔE 0.6 eV에서 1 pA면 Dit ≈ 10¹¹ cm⁻²eV⁻¹. HCI 전후 비교로 계면 손상을 정량한다.

14. 킬 비율(kill ratio)을 어떻게 구하고 어디에 쓰나?
- 답: 인라인 검사에서 결함 좌표를 얻고, 그 좌표를 포함하는 다이의 EDS 결과를 매칭한다. 결함 종류별로 "결함 있는 다이 중 불량 다이 비율"에서 배경 불량률을 빼면 킬 비율이다. 결함 밀도 × 킬 비율로 수율 손실 기여를 계산해 우선 개선 결함을 정하고, 검사 레시피 감도 기준을 킬러 중심으로 조정한다. 세대·층마다 갱신한다.

15. 하이브리드 본딩 계면의 미세 보이드를 비파괴로 찾기 어려운 이유와 접근은?
- 답: 범프가 없어 X-ray 밀도 대비가 거의 없고, 보이드가 μm 이하라 SAT 분해능(10 μm급)에도 못 미친다. 접근은 본딩 전 AFM/검사로 Cu 디싱·파티클을 관리하고, 본딩 후 고주파 SAT나 IR 투과 현미경으로 큰 이상을 걸러낸 뒤, 전기 테스트(데이지 체인 저항)로 후보를 좁히고 단면 TEM으로 확인하는 것이다. 근본적으로는 본딩 전 검사 강화가 답이다.

16. OCD 결과가 갑자기 튀었다. 구조 변화인지 모델 문제인지 어떻게 가르나?
- 답: 먼저 피팅 잔차(GOF)를 본다. 잔차가 커졌으면 모델이 현실을 못 따라간 것이다. 다음으로 상관이 높은 파라미터(CD와 높이, 하부 막 두께)가 반대 방향으로 함께 움직였는지 본다. 그러면 파라미터 교환일 가능성이 크다. 최종적으로 같은 위치 CD-SEM·엘립소, 필요하면 TEM으로 대조한다. 하부 막 공정이 바뀐 이력이 있으면 모델 광학 상수를 갱신한다.

17. 나노프로빙이 FIB/TEM 앞에 놓이는 이유는?
- 답: TEM은 한 점의 구조만 보여 주고 "그 구조가 전기적으로 문제인가"를 말하지 못한다. 나노프로빙은 FBM이 지목한 셀 트랜지스터·컨택에 직접 탐침을 대어 이웃과 I-V를 비교하므로, 불량이 그 소자에 있다는 마지막 전기 증거를 준다. 이 증거가 있어야 TEM에서 발견된 미세 구조 차이를 원인으로 연결할 수 있고, 반대로 나노프로빙이 정상이면 FIB 위치를 바꿔야 한다.
